# 馆藏对照室

用户：古籍整理、档案扫描质检与修复前后复核人员。主任务是在两个可缩放图像窗口中核对扫描页，保存页级意见与复核状态。

设计：档案阅览室风格。深色木棕顶栏、暖灰纸面、赭色状态点；主要空间留给并排画面，图片之外保持简洁。左/右页选择在画面上方，资料页条与复核记录放画面下方。与参数制图的尺寸表格、乐谱的长纸张、农田的地图不同。

首屏：项目与保存状态 → 选择两页 → Mirador 双窗口 → 复核记录。没有顶栏统计卡。初始原创资料页演示图像差异，界面明确标为演示；用户可换成自己的 JPEG/PNG。

状态：加载显示文字；导入中锁定项目切换；非法图片保留当前资料；图像资源丢失显示具体原因；保存冲突保留草稿；未保存离开提示。图像导入、记录、新建与删除都有独立边界。

375px：左右画面改为可切换的单侧查看，上方保留两侧页选择；页条横向局部滚动；批注表改单列卡片。所有主要操作有键盘路径，图片浏览工具由 Mirador 提供可访问按钮，外层不接管快捷键。尊重 reduced-motion，焦点明显；深色主题保持纸面图像原色。

验收：本地图像导入 → 两侧切换/缩放 → 添加复核意见 → 保存/刷新/重开 → 图像与意见恢复 → 下载可移植项目及复核清单。另验错误格式、删除/导入草稿保护、375px、键盘、console/CSP和图片请求。

## 产品化重排

按用户要求改成固定视口的专业图像阅览台：紧凑文件条和自动保存状态、左侧深绿资料抽屉、中央深色双图光台、右侧独立复核账本，去除大型标题区与全页卡片流。查看区采用Mirador暗色工具条，原图不变色。移动端改为单侧光台与水平资料条，复核账本在下方。平移/缩放/旋转进入自动保存；响应式重建前捕获视图。图片导入保留原项目，完整项目导入开启新文档。非法但结构安全的输入存为工作草稿。
