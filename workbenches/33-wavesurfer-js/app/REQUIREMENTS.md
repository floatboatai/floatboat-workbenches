# 声段 · 录音听审

用户：采访编辑、素材研究者。上传音频原件 → 查看真实波形 → 播放/速度/缩放 → 建立并调整时间区间 → 循环回听 → 写摘录并标记审阅 → 导出区间与完整工程。

原音频以 SHA-256 命名，单文件 32 MiB，384 KiB 分块。最多 500 个选段、850 KB 工作稿。累计原件随使用增长，不自动删除原件；数据资源由工作台保存，不含在默认源码包。浏览器解码格式取决于设备。

自动保存覆盖有效工程、未完成秒数字段、未应用 JSON 和空标题；恢复文件 snapshot:{title,data,extra} 导入为新副本。完整工程含原件；恢复稿无原件时要求匹配 SHA-256 重附，保留笔记。导航先锁编辑再等待旧工作稿保存。没有转写、降噪、剪切/编码导出或模型调用。

音频预算补充：原生metadata先限制10分钟；验证解码使用16kHz并检查128MiB PCM预算，原音频保持原始字节。输入上限与恢复契约一致；CSV公式前缀以文字转义。
