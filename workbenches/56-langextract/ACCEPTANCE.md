## 未覆盖与限制

- **真实 Floatboat Host / 模型调用未测**：按要求只做 mock 合同测试；预览全程离线模式，“Floatboat 模型可用”状态的界面未在浏览器中实际出现。模型 ID 默认 `gemini-3.8-flash`，可在抽取面板修改，Host 路由是否可用以实际账户为准。
- 抽取质量取决于模型；对齐只保证片段确实出现在原文中，不保证分类正确，所有模型记录默认待复核。模糊对齐（≥0.75）需要人工核对。
- Host 任务逐段串行，单段失败（解析不出 JSON）只记提示；Host 连接错误会让整次任务失败，不保留已完成段的部分结果；不支持取消正在进行的 Host 任务（停止接收只对 Python 服务）。
- Python 服务未连真实模型（沿用 0.4 契约测试），一次最多 8 份、每份 3 万字符。
- 正式批次 880KB 上限来自共享存储的 900KB 限制；原文与抽取时原文各存一份，中文资料实际约 13 万字符/批次，超过部分以工作稿保存。
- 不解析 PDF/扫描件；可视化 HTML 为本工作台自写，未复制 LangExtract `visualize()` 的动画页面。
- Floatboat 客户端导入未实测。
