# 证据书桌（0.9.0）

## 用户与主任务

采购、合同、访谈与会议资料的整理者。主任务：把一批原文里的组织、人员、金额、日期、义务和风险抽出来，每一条都能回到原文区间核对，接受、驳回或修订后交付审定结果。工作对象是“资料批次”（一组原文 + 类别定义 + few-shot 示例 + 逐条记录），不是“项目”。

## 任务路径

- **首次使用**：首屏直接是示例批次《城市的灯》灯具采购（5 份资料、55 条人工编制记录，明确标注“非模型输出”）。不需要先建项目；点高亮即看依据，选中原文即可标注。
- **从空白开始**：档案 → 新建空白批次，纸面给出“粘贴原文 / 添加文本文件 / 打开 LangExtract JSONL”三个入口。工作副本在第一次编辑后由自动保存创建，以批次名称命名。
- **继续上次工作**：打开即恢复最近批次（SQLite + IndexedDB）；档案菜单“最近批次”列出其余批次与本机未同步草稿。
- **导入与恢复**：档案 → 打开文件（JSONL / 工作稿 / 文本）或粘贴 JSONL，一律新建批次，原批次保留；完整工作稿 JSON 含修订与未应用草稿。模型结果（Host 或 Python 服务）也另开为新批次。

## 空间关系

- 主工作区：左侧原文纸页（约 58%），所有已定位记录按类别着色高亮、上标编号；右侧记录账本与复核卡片。选区出现时，纸页上方弹出深色“标注为”工具条（窄屏固定在底部），主操作紧贴操作对象。
- 上下文工具：顶部单行书桌条——档案菜单（文件生命周期全部在此）、批次名称、保存状态、通道状态点、“抽取”。抽取面板在按钮下方展开：范围、通道、模型 ID、通道状态与启动方式、重新检查、开始；不可用时按钮旁写明原因，不出现死按钮。
- 按需信息：页签“类别与示例”（任务说明、类别与属性名、结构化 few-shot 示例与对齐警告、JSON 源码、提示词预览）、“统计”（类别 × 状态、逐份资料）、“任务”（Host 与 Python 任务记录、进度、提示与输入快照）。
- 去掉了 0.4 的“项目选择器 + 新建 + 导出 + 立即保存”通用页头；“立即保存”只在草稿、离线、冲突时出现。

## 色彩、排版与密度

米白桌面（#f6f3ec）、纸页 #fffef9、深棕文字、墨绿主操作。证据颜色是类别色板（10 色浅色系，类别定义顺序固定分配），状态用形状区分：待复核下划阴影、驳回删除线淡化、当前记录墨色描边。原文用衬线中文字体 17px/2.1 行高；控件为系统无衬线；区间、计数用等宽数字。账本行 10px 内边距，单屏约 6 条记录；统计页是密排表格加堆叠条。

## 关键状态

- 通道：Floatboat 模型（可用 / 未连接 / 工作台未授权）、Python 服务（未配置 / 不可达 / 未配模型 / 可用）分别显示；两者都不可用时顶部显示“离线 · 手工标注”，手工标注、导入、复核、导出全部可用。
- 记录：精确定位、模糊定位（Node 对齐，标注相似度）、人工定位、未定位（可“在原文中查找”或“定位到选区”）、原文已变更（禁用接受/修订，可恢复原文）。
- 来源：模型记录只能驳回不能删除；人工标注默认已接受、可删除；原始 JSONL 不含人工标注。
- 保存：pending/saving/saved/draft/offline/conflict，后台保存不阻挡输入；冲突时提供导出本机草稿与打开服务器版本。
- 任务：Host 运行中显示分段进度；完成后“另开结果批次”；Host 断开为失败并保留记录；服务重启的运行标为中断，不自动重发。

## 窄屏（375px）

书桌条两行：图标、档案、抽取在上，批次名与保存状态在下；通道点隐藏（抽取面板内仍完整显示）。页签横向滚动；资料条横向滚动；纸页与账本纵向排列；标注工具条固定在屏幕底部；抽取面板与档案菜单铺满宽度。统计表在局部横向滚动，页面本身不横向溢出。

## 与相邻工作台的结构差异

对照 PageIndex（章节目录 | 原页 | 摘录与问答三栏）与 Agent-Reach（来源采集 | 阅读正文 | 摘录夹三栏）的 0.9.0 截图：二者以“单篇长文阅读 + 侧栏摘录”为主，左侧是导航树。证据书桌没有左侧导航栏，横向资料条承担批次导航，主区 2 栏把面积给原文纸页与逐条账本；摘录不是自由文本卡片，而是带类别、属性、区间和状态的结构化记录，并有批次级统计与 few-shot 配方页。文件生命周期都在产品菜单（PageIndex“文档”、Agent-Reach“调研”、此处“档案”），属于同类惯例。

## 结构审查

本轮按上述路径在 1440 与 375 宽完成空态（空白批次、新增文本资料）与有内容两种状态的新建、打开、导入、恢复和主业务动作；菜单与抽取面板验证了 Escape 关闭与焦点返回。正式的跨工作台截图对照审查仍为 **pending**，由主线统一记录。
