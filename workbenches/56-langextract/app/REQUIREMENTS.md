# LangExtract 证据批次复核台

输入：普通非医疗文本（粘贴、.txt/.md 文件）、LangExtract AnnotatedDocument JSONL/JSON 数组、完整工作稿。一个批次 1–40 份资料、每份最多 20 万字符、每份最多 2000 条记录，正式批次受 880KB 保存上限约束（超出部分作为可恢复工作稿保存）。

能力：

- 抽取配方：任务说明、类别定义（名称、含义、属性名）、结构化 few-shot 示例；按 LangExtract 的做法校验示例片段必须逐字出现在示例原文中；可预览实际提示词。
- 抽取通道：内置 Floatboat Host 模型（`llm.generateText`），按 LangExtract 的 Q/A few-shot 格式分段提示，在 Node 内解析输出并把每条结果对齐到原文 Python 码点区间（精确、规范化、模糊≥0.75，否则未定位）。可选 LangExtract 1.7.1 Python 服务。两条通道都在抽取面板旁显示状态、启动方式与重新检查；结果另开为新批次。
- 无模型时：选中原文手工标注、修改类别/值/属性、重新定位到选区、自动对齐未定位记录、接受/驳回/修订、笔记；键盘 J/K/A/X。
- 批次：多文档、类别统计、逐份进度。
- 导出：审定结果 JSONL（LangExtract 格式）、原始抽取 JSONL（模型原样，不含人工标注）、审校表 CSV、可视化审校页 HTML、完整工作稿 JSON。

约束：原始模型记录不被人工修订覆盖；原文变化使旧区间失效；任务输入快照先落盘，同一任务标识不重复调用模型；示例不能称为模型结果。本地业务、Host 合同（mock）、真实 Host、Python 服务与 Floatboat 客户端导入分别验收。
