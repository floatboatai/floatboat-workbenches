# 页面构建工作台

面向需要制作活动、工作室和产品介绍页的内容设计者。首屏的主任务是直接选择画布元素、双击改字、添加区块和调整样式；上方显示设备尺寸与保存状态。

布局采用网站构建器：52px 文件条、40px 设备/撤销工具条，左侧 176px 区块/图层切换，中间带灰色工作区的白色页面，右侧 230px 样式检查器。主视觉来自可编辑示例页面，不使用统计卡或说明式 hero。紫色仅用于选区与操作，工具框架使用石墨灰和温白。中文系统无衬线，工具 12–14px，示例页面使用大字号与有节奏的留白。

状态包含初始加载、未选元素、选择/文字编辑、待保存、保存模型、未应用输入草稿、离线本地副本、冲突和导入错误。背景保存不能禁用画布。源项目 JSON 和检查器中的未完成输入保存在工作副本。导入总是新页面。

窄屏使用横向工具条与画布/组件/样式三个工作视图，画布默认手机宽度；所有文件动作仍可访问。主题跟随系统和 Host 变量。组件操作保留文字标签与焦点轮廓，减少动画时关闭过渡。键盘用户可通过组件添加按钮、图层选择、检查器和属性输入完成主要任务。

验收：模板→文字→区块→样式→导出→重载；未 blur 的文字和属性草稿恢复；延迟响应不重建引擎；导入新文档；冲突/断网可恢复；375px/1440px 与深色/减少动画无页面横向溢出。
