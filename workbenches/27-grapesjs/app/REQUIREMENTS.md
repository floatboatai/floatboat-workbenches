# GrapesJS 页面构建

面向内容设计者制作文字、图形化 CSS 装饰和布局组成的单页网站。核心任务为选模板、双击改字、拖动或键盘插入区块、用原生图层和样式面板排版，切换设备后导出网页。

必须保留原生 GrapesJS 编辑行为；保存响应不能替换或重建实例。导入创建新页面；源 JSON、正在编辑的文字和属性输入需要恢复。区分模型保存、含输入的工作副本、本机离线副本和版本冲突。真实服务为本地 HTTP/SQLite；不依赖 Host 模型服务。

验收范围：6 种区块、单页、常见安全 HTML 标签/属性和受限 CSS，HTML/CSS/JSON 导出。HTML 导出必须脱机打开且内容与样式一致。页面模型 700 KB / 1000 元素 / 24 层 / 1200 规则。图片、视频、脚本、表单、远程资源、任意 HTML、Studio SDK、邮件客户端适配、AI 和发布不在本次范围。

要求的状态：加载、未选元素、选择、文字编辑、待保存、模型已保存、输入草稿已保存、断网、冲突、格式错误和恢复。要求的视图：1440px 桌面、375px、深色、减少动画。截图必须来自普通示例页面。
