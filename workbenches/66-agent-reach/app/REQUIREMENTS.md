# 公开来源调研

用户：做技术选型、行业调研或写作准备的人。主任务：采集公开来源 → 收件区 → 按链接去重收藏 → 阅读原文 → 逐字摘录与判断 → 审阅状态 → 带出处的 Markdown 报告。

## 必须

- 无外部服务即可使用：采集在工作台 Node 服务内完成，空数据目录首次打开即有真实示例调研，主任务可完整走通并导出报告。
- 渠道（移植 Agent-Reach 1.6.0 公开、免登录路径）：网页阅读（Jina，失败时直接读取）、直接读取（Readability 正文提取）、网页搜索（Exa 免密钥）、GitHub 仓库/Issue/PR 读取与仓库搜索、V2EX 主题/节点/热门。输出 `schema_version:1` 信封，raw 原样保留。
- 网络只在用户点击采集时发生；加载页面不访问外部网站。用户 URL 需通过公网检查：字面地址、DNS 解析结果和每次重定向；超时、5MB 上限、网页类型白名单；支持环境代理。
- 错误统一为 NOT_FOUND / BAD_INPUT / RATE_LIMITED / TIMEOUT / UPSTREAM_BROKEN / PLATFORM_BLOCKED / BLOCKED_ADDRESS / TOO_LARGE / UNSUPPORTED_TYPE / NETWORK，界面给出中文说明、错误代码、尝试记录与重试。
- 资料引用不可脱离原采集记录；URL 去除片段与 utm/fbclid 后去重，已有笔记不被覆盖；摘录必须是来源正文子串；单项目 100 来源 / 50 批 / 880KB。
- 自动保存完整工作副本：查询、收件区与勾选、每来源未完成摘录、未应用 JSON、模型概括草稿。导入总是新建调研，旧的未完成采集不重放。
- 导出：Markdown 报告、完整项目 JSON、原生结果 JSON。

## 可选

- Floatboat Host 模型概括：用户勾选来源并主动检查连接后生成带编号的草稿，手动插入研究小结并标注未经核对。Host 不可用时其余功能不受影响。

## 不做

需要登录、浏览器会话或账号复用的渠道（X、小红书、Reddit、YouTube 等）；绕过限流或平台验证；后台定时采集；渲染远程 HTML。
