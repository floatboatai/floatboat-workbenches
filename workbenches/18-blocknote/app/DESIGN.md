# 知识夹设计

主要使用者把会议决定、实践笔记和团队共识整理成能持续补充的知识页。主任务是写块、调整层次、勾选行动项，并在知识夹中找回页面。

首屏 P0 是可直接输入的 BlockNote 正文；P1 是标题、分类、自动保存状态和当前页面大纲；P2 是导入导出与恢复。采用装订知识夹：左侧细窄暖灰导航，正文暖纸张，无仪表盘或统计卡。顶部目录条固定操作，页面内使用墨绿主题标签、细分隔线、充足段落间距与衬线大标题；正文中文无衬线保证编辑可读性。与 Tiptap 单文稿的区别是块结构、知识页库、章节跳转与任务/表格。

状态：首次加载保留正文区域占位；空知识夹提供空白页和示例页；搜索无结果给出清晰提示；保存中仍可编辑；未完成导入源文保存在独立草稿区；离线、冲突和错误显示持久提示及重试/导出恢复/打开服务器版本。导入始终新建。

375px 时知识夹通过按钮展开，顶栏操作换行，正文留出块拖拽和菜单空间，表格在编辑器内部滚动。深色使用棕黑纸面和浅暖灰文字。所有控件有名称、可见焦点，按系统设置减少动效。不加载远程字体/媒体。

验收：原生标题、任务、嵌套、格式和表格；完整 JSON 保存；Markdown/HTML 导出与新建导入；自动保存延迟/失败/重试/冲突；桌面、窄屏、深色和 reduced-motion；实际截图复核。
