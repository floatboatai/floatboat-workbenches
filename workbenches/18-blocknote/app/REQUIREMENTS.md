# BlockNote 知识夹

为个人或团队整理实践记录、手册与会议知识。核心任务是用原生块编辑器编写正文、组织层级、勾选任务和维护简单表格，随后从知识页库找回内容。

## 已实现
- BlockNote OSS 0.56.0 原生可编辑组件，中文块菜单和选区格式工具；标题、段落、引用、无序/有序/任务列表、可折叠列表、嵌套块、表格与文字/链接格式。
- 独立页面标题、分类和摘要；搜索知识夹、实时章节目录、空白页和普通团队知识示例。
- 完整块 JSON 经 SQLite 持久化。自动保存不锁编辑器；同一 documentKey 维持编辑器实例。工作副本保留未完成导入源文、页面输入、离线和冲突状态，IndexedDB 同源恢复。
- JSON（含恢复工作副本）、Markdown、HTML 导入为新知识页，原页不覆盖；完整 JSON、BlockNote 原生 Markdown / HTML 导出，恢复文件包含未应用输入。
- 断网重试、冲突保护、恢复文件导出和显式打开服务器版本。

## 约束
- 仅使用 MPL-2.0 BlockNote OSS 包，不包含 XL、商业协作、AI、评论或高级布局。
- 支持文字知识页，无图片/视频/音频/文件块、远程媒体、执行代码、嵌入式网页或实时多人编辑。HTML 导入只保留白名单文字结构并去除脚本、样式与事件；链接限定 http/https/mailto，无自动外部请求。
- 1,200 块、8 层子块；每表最多 100 行 × 12 列，无合并单元格。标题 120 字符，分类 40，摘要 500；模型 700 KB。源文 180,000 字符，文件 700 KB；JSON 为保真格式，Markdown/HTML 是有损互操作。
- 本机缓存只适用于同一个浏览器源，不承诺跨端、跨预览端口恢复。源包不带用户预览数据。

## 验收
原生编辑与刷新恢复；延迟保存期间继续输入；提交后丢失响应的幂等重试；失败后恢复；无效源文恢复；导入新页；版本冲突与新标签页保护；新建离线草稿切换恢复；下载文件独立内容核验；1440/375、深色、reduced-motion、无页面溢出或脚本错误。
