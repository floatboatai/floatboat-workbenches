# Univer 表格工作台

用户处理预算、项目清单和日常计算。首屏主任务是直接编辑单元格、查看公式结果、调整数字与文本格式，并在多个工作表间切换。

## 页面与层级
- 根页面 App：紧凑文件条（工作簿名称、保存状态、文件操作）→ 可折叠导入/工作簿目录 → 原生 Univer 工具栏、公式栏、网格与底部标签。
- 网格占据主要空间，没有侧边统计卡或欢迎区。默认展示普通的社区工作坊预算，公式行和表头格式帮助识别计算关系。
- 未提交的原生单元格编辑使用独立恢复条：显示工作表/单元格、文本和“应用/放弃”。已提交数据与恢复文本不混为同一状态。

## 视觉
使用清晰的白色表面、墨绿色文件条标记、细灰色边框；系统中文无衬线，数字等宽。产品操作行 36–40px，表格保持原生密度。暗色模式使用 Host token 与 Univer 的暗色主题，单元格自定义样式保持可读。

## 状态
加载时保留文件条和进度说明；自动保存呈现待保存、保存中、已保存、草稿、离线、冲突。输入不因后台保存禁用。错误在来源区域展示并提供重试/导出恢复/服务器版本路径。导入错误保留原始文本，成功导入总是新建工作簿。

## 窄屏与可访问性
375px 文件操作折行。Univer 保持至少 780px 的操作宽度，由可聚焦且有名称的独立表格容器水平滚动，页面自身不溢出。文件工具与恢复输入适配视口。所有自有输入有标签、键盘焦点可见；遵守 reduced-motion。上游画布的读屏限制在 README 中说明。

## 验证顺序
1. 核实 OSS 包、导入 schema 与公式/文本语义。
2. 接入稳定的 Univer 实例与草稿保存契约。
3. 验证多工作表、格式、公式、CSV 与原生 JSON 的真实结果。
4. Chrome 验证保存重载、未完成输入、失败重试、并发冲突、375px/暗色与截图。
