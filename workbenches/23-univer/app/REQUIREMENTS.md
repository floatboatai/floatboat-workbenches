# Univer 表格工作台验收要求

服务于需要整理数据、预算计划和公式计算的个人用户。业务对象是工作簿、工作表、单元格、公式、格式和未提交输入。

- 使用 Apache-2.0 的真实 Univer Sheets 1.2.0 原生编辑器，支持单元格键盘编辑、公式计算、格式、工作表创建/切换/重命名/删除。
- 以网格、工具栏、公式栏和工作表标签为主体；中文文件操作；桌面与 375px 窄屏可用。
- 默认持久化完整原生 snapshot。后台 ACK 不改变编辑器实例，使用 documentKey 区分文档切换。
- 原生 SheetEditChanging 捕获当前单元格的未提交文本；重载后单独恢复，由用户应用或放弃，不直接覆盖已应用数据。导出前结束正在编辑的单元格并等待真实计算完成；恢复草稿需用户先明确处理。
- 原生 JSON 保存公式、样式、工作表和已计算值；CSV 仅输出当前表计算值，不包含公式源、格式或其他工作表。危险文本前加单引号。CSV 导入公式样文本保持文本，数字标识前导零不丢失。
- 导入总是新建工作簿，保留原工作簿与未完成的原始导入文本。明确报错并恢复无效导入。
- 支持保存失败/离线缓存、幂等重试、冲突保留、打开服务器版本及恢复草稿下载。
- 输入限制：850 KB / 8 张表 / 每表 2000 行和 200 列 / 合计 20000 个非空单元格。拒绝图片、外部链接和未知插件资源。
- 验证类型与构建、业务测试、真实 Chrome 公式/导出/持久化/失败状态、桌面暗色和 reduced-motion、无 body 横向溢出，提供真实截图与源代码包。
- 不实现商业 XLSX/PDF 交换服务、协作后端、图片资源或 AI。Floatboat Desktop 导入验收独立于本地成功。
