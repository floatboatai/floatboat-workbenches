# Univer engineering

`src/ui/App.tsx` owns the compact document actions and recovery/import surfaces. `SheetEditor.tsx` creates the OSS core preset exactly once per `documentKey`, keeps callbacks current through a ref, and disposes events, media/DOM observers and the Univer instance. Save acknowledgements do not remount the editor. All Univer SDK release packages are resolved at exact version 1.2.0 (upstream companion icons uses its independent 1.46.0 release); React is 19.2.3.

`contracts/workbook.ts` owns bounded native snapshot validation, CSV parsing, CSV-safe value export, input formula/text semantics, and the ordinary demonstration budget. Native inputs use Univer interpretation; explicit recovery strings use `inputCell`: `=` is formula, a leading apostrophe escapes literal text, strict decimal text becomes numeric, and leading-zero identifiers remain strings. CSV deliberately never executes formula-shaped text. Formula results come exclusively from the Univer engine. Export calls `endEditingAsync(true)` and then waits for the calculation-end success event before saving the snapshot. A workbook without formulas skips this wait because the engine reports NOT_EXECUTED. Document transitions use the same flush to preserve the last committed cell before leaving. JSON retains native `f`, `v`, styles and sheets. CSV uses cached calculated `v`, never substitutes formula source for missing output, and prefixes risky literal text to prevent downstream spreadsheet execution.

`SheetEditChanging` captures the sheet and coordinates plus plain text before commit. `SheetEditEnded` clears the extra draft and captures the applied model, including Esc cancellation. A restored draft is shown as a separate editable recovery bar; applying uses the native range API. Rich-text styling inside an unfinished cell draft is not preserved; its text is preserved, while committed rich-text formatting stays in the native snapshot. Native formula/format mutations and calculation-end events trigger snapshot capture. The current formula may be invalid as business input but still be a valid spreadsheet formula with an error result; it must not be rejected as an unfinished import.

`useWorkbenchState` provides 700 ms autosave and IndexedDB fallback, idempotent mutation replay, optimistic revision checks, raw extras, and document transitions. `routes.ts` only registers project CRUD and autosave; no unused model service or Host capability. `server/index.ts` uses the provided runtime and SQLite migrations 0001–0003 unchanged. Model validation is shared across browser and server. Engine snapshots are retained even when they exceed applied-model limits, so the server can preserve them as drafts; restoreDraftData accepts a bounded larger working copy (1.8 MB) with permissive business counts. Requests exceeding the shared 1.95 MB envelope stay in local recovery and display an error rather than claiming an applied save. The model cap is 850000 bytes, below the shared 900000 project cap; imported raw source is also capped at 850000 bytes, keeping combined working copies below the 1950000 request envelope. Native imported files are decoded to durable JSON; binary originals are not required and no user resource files are stored. The licenses directory is a declared project asset so upstream Apache-2.0 and icon MIT notices are included in the source package.

All dependency code is bundled by the official template profile. No remote scripts, CDN fonts, workers, or paid `@univerjs-pro` packages are used. Background images, drawing data, rich-text hyperlinks and unknown resources are rejected before engine creation. Only core preset resource identifiers are accepted; serialized resource data is parsed and bounded. External JSON is never cast before structural/size validation. The app has no external service calls or active Host SDK feature.

The narrow-screen grid preserves a 780 px minimum inside an independently scrollable, named region; file and recovery controls remain within 375 px. Native canvas has upstream screen-reader and touch limitations; no full screen-reader spreadsheet equivalence is claimed. OS dark preference is passed to the native theme and Host theme attributes are observed.

Commands from `workbenches/23-univer`: `pnpm workbench:check`, `pnpm test`, `pnpm dev -- --no-watch`. Source packaging runs from repository root with `pnpm workbench package univer`. Browser scripts/results and downloaded files stay in ignored `.cache/`; final evidence is summarized in README. Floatboat import remains unverified.
