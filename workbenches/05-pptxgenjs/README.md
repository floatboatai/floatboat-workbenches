# 演示编排室

当前版本：**0.9.1**（重建为真正的演示编辑器）。

母版版式 + 原生对象的 PPTX 编辑器：在缩略轨里选页、在舞台上放置与编辑文字/图片/表格/图表/形状、套用品牌主题、写演讲备注，再导出可在 PowerPoint / Keynote / WPS 中继续编辑的 `.pptx`。舞台预览与导出共用同一份几何（百分比坐标 × 英寸尺寸）、字号（pt）、颜色角色和母版定义。

![演示编排室](../../docs/screenshots/pptxgenjs.png)

## 能做什么

- **10 种版式，导出为幻灯片母版**：标题页、章节页、标题+内容、双栏、对比、图文、引用、图表、表格、空白（`defineSlideMaster`，标题/正文等为真正的 PPT 占位符；切换版式时占位迁移）。
- **元素**：富文本（加粗/斜体/下划线/主题颜色/超链接/项目符号与缩进，双击就地编辑）、图片（上传后存入本应用媒体库，超过 2400px 或 1.4 MB 自动缩放/转码，原始文件上限 30 MB）、可编辑表格（标题行、镶边行、增删行列）、原生图表（柱形/折线/面积/饼图/环形，系列与分类数据表、图例、数据标签）、形状（矩形、圆角矩形、椭圆、三角形、右箭头、直线，可带文字）。
- **舞台操作**：选择、拖动、八向缩放、吸附（页边、中线、版心、其它元素边线；Alt 关闭）、方向键微移、复制/粘贴/复制元素、层级调整、删除、撤销/重做；缩略图拖动或 Alt+方向键排序；隐藏页；放映模式。
- **主题**：6 个预设 + 六个品牌颜色角色（背景/面板/正文/次要/强调/辅助）+ 标题/正文字体 + 16:9 / 16:10 / 4:3（`defineLayout`）。元素引用颜色角色，换主题整体换色。
- **文件**：自动保存；「文稿」菜单中新建空白/示例、最近文稿、导入/导出项目 JSON（含图片数据，导入总是新建文稿；兼容 0.3.0 旧格式）、导出恢复草稿、删除。
- **AI 大纲（次要）**：需要 Floatboat Host；未连接时面板内显示状态卡与「重新检测」，其余功能不受影响。候选稿先预览、确认后替换页面并保留主题。

首次打开即为 10 页示例文稿《华东区门店 Q3 运营复盘》，覆盖全部版式、两种图表、表格、图片、形状与超链接。

## 使用与验收

在总仓库执行 `pnpm workbench prepare pptxgenjs`，然后 `node scripts/workbench.mjs check|test|package pptxgenjs`。打包文件在 Floatboat → My → Workbenches → Import workbench 导入，默认不含预览数据。

2026-10-29 验收见 [app/ACCEPTANCE.md](app/ACCEPTANCE.md)：20 项单元/集成测试（含真实 PptxGenJS 导出并解包校验页数、母版、图表、媒体、超链接、备注）；Chrome 1440/375 完整编辑流程、自动保存契约、导出文件内容校验；Floatboat 真实 Host 生成大纲。

## 边界

- PPTX 不嵌入字体；接收方缺少字体时由演示软件替代。超链接颜色在部分 PowerPoint 版本中按主题超链接色显示。
- 舞台图表是 SVG 近似预览，坐标轴刻度由 PowerPoint 自行计算，可能与预览略有差异；macOS 快速查看不渲染图表对象（上游示例同样如此）。
- 不支持动画、切换效果、视频、PPTX 反向导入、多选与旋转；表格不支持合并单元格。
- 被移动的标题/正文不再绑定母版占位符（导出为普通文本框），以保证位置一致；此时 PowerPoint 编辑视图会显示该母版的空占位提示（放映不可见）。
