# 演示编排室设计

深色演示工作面、橙色导出动作和活动页框。横向缩略片带组织页序，中央 16:9 舞台预览，编辑字段在舞台下方；375px 缩略片自身横向滚动、表单上下堆叠。与连续写作及毫米纸张设计采用不同空间组织。

首屏优先主编辑任务和保存/导出。加载、未保存、保存中、生成中、错误及待采用均有文字状态。原生控件提供标签和可见焦点，正文有 skip link；删除/替换需确认、未保存离开警告。支持 reduced-motion、安全区与长内容换行。

React Best Practices 应用于条件加载和稳定编辑器初值；Web Design Guidelines 用于语义、键盘、表单、错误状态和触摸布局。桌面/375px 真机浏览器截图检查通过，窗口无横向溢出。Chrome 1440px/375px 添加/删除/排序→保存刷新恢复→PPTX/JSON 导出。解压验证 3 页 OOXML 顺序、中文正文和备注。LibreOffice 能打开并转 PDF；渲染验收使用 Noto CJK 替代 Microsoft YaHei。
