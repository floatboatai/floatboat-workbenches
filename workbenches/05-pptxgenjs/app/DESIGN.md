# 演示编排室 · 设计（0.9.0）

## 用户与主任务

做周报、季度复盘、销售方案的业务人员与运营分析师。他们要的是一份**能直接在 PowerPoint / Keynote / WPS 里继续编辑的 PPTX**，而不是一张图片。P0：**选版式 → 在舞台上放置与编辑文字、图片、表格、图表、形状 → 套用品牌主题 → 写演讲备注 → 导出 PPTX**。用户对象是“演示文稿”，内部仍存为 project。

舞台预览与导出共用同一套几何（百分比坐标 × 幻灯片英寸尺寸）、字号（pt）、颜色角色与版式母版定义，所以舞台上看到的位置、字号、配色、表格和图表类型就是 PPTX 里的样子。

## 首次使用

空数据目录打开即看到一份 10 页的示例文稿《华东区门店 Q3 运营复盘》：标题页、章节页、柱状图、富文本要点（加粗/强调色/超链接）、门店指标表、双栏（含环形图）、对比、图文（自带门店插画）、引用、自由放置的行动路线（形状 + 箭头）。第一屏就是舞台，单击即可选择元素、拖动、缩放、双击改字。无需 Floatboat Host；只有“AI 大纲”依赖 Host 模型。

## 继续上次工作

刷新或重开时恢复最近的工作副本（含尚未通过校验的图表单元格、空字体名等未完成输入）。左上「文稿」菜单列出最近文稿与本机草稿，点击即切换；切换期间工作区 inert。

## 导入与恢复

- 「文稿 → 导入项目 JSON」：接受本应用导出的项目包（含图片数据）以及 0.3.0 旧格式（标题/页眉/要点），旧格式自动转为“标题 + 内容”版式。导入总是 `replace()` 另建新文稿，不覆盖当前文稿。图片先上传为本应用自有的媒体，再创建文稿。
- 「导出恢复草稿」处理完整工作副本；版本冲突时提供“打开服务器版本”。

## 空间关系

```
┌ 文稿▾ │ 文稿名称 │ 自动保存（小字） ─────── 撤销 重做 │ 放映 │ AI 大纲 │ 导出 PPTX ┐
├ 缩略轨 ┬──────────── 插入：文本 图片 表格 图表 形状▾ ─────────────┬ 检查器 ─────┤
│ 01 ▢  │                                                          │ 元素│页面│主题│
│ 02 ▢  │                 幻灯片舞台（深色桌面，按比例）              │ 位置/尺寸    │
│ …     │       选择框、8 向手柄、吸附参考线、双击就地编辑富文本      │ 文字/图表数据│
│ ＋版式 │                                                          │ 表格网格     │
│       ├──────────────── 演讲备注 ───────────────────────────────┤ 层级/复制/删除│
└───────┴──────────────────────────────────────────────────────────┴──────────────┘
```

- **主工作区**：舞台占中间约 60% 宽，深色桌面衬托幻灯片；插入工具条贴在舞台上沿；演讲备注贴在舞台下方。
- **上下文工具**：右侧检查器随选择切换——元素（位置尺寸、文字格式、图片适配与替换文字、表格网格、图表类型与数据表、形状填充/线条）、页面（版式、隐藏页）、主题（预设、六个品牌颜色角色、标题/正文字体、16:9 / 16:10 / 4:3）。
- **文件生命周期**：新建、最近文稿、导入/导出项目 JSON、立即保存、恢复草稿、删除全部在「文稿」菜单；不再有常驻的项目选择器与按钮排。
- **主业务动作**：「导出 PPTX」是唯一实色按钮；「AI 大纲」为次要按钮，Host 未连接时在其面板中显示状态卡（原因、启动方法、重新检测），其余功能不受影响。

## 视觉

暗色制作台：墨黑背景（#121417）、炭灰面板、细 1px 分隔线；幻灯片本身完全由文稿主题决定。强调色琥珀（#f0a35a）只用于选中、主按钮与吸附参考线（品红 #ff4fa3，确保在任何主题上可见）。界面字号 12–13px，数字 tabular。缩略轨 168px，检查器 300px。

## 关键状态

- 未完成输入：图表单元格写成非数字、字体名为空、链接不是 http(s)/mailto → 状态显示“草稿已自动保存，待完善输入”，刷新后原样恢复，正式模型不变；检查器在对应格子标红。
- 图片：上传前在浏览器内解码，超过 2400px 或 1.4 MB 自动缩放/转码；原始文件上限 30 MB；格式不支持时说明原因。缺失的媒体会让保存进入草稿而不是生成坏文件。
- 导出：生成中按钮显示进度文字；失败时说明原因，内容不丢失。
- AI 大纲：离线状态卡；生成稿停留在待采用区，确认后只替换页面、保留主题。

## 交互

单击选中，Shift 无吸附细调用 Alt；拖动吸附到页边、中线与其它元素边线；方向键微移 0.5%（Shift 5%）；⌘/Ctrl+D 复制，Delete 删除，⌘/Ctrl+Z / ⇧⌘Z 撤销重做，⌘/Ctrl+] / [ 调整层级，⌘/Ctrl+S 立即保存，Esc 取消选择或退出编辑。快捷键只在编辑区域内生效，不注册全局监听。缩略图可拖动排序。

## 窄屏（375px）

顶栏保留「文稿」、名称与「导出」；缩略轨变为舞台上方的横向条；插入工具条横向滚动；检查器移到舞台下方；备注在最后。拖动/缩放使用 Pointer Events，触屏可用。

## 可访问性

所有控件有可见标签或 aria-label；舞台元素可 Tab 聚焦并以键盘移动；菜单 Escape 关闭并把焦点还给「文稿」；保存状态 `role=status`，错误 `role=alert`；尊重 reduced-motion。

## 与相邻工作台的差异

reveal.js 是“横向页带 + 排练台”，面向网页演示；Presenton 以资料简报驱动生成；Fabric.js 是单张海报画板。演示编排室的核心是**多页 PPTX 的母版版式 + 原生图表/表格对象**，所以缩略轨、母版版式选择和图表数据表是一等公民，舞台与 PPTX 共享同一几何。
