# 演示编排室需求与验收

主流程：逐页编辑标题、页眉、要点与演讲备注 → 添加/删除/前后排序 → 三主题舞台预览 → 保存恢复 → 真实 PPTX 下载。JSON 可导入恢复。AI 大纲先预览、确认后采用。

边界：1–30 页、唯一页面 ID，标题 1–80 字、页眉 60 字、备注 4000 字。每页最多 7 个要点，每行约 35 个汉字/70 个英文字母，超限需缩短。当前为标题+要点版式，无图片、动画、自由拖放或 PPTX 反向导入。PPTX 不嵌入字体，接收端需要中文字体。 持久化项目最多 900 KB，导入在验证后才替换内容。删除和覆盖未保存内容需确认，保存采用版本号防止覆盖另一窗口更新。

2026-10-27 已通过：5 项业务/数据库测试；Chrome 1440px/375px 添加/删除/排序→保存刷新恢复→PPTX/JSON 导出。解压验证 3 页 OOXML 顺序、中文正文和备注。LibreOffice 能打开并转 PDF；渲染验收使用 Noto CJK 替代 Microsoft YaHei。

真实 Floatboat llm.generateText 返回 3 页中文大纲并停留在待采用区，未自动替换页面。另明确注入 HTTP 503 验证输入与页面保留；失败注入与真实 Host 成功分开记录。 尚未验收导出包导入客户端的安装流程。
