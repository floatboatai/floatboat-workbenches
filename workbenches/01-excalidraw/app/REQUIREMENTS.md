# 白板工作台

面向整理流程、讨论方案和绘制草图的人。主任务是创建画布，编辑并保存，稍后重新打开或导出交付图像。

## 对象与范围

- 画布：标题、Excalidraw 场景、图片、保存版本、更新时间。
- 本地创建、搜索、打开、重命名、保存、删除。删除与放弃未保存修改需确认。
- 导入 `.excalidraw`/JSON，新建独立画布；导出源文件、PNG、SVG。
- 通过 Floatboat Host 的 LLM 将描述生成节点和连接，追加到已有画布，保留人工编辑和保存步骤。
- 服务未连接或模型失败时显示明确错误，保留输入与现有内容。

## 验收

1. 真实浏览器绘图并保存，刷新和服务重启后可以恢复。
2. 两个窗口修改同一版本时返回冲突，不能静默覆盖。
3. 非法/过大的文件被拒绝，正常图像和中文内容保留。场景上限 1.5 MB；编辑器中的未保存内容仍可导出。
4. PNG/SVG/源文件包含实际图形，生成图形可以继续编辑。
5. 375px/1440px、深浅主题、键盘及 reduced-motion 可完成关键操作。
6. 类型检查、业务测试和源包导出通过；实际 Host 模型调用与 Host 导入结果分开记录。

## 自动保存

编辑后 700ms 防抖自动保存，提交串行且不锁定输入；IndexedDB 暂存、SQLite 工作草稿与合法项目分别保存。无效输入仍保留为草稿，网络失败和版本冲突明确提示并可导出恢复文件。导入创建新项目，打开/新建先同步旧草稿，只有需要放弃未同步内容时才确认。本项目覆盖画布场景与 AI 描述。自动保存回执不得重建重型编辑器；只有切换文档或重新打开才重建。
