# 白板工作台设计

## 主任务

用户创建画布并直接绘图，明确保存状态，随后继续编辑或导出交付。画布是主操作区，项目目录属于辅助导航。

## 空间与视觉

- 采用画布主导布局，文件栏可收起；顶部只保留标题、保存、生成与导出。
- 首屏留出宽阔空间，用简单手绘流程示意任务，避免统计卡和仪表盘结构。
- 文件区域使用柔和绿色、纸张白和低对比边界；画布保留 Excalidraw 自身的编辑工具。主题色来自公开 workbench tokens，深色模式提供独立表面色。
- 文档名和项目列表使用紧凑字号，欢迎区有较大的排版层级。长名称省略，完整名称可在标题输入框查看编辑。
- 这是白板的布局选择，不作为其他工作台的视觉模板。资料脑图、单据版式、数据分析分别重新选择交互布局。

## 状态与可访问性

显示加载、空列表、无搜索结果、未保存、保存中、冲突、生成中、模型失败。放弃修改和删除前明确确认。

使用原生控件、标签、可见焦点、跳过导航链接。装饰图标对读屏隐藏；新建表单支持 Escape。移动端新建不抢占键盘，375px 使用项目列表与画布切换。

宽屏 1440px、窄屏 375px、深浅色、reduced-motion 均以真实浏览器检查。上线前使用仓库 Vercel React 与 Web Design 两个 skill 复核。

## 原生画布布局修订

去掉常驻260px文件侧栏和展示性欢迎页。画布区域保留Excalidraw原生工具，外层只占48px文件条；目录为按需浮出的项目框，打开后可Escape收起。保存、导出、适应画布和删除收在文件菜单，AI输入是按需面板。空状态只有新建/打开操作，不放假图。移动端同样保留原生画布，文件目录不再替换整个主区域。
