# 数据流水线（React Flow）

本地数据流水线 IDE，基于 @xyflow/react 12.12.0。上游：https://github.com/xyflow/xyflow。

![数据流水线](../../docs/screenshots/react-flow.png)

## 能做什么

把 CSV、日志或 JSON 放进输入节点，从左侧节点架拖入变换节点并连线，每个节点上直接显示运行状态、耗时、行列数和结果预览，最后在表格/柱状图里查看结果或下载 CSV/JSON/TXT。

- 20 种节点：文本/CSV/JSON 输入；文本处理、按行拆分、正则提取与替换、模板填充、JSON 路径取值、筛选（条件构建器，符合/其余两路）、字段映射、排序、去重、分组汇总、关联两表、合并追加；文本/表格预览、柱状图、下载文件。
- 带类型的多端口（文本 / 表格 / JSON，颜色区分），连接时校验类型和回路；支持分支与合并的 DAG，拓扑执行，环和失败钉在对应节点，其它分支继续。
- 在浏览器 Worker 中确定性执行，不联网、不使用 `eval`/`new Function`；正则静态拒绝嵌套量词，单节点超过 5 秒自动终止。
- 画布：拖放添加（也可点击或把数据文件直接拖到画布）、Delete/Backspace、框选、复制/粘贴/复制一份、撤销/重做、MiniMap、Controls、dagre 自动布局、尺寸变化自动适应。检查器可按端口选择来源，窄屏不依赖拖拽。
- 「文件」菜单：空白、模板库（订单 CSV 清洗与按地区汇总、日志提取错误码统计、接口 JSON 转逾期提醒、两月订单合并对账、关键词清单去重排序）、导入/导出流水线 JSON（导入总是另建新文件，兼容 0.3 单链配置）、恢复稿、删除。自动保存遵循仓库契约。
- AI 起草（需要 Floatboat 模型）生成候选流水线，采用前不覆盖画布；未连接时显示状态卡，其余功能不受影响。

## 运行

总仓库：`pnpm workbench prepare react-flow` → `pnpm workbench dev react-flow`。测试：`pnpm workbench test react-flow`。打包：`pnpm workbench package react-flow`，在 Floatboat「我的 → 工作台 → 导入工作台」使用源包。

## 验收与限制

0.9.0 的命令结果、真实浏览器流程（含下载文件内容核对、正则超时、导入另建、自动保存延迟/回包丢失/草稿恢复、375px）见 [app/ACCEPTANCE.md](app/ACCEPTANCE.md)。主要限制：输入数据随流水线保存（单节点 600,000 字符、项目 900 KB）；检查器表格最多渲染 500 行；没有计算列表达式；本轮未做真实 Host LLM 调用与客户端导入验收。

第三方许可见 [NOTICE.md](NOTICE.md)。
