# 数据流水线（React Flow）需求

## 主任务

把 CSV、日志文本或 JSON 放进输入节点，用可视化节点完成清洗、变换、汇总，在节点上直接看到每一步的结果，最后得到表格、柱状图或下载的 CSV/JSON/TXT 文件。全部在本机完成：不联网、不执行任意代码、结果确定。

## 节点（20 种，带类型端口：文本 / 表格 / JSON）

- 输入：文本、CSV（粘贴或上传，自动识别分隔符，引号/引号内换行/BOM，数字识别保留前导零）、JSON。
- 变换：文本处理（大小写/去空白/前后缀）、按行拆分、正则提取（命名分组成列，文本或表格某列）、正则替换、模板填充 `{{字段}}`/`{{#}}`、JSON 路径取值（`$.a.b[0]`、`[*]` 展开，可转表格）、筛选行（条件构建器：全部/任一，13 种比较，符合与其余两路输出）、字段映射（重命名/挑选/类型转换/模板生成新列）、排序（多列，空值总在最后）、去重（按列，保留首条/末条）、分组汇总（计数/求和/平均/最值/去重计数）、关联两表（内/左连接）、合并追加（表格并集或文本拼接，可加来源列）。
- 输出：文本预览、表格预览、柱状图、下载文件（CSV 带 BOM、JSON、TXT）。

## 执行

- 有向无环图：分支、合并、多输出端口；Kahn 拓扑排序，同层按画布位置；环检测把错误钉在环上节点，下游标记跳过，其它分支照常运行。
- 连接时校验端口类型、单输入、不成环；运行时再次检查类型与缺失端口。
- 每个节点记录状态、耗时、摘要与预览；错误钉在失败节点；节点签名只让改动节点及下游显示“过期”。
- 在浏览器 Worker 中执行，单节点超过 5 秒终止 Worker 并把超时钉在该节点；正则先经静态检查拒绝嵌套重复量词，标志仅限 i/m/s/u。
- 规模：单表 200,000 行、500 列；文本 5,000,000 字符；单个输入节点内联 600,000 字符（随流水线保存，受项目 900 KB 上限约束）；最多 80 节点 / 160 连线。

## 编辑

节点架拖放（`screenToFlowPosition`）或点击添加；把 CSV/JSON/日志文件拖到画布生成输入节点；Delete/Backspace、Shift 框选或框选模式、⌘/Ctrl+C/V/D、撤销/重做、MiniMap、Controls、dagre 自动布局、容器尺寸变化时自动适应。检查器按端口选择来源（键盘与窄屏连线方式）。自动运行可关闭；“运行”把小预览记录进流水线。

## 文件与自动保存

文件菜单：空白流水线、模板库（5 个示例）、导入流水线 JSON（另建新文件，兼容 0.3 单链与恢复稿）、导出流水线 JSON、下载恢复稿、删除。自动保存遵循共享契约：编辑后防抖保存、提交不锁输入、名称为空等无效内容保存为草稿并可恢复、网络失败/冲突明确提示。AI 起草（Host LLM）生成候选流水线，采用前不覆盖画布，未连接时显示状态卡。
