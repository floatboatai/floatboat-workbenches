# 数据流水线工作台设计（0.9.0）

## 用户与主任务

运营、分析和工程同学手里有一段 CSV、一份日志或一个接口返回的 JSON，需要**清洗 → 变换 → 汇总 → 拿到结果文件**，又不想写脚本。P0 是：把数据放进输入节点 → 从节点架拖入变换 → 连线 → 每个节点立刻显示行数、耗时和预览 → 在输出节点看表格/柱状图并下载 CSV/JSON。

用户对象是**流水线**（`.pipeline.json`，内部存为 project）。执行完全在本机浏览器 Worker 中完成：没有网络请求、没有 `eval`/`new Function`，每种操作都是带类型的纯函数，结果确定可复现。

## 首次使用

空数据目录打开即是“订单 CSV 清洗与按地区汇总”：10 月订单 CSV 经过筛选（剔除取消与零数量，其余行流向“被剔除的订单”）、按订单号去重、按地区汇总，分叉到柱状图、汇总表和 CSV 下载。页面打开后立即在 Worker 中运行一次，每个节点上已经有“✓ <1 ms · 17 行 × 8 列”与预览，无需创建项目即可编辑。首次编辑后自动保存为新流水线。模板库还有“日志提取错误码统计”“接口 JSON 转逾期提醒”“两月订单合并对账”（含关联两表）“关键词清单去重排序”。

## 继续上次工作

刷新或重开时自动恢复最近的工作副本（含校验未通过的草稿、AI 提示词与候选稿）并静默重算一次。左上「文件」打开文件面板：最近流水线（含“本机草稿”“草稿”标记）、新建空白、从模板新建、导入、导出、下载/导入恢复稿、删除。

## 导入与恢复

- 「文件 → 导入流水线 JSON」：校验后用 `replace()` 另建新流水线，不覆盖当前文件；旧版 0.3 单链文件（input/uppercase/prefix/output）自动转换成新节点。
- CSV/JSON/文本输入节点可在检查器“从文件载入”，或把文件直接拖到画布上生成对应输入节点。
- 冲突时自动保存状态提供“打开服务器版本”和“导出恢复草稿”。

## 空间关系

```
┌ 文件▾ │ 流水线名称 │ 自动保存（小字） ─────── 模板库 │ AI │ 自动运行☑ │ ▶ 运行 ┐
├ 节点架 ┬──────────────── 画布（主区 ≥ 60%） ────────────┬ 检查器 ─────────┤
│ 输入   │  [节点]─表──▶[节点]─表─▶[输出·柱状图]          │ 配置 │ 输出      │
│ 变换   │     ╰─文本──▶[节点]  节点上：状态·耗时·预览     │ 端口来源选择    │
│ 输出   │  工具：整理布局 / 框选 / 撤销重做 / 适应 / 小地图 │ 条件/字段编辑器 │
├────────┴── 运行控制台（默认收起成一行摘要，可展开） ─────┴─────────────────┤
```

- **主工作区**：React Flow 画布占满中间；节点本身就是结果面板（状态徽标、耗时、行列数、表格前 3 行/文本首行/迷你柱状图），失败节点红框并在节点下钉住错误。
- **上下文工具**：选中节点上方 `NodeToolbar`（复制、删除、查看输出）；画布左下 Controls + 整理布局 + 框选切换，右下 MiniMap。
- **检查器**：配置页按操作类型给出专用编辑器（条件构建器、字段映射表、聚合列表、正则测试提示），每个输入端口一个“来源”选择器（键盘与窄屏连接方式）；输出页展示完整结果（表格最多渲染 500 行）并可下载该节点的 CSV/JSON。
- **按需信息**：运行控制台默认收起为一行（“9 个节点 · 全部成功 · 18 ms”），展开后是逐节点日志，点击跳到节点。文件、模板库、AI 是对话框。

## 视觉

深石墨画布 + 细点阵，节点为 224px 卡片。类别色只用于节点顶部细条：输入青绿、变换钢蓝、输出琥珀。端口按**数据类型**着色并标注：文本 `T` 沙黄、表格 `▦` 青色、JSON `{}` 紫色——连线颜色跟随源端口类型，类型不符时连接被拒绝并提示。状态：成功绿、失败珊瑚红、跳过灰、过期（配置已改未重算）虚线。数字用等宽 tabular。顶栏 44px、12px 按钮、4px 圆角，唯一实色主按钮是“运行”。

## 关键状态

- 运行中：节点逐个点亮“运行中”；超过 5 秒（如灾难性回溯正则）终止 Worker，把超时钉在当时执行的节点。
- 环、端口缺失、类型不匹配、正则不安全/无效、JSON 解析失败：错误钉在对应节点，下游标“跳过”，其它分支继续执行。
- 配置改动后：自动运行开启时 400ms 后重算；关闭时受影响节点及下游显示“过期”。
- 自动保存：idle/pending/saving/saved/draft/offline/conflict 以小字显示在名称旁；⌘/Ctrl+S 立即保存。

## 窄屏（375px）

顶栏保留「文件」、名称、运行；节点架折叠为“＋ 节点”按钮弹出的列表（点按即在视口中心添加）；画布高 56vh，下面依次是检查器与控制台。容器尺寸变化时自动 `fitView`。连线可完全通过检查器的“来源”选择器完成，不依赖拖拽。

## 可访问性

所有控件有标签；首个 Tab 为“跳到检查器”；节点可 Tab 聚焦，Delete/Backspace 删除，⌘/Ctrl+C/V/D 复制粘贴复制，⌘/Ctrl+Z / ⇧⌘Z 撤销重做，⌘/Ctrl+Enter 运行；对话框为原生 `<dialog>`，Escape 关闭并把焦点还给打开按钮；运行状态 live region；尊重 reduced-motion。

## 与相邻工作台的差异

LogicFlow 是“流程图纸 + 条件连线”的业务流程绘图，不执行数据；LangGraph 是三站 AI 复核流程；CircuitJS 是电路画布 + 仪表。本工作台的核心是**带类型端口的数据 DAG + 节点上的真实运行结果**，所以结果直接长在节点上、端口按数据类型着色，检查器同时承担配置和完整输出两种视角。
