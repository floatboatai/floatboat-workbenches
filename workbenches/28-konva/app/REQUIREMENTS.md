# Konva 标注画板 · 0.6.0

用户通过原生 Konva 画布对包装、图片和标签做可编辑标注。支持创建矩形、纯文字、箭头、PNG/JPEG 原图，选择与拖动，Transformer 缩放/旋转，精确属性和层序。允许空画板。删除对象需确认。

画板模型、标题、JSON 源码草稿和未应用属性自动保存。新建、打开与导入先同步锁住编辑器，再等待旧工作稿安全离开。正常后台保存允许继续编辑。冲突保留两份内容并提供服务器版本和恢复稿。恢复文件 cacheValue.snapshot 可以导入为新项目。

原图在 originals 数据资源内按 SHA-256 持久化；完整工程 JSON 包含原图 base64，可在新实例逐张写入并验证哈希后恢复。恢复稿只包含引用，跨实例需用完整工程或重新附加原图。导出 PNG 为原画板尺寸，隐藏选择控制点。支持 200–2400px 画板、最多 200 个对象、每张图 750 KB、1600 万像素；工作稿约 1.9 MB、正式模型 850 KB。

不声称 Polotno、任意 Konva JSON 或 SVG 编辑兼容；不包含滤镜、自由画笔、多选、团队协作和历史撤销。Floatboat 客户端导入独立标记 unverified。
