# ComfyUI 工作台 设计

方向：AI 视觉生成 · 节点画布 + 运行台。设计隐喻是**暗室**：画布是暗室工作台，生成结果像冲洗出的联系印样排在底部。

## 用户与主任务

用户是在自己的 ComfyUI 服务上调试出图流程的人：搭节点、改参数、检查连线是否完整，然后排队运行，对比几张结果，把满意的那次连同参数一起留住或重新载入。

最高频动作：改一个参数 → 运行 → 看结果 → 再改。成功状态：画布上的工作流校验通过，运行结束后底部印样带出现新图，并且能随时“载入这次的工作流”。

## 首次使用

1. 打开即看到完整的 SDXL 文生图图（检查点 → 两个 CLIP 文本编码 → 空潜空间 → KSampler → VAE 解码 → 保存图像）。无需任何服务就可以平移缩放、改提示词、校验、导出 UI/API JSON。
2. 运行按钮旁的连接芯片显示“未连接”。点它在右侧运行面板里填写 ComfyUI 地址、检查连接；成功后节点库换成该服务的 `/object_info`（含自定义节点）。
3. 没有服务时，运行区给出精确的启动命令和“只看不跑”的说明，不出现原始 fetch 错误。

## 继续上次工作与导入恢复

- 工作副本在第一次编辑（或第一次运行前）自动创建；之后每次画布变化（视口位置随其一并写入 `extra.ds`）都会自动保存完整工作流，并在状态条里安静地显示“已保存 / 待保存 / 草稿 / 冲突”。
- “工作流”菜单（左上角名称）是文件入口：新建、模板（文生图、图生图、放大、LoRA、局部重绘、ControlNet）、最近打开、导入（UI JSON / API JSON / 带元数据的 PNG）、导出（UI JSON / API JSON；带元数据的 PNG 与 ZIP 在印样带下载）、删除。内部 projects 表不出现在界面里。
- 导入永远新建文稿，旧文稿不被覆盖。未完成的导入文本保存在草稿中，刷新后仍在。

## 空间关系（桌面 1440×900）

```
┌ 工作流名 ▾  ↶ ↷  ⚠ 2 个问题  ·  ○ 本地 ComfyUI · 已连接     [▶ 运行 ⌘↵]   已保存 ┐
│┌库┐ ┌──────────────────────────────────────────────────┐ ┌ 检查器/运行 ┐│
││搜││ │              全幅节点画布（点阵暗底）               │ │ 选中节点/队列 ││
││类││ │  ● checkpoint ─ ● clip ─ ● ksampler ─ ● decode ─ ● save │ │ 进度 · 问题   ││
││别││ │  [缩放 ⌖ 适合]                         [小地图]    │ └─────────────┘│
│└──┘ └──────────────────────────────────────────────────┘                  │
│ 印样带：▢ ▢ ▢ ▢ ▢   最近一次 12.4 s · seed 482…  [对比] [载入工作流] [下载] │
└──────────────────────────────────────────────────────────────────────────┘
```

- **画布是主体**，占满工作区；其余全部是可收起的边缘层。
- **左侧节点库**（收起为 40px 图标轨）：搜索 + 分类树；也可双击画布空白处弹出就地搜索，或从连线端点拖到空白处按类型筛选。
- **顶部工作流条**：名称与文件菜单、撤销/重做、问题计数（点开列出并定位）、连接芯片、运行按钮（主操作，琥珀色），保存状态安静放在右端。
- **右侧浮层**：按需出现，选中节点时显示检查器（标题、模式：运行/静音/绕过、参数、此节点的校验与服务端错误）；点连接芯片或运行时显示运行面板（连接设置、进度、队列、问题）。
- **底部印样带**：每次运行一格缩略图（含状态角标），展开后是对比台（2–4 张并排）、参数表和导出。
- **运行进度**：正在执行的节点描边为琥珀色并带进度条；顶部运行按钮变为总进度条与“中断”。

## 窄屏（375px）

阅读/运行模式：顶部条保留工作流菜单、撤销/重做、节点搜索、问题计数与运行按钮；底部三标签 **画布 / 运行 / 图库**。画布可平移缩放、点选节点、直接点击节点上的参数控件编辑；节点库不占屏，改由工具条里的“搜索并添加节点”弹出就地搜索。“运行”标签合并连接设置、运行进度、问题与服务端队列；“图库”标签是印样带加大图、参数表和下载/复现入口。右侧检查器与小地图只在桌面宽度出现；复杂连线编辑不是窄屏目标。

## 视觉

- 背景三层：画布 `#11141a`（点阵 `#1c212b`）、边缘面板 `#171b23`、浮层 `#1d2230`；文字 `#dbe0ea` / 次要 `#8993a8`。
- 琥珀 `#f0b24a`（安全灯）只用于运行、进度、选中连线；错误 `#ef6a6a`；完成 `#56c28a`；缓存 `#6fb4ee`。
- 插槽/连线按数据类型着色（MODEL 紫、CLIP 黄、VAE 红、LATENT 粉、CONDITIONING 橙、IMAGE 蓝、MASK 绿）。
- 界面文字为系统无衬线，数字使用等宽数字；JSON、ID 用等宽。
- 动效仅用于运行状态与面板进出，遵循 `prefers-reduced-motion`。

## 状态

| 状态 | 表现 |
| --- | --- |
| 空画布 | 提示“双击画布搜索节点，或从工作流菜单选择模板” |
| 无服务 | 内置核心节点快照；运行区显示启动命令；其余功能可用 |
| 连接中 / 失败 | 状态卡片带原因（拒绝连接、超时、401/403）与重试 |
| 校验问题 | 节点红色描边 + 顶部计数 + 问题列表（点击定位） |
| 排队 / 运行 / 完成 / 出错 / 中断 | 节点描边、总进度、印样格角标 |
| 服务端 node_errors | 映射到对应节点与输入，列表标注“服务端” |
| 保存 | 待保存 / 保存中 / 已保存 / 草稿 / 离线 / 冲突，文字 + role=status |

## 与近邻工作台的结构差异

- glTF Transform：浅色三维陈列 + 底部材质带 + 浮动检查器。本工作台是深色节点画布，底部是**按运行生成的结果带**而不是资产带，左侧有节点库轨。
- Bruno：集合树 + 请求编辑 + 响应控制台的三栏。本工作台没有固定三栏，画布全幅，其余为浮层。
- FigCraft：画板序列与文案复核。本工作台的主对象是有向图，交互是连线与参数，而非画板内容。
