# 光路实验台运行

本工作台使用本地 CPU 与 SQLite，不需要模型、Python 服务、WebGPU 或网络。首次导入源码包后由 Floatboat 按锁定依赖构建。

打开即是可拖动的凸透镜演示，光线随拖动实时重绘。左侧器材架点击放入元件，右侧检查器修改参数；参数未填完会保存为“未应用”草稿，刷新后仍在。平台工具条切换光线 / 延长线 / 成像 / 观察者视图、波长色彩和追踪质量，随时导出 PNG 或场景 JSON。

“实验”菜单提供示例库（打开即新建实验）、我的实验、导入（上游场景 JSON version 1–5、完整工程、恢复稿）与导出（完整工程、恢复稿）。场景 JSON 与上游 Ray Optics Simulation 互通；完整工程另含实验记录、质量设置、原始输入和未应用草稿。

限制：背景图片场景、WebGPU 引擎、模块编辑界面和样式编辑不开放；最多 400 个元件；正式数据 850 KB，恢复结构 2 MB，完整请求与导入 snapshot 1.95 MB，导入文件 12 MiB。过大或不支持的文件不会替换当前实验，可容纳的原文放入原生场景 JSON 草稿。

二维几何光学用于教学与解释，未验证专业镜头设计或制造精度。Floatboat 客户端导入尚未实测。
