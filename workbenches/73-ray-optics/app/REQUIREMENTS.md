# Ray Optics 光路实验台 0.9.0

用户：光学课程师生与需要解释二维几何光路的人。核心对象是原生场景、元件参数、探测器读数、实验记录与导入原件。

- 使用固定上游（ricktu288/ray-optics daf76772，5.5.0）的 Scene、Simulator、Editor 与**完整** sceneObjs 注册表；原生拖动与 CPU 追踪必须真实可用。
- **实时光路**：拖动、参数修改、视图切换后自动重绘（上游分片计时器），不需要“计算”按钮；PNG 与场景 JSON 随时可导出。每次重绘受质量上限约束（草图 2 万 / 标准 10 万 / 精细 50 万光线段），达到上限明确提示。
- 器材架按上游分类提供 27 种常用元件；导入接受全部 42 种上游对象类型、模块、观察者、四种视图模式、波长色彩与五种亮度映射。检查器参数来自上游 `populateObjBar`，控制点坐标来自上游 `getPropertySchema`。
- 示例库：上游画廊 16 个场景（棱镜色散、反射棱镜、球面透镜与凹面镜、抛物面镜、平凸厚透镜、凸/凹透镜、开普勒与牛顿望远镜、全内反射、棱镜与光栅分光、反射式单色仪、视深、横纵向放大率、下蜃景、彩虹）保留贡献者署名与 Apache-2.0；另有 3 个原创场景。打开示例 = 新建实验。
- 上游场景 JSON 导入导出兼容；version 1–4 由上游 versionUpdate 升级为 version 5。背景图片场景明确拒绝并保留原文为草稿。
- 未完成参数（数字、方程、坐标）与原生 JSON 编辑保存为工作稿并在刷新后恢复；合法输入立即应用。
- 自动保存完整场景、质量设置、示例来源、实验记录、原始输入与未完成草稿；覆盖刷新、离线、乐观冲突、延迟/丢失回执、项目切换。
- 容量：最多 400 元件；正式数据 850 KB、恢复结构 2 MB、完整保存请求与导入 snapshot 1.95 MB、导入文件 12 MiB。
- 桌面 1440×900 画布、读数条和检查器同时可见；375 px 无横向溢出，画布操作均有列表/数值/方向键替代路径。

本地 check、14 项应用测试与真实 Chrome 验收见 ACCEPTANCE.md 与 acceptance-evidence.json。不调用模型或外部业务系统，客户端导入尚未实测。
