# Ray Optics 光路实验台

用原生Ray Optics核心搭建二维光路、调整元件参数、运行CPU光线追踪并保存实验。界面以光学平台、横向器材架、元件参数和探测器读数为主。

## 运行

在总仓库根目录运行：

```sh
pnpm workbench prepare ray-optics
pnpm workbench check ray-optics
pnpm workbench test ray-optics
pnpm workbench dev ray-optics
```

使用CLI打印的完整预览URL。无需模型、外部服务或WASM；普通源码包不包含预览数据。

## 使用

- 从器材架添加单束光、平行光、镜面、理想透镜、圆形/半平面玻璃、挡光板、探测器、标尺或标注；直接拖动原生画布对象。可用对象列表、数值字段和方向按钮精确操作。
- 参数字段未填完也保存为草稿；点击“应用参数”才改变光路。元件若已在画布中改变，旧参数稿保留并拒绝覆盖。
- 点击“计算光路”取得探测器相对功率/动量分量。编辑、改变视图或切换会使结果失效；恢复实验不自动计算。
- 场景JSON为原生格式，PNG为当前已计算画布；完整工程额外保存记录、导入原件和未完成输入。实际恢复稿导入创建新实验，不覆盖旧实验。
- 文件柜提供保存回执、重试、冲突恢复和项目切换；本机离线恢复只适用于同一浏览器来源。

## 范围

固定上游5.5.0提交 `daf76772c73a85e1a2568c4e2e71613bba1fab77`，真实Scene/Simulator/Editor及CPU算法。支持version5、rays/extended、标准颜色；最多100个用户元件与单次10000段光线。模块、背景图片、公式物体、WebGPU、探测器空间直方图和编辑辅助对象导入不开放。Ctrl组合创建辅助对象不开放；普通拖动、Shift和数值调整可用。

正式数据850KB UTF-8、恢复结构2MB、完整保存请求/导入snapshot上限1.95MB。恢复文件容器允许12MiB，便于包含待确认请求的完整恢复稿回导。不能支持或过大的输入明确报错，不替换当前实验。

这是二维几何光学教学/解释工具，不等同于专业三维镜头优化或制造签核软件。原生计算的上限停止会明确显示，不能导出为已完成PNG。
