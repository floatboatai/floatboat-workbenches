# Ray Optics 光路实验台

用固定版本的 Ray Optics Simulation 5.5.0 内核在二维光学平台上搭建光路：拖动光源、镜面、透镜和光栅时光线**实时重绘**，切换光线 / 延长线 / 成像 / 观察者视图，按波长模拟色散，读取探测器功率与动量分量，并随时导出 PNG 或上游兼容的场景 JSON。

![光纤全内反射示例](../../docs/screenshots/ray-optics.png)

## 运行

在总仓库根目录：

```sh
pnpm workbench prepare ray-optics
pnpm workbench check ray-optics
pnpm workbench test ray-optics
pnpm workbench dev ray-optics
```

打开 CLI 打印的完整预览 URL。无需模型、外部服务、WebGPU 或网络；普通源码包不含预览数据。

## 使用

- **首次打开**：直接是“凸透镜 · 平行光会聚”演示，光线已画出、探测器已有读数。拖动透镜即可看到焦点移动。
- **器材架**（左侧）：光源（单束光、平行光束、点光源、角度光源）、镜面（平面、圆弧、抛物面、理想曲面、分光镜、函数曲面）、透镜与玻璃（理想透镜、球面厚透镜、三棱镜/多边形、半平面、圆形、函数透光物、渐变折射率多边形与圆）、遮光与光栅（吸光片、圆形遮光物、光圈、衍射光栅）、测量与标注（探测器、直尺、量角器、文字、箭头）共 27 种。点击放到视图中心并选中，然后在画布上拖动原生控制点。
- **平台工具条**：视图模式、波长色彩、质量（草图 2 万 / 标准 10 万 / 精细 50 万光线段上限）、撤销/重做、缩放/适配、PNG、JSON。拖动时始终实时预览；达到上限会在读数条说明并可提高质量。
- **检查器**：元件页是上游 objBar 参数（焦距、折射率/柯西系数、曲率半径与厚度、光栅线密度、发射角、透射比、方程等）与控制点坐标；不完整的数字或方程保存为“未应用”草稿，刷新后仍在。场景页是光线密度、亮度映射、波长范围、网格、最大交互次数与原生场景 JSON；记录页是实验笔记。
- **读数条**（画布下方，1440×900 不用滚动）：追踪状态、光线段数、耗时、原生错误/警告和所有探测器的 P / F⊥ / F∥。
- **实验菜单**：示例库（19 个，16 个移植自上游画廊并署名）、我的实验、导入与导出（上游场景 JSON v1–v5、完整工程、恢复稿；导入与打开示例都会新建实验）、删除。

## 范围与限制

支持上游 5.5.0 全部 42 种场景对象的导入与模拟（含模块 ModuleObj、控制柄 Handle、裁切框 CropBox、手绘与自定义表面），以及四种视图模式、波长色彩和五种亮度映射（非标准映射使用 WebGL，不可用时上游自动回退并提示）。仍不支持：背景图片场景（需要上游画廊图片文件）、WebGPU / primitive 引擎、模块的创建与编辑界面、样式（颜色/线型）编辑、画布上的“点击绘制”新建方式（器材架改为放入预设后拖动调整）。最多 400 个元件；正式数据 850 KB、恢复结构 2 MB、完整请求与导入 snapshot 1.95 MB、导入文件 12 MiB。

二维几何光学用于教学与解释，不等同于三维镜头设计或制造签核。
