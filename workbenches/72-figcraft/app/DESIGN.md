# 0.9.0 · 原型校样台

## 用户与主任务
产品经理、文案与前端在交付前逐屏审阅一份 FigCraft 原型：看画板、改文案、记录交付意见、标记“可交付/已完成”，最后带走更新后的 `.figcraft`、交付说明与预览图。P0 是当前画板本身、画面上的文字与图层、以及紧邻画板的交付状态。P1 是画板顺序、逐屏备注、图层名称与填色。P2 是文件生命周期（打开、导入、恢复、删除）、原生引擎连接与工程 JSON。

## 首次使用
空数据目录、没有引擎服务、没有 Floatboat Host 时，首屏直接打开示例 “Calm Studio”（Ridgeline Trails 移动端 4 屏、224 个图层）。工作台自己的 Node 服务读取 `.figcraft` zip 内的 `document.json`，浏览器按节点树（自动布局→flex，矢量/椭圆→SVG，填充/圆角/描边/阴影→CSS）画出近似校样，并在画板上方明确标注“近似校样”。用户可以立刻点选文字、修改文案、改名、改填色、记备注、标记交付状态并导出 SVG/PNG 近似图、交付说明和原生 `.figcraft`。引擎缺席只影响“原生渲染、原生 PNG/PDF”，这些入口旁边是引擎状态卡（安装/启动命令、服务地址、重新检查），不出现原始 `fetch failed`。

## 继续上次工作
自动保存完整工作副本：原生文件、逐屏备注，以及未应用的文案、图层名称、填色、当前画板/图层和工程 JSON 草稿。刷新或重启预览恢复到同一画板与同一未应用输入；状态在顶栏右侧安静显示，草稿/离线/冲突时才出现“重试、下载恢复稿、打开服务器版本”。

## 导入恢复
左上“校样文件”按钮打开文件面板（对话框）：打开 `.figcraft`、导入工程/恢复稿 JSON、载入示例副本、最近校样列表与搜索、下载设计文件/完整工程/恢复稿、删除当前校样，以及按需展开的工程 JSON 草稿。任何导入都创建新校样，不覆盖当前稿。Escape 关闭，焦点回到触发按钮；转场期间禁止编辑旧稿。

## 空间关系
- 顶栏 44px：校样文件入口与稿名、保存状态、引擎状态胶囊。没有项目下拉或新建/保存按钮组。
- 左侧画板带：按页分组的缩略图序列（真实缩略渲染，不伪造）、状态徽标、备注/未应用计数；选中项可上移/下移调整交付顺序（写回页面子节点顺序）。
- 中央舞台占主导：深色粘贴板上居中画板，适配/100% 缩放，近似/原生切换（引擎可用时）。画板名称、尺寸和交付状态切换（未标记/可交付/已完成）就在画板上方；导出菜单紧挨着，内含 SVG/PNG 近似、原生 PNG/PDF（旁附引擎卡）、交付说明、设计文件。
- 右侧复核栏三个标签：文案（当前画板全部文字，未应用草稿在画板上以虚线标出）、图层（选中图层的名称与填色、图层树供键盘选择）、交付（画板名称、备注、全稿交付统计）。

## 视觉
沿用暗色校样室：靛墨粘贴板 `#14151f`，面板 `#1d1f2c`，线 `#33364a`，正文 `#e7e8f0`，次要 `#a2a6bd`；淡紫 `#c4b5fd` 只用于选中与焦点，青绿 `#5eead4` 表示可交付，琥珀 `#fbbf24` 表示已变更/未应用。画板本身保持设计原色，不受主题影响。紧凑 12–13px 界面字，画板名 18px。无装饰动画，reduced-motion 下无过渡。

## 窄屏（375px）
顶栏保留文件入口与状态；画板带变为横向滚动条；舞台按宽度适配；下方“画板 / 复核”切换显示右栏内容。页面不横向溢出，导出菜单与文件面板成为可滚动对话层。

## 与相邻工作台的差异
OpenPencil 是全幅组件画板与图层/属性工具（作图）；Penpot 是资产样本册；glTF 是模型空间与浮动检查器。FigCraft 是“逐屏校样与交付”：画板序列 + 舞台 + 文案/交付复核栏，编辑只限审阅需要的名称、文案、填色和交付状态。

## 状态
加载、示例、编辑中未应用、写入中、引擎检查中/可用/不可用、原生渲染失败（回退近似）、空画板/无文字、导入错误、草稿/离线/冲突均有可见文字。
