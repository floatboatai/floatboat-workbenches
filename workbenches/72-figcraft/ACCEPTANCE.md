# FigCraft 0.9.0 验收

2026-10-29（America/New_York）。Node 22.22.2、Chrome for Testing（playwright-core，headless）、全新数据目录（每轮删除 `.local`）、无引擎服务；引擎在线轮次使用官方 FigCraft CLI 0.11.2 macOS universal（与 0.5.0 验收同一 SHA256 核对过的归档）。

## 功能验收（local-verified）

修复前（审计）：引擎是未打包的独立 CLI 服务，首开 `POST /api/engine` 400，页面红色 “fetch failed”，舞台为空，画板/文案/备注/导出全部不可用。

- 构建：`node scripts/workbench.mjs check figcraft` 通过；`test` 14/14（新增 9 项：示例目录、与 CLI 语义对照的写入、zip 其它条目字节保留、同输入同输出、画板顺序、非法编辑、损坏/伪造/越界文件、交付说明、渲染换算、引擎缺席状态与自动保存校验）；`package` 生成 `figcraft-studio-0.9.0.fbworkbench`（50 个文件，业务数据排除）。`service/` 5/5 真实 CLI 测试（新增 refit：无引擎改过的文字在原生渲染与下一次原生修改时重排，后续自动布局兄弟下移）。
- 首开（无引擎、无数据）：示例 Calm Studio 4 屏 + 3 组件可见，无 “fetch failed”，引擎胶囊“内置校样”，舞台标注“近似校样”。
- 内置渲染保真：4 屏 175 个节点与 `document.json` 中引擎已解析的位置/尺寸对照，152 个误差 ≤2px；其余 23 个全部是按内容收缩的文字（及其收缩父级），由系统字体代替 Inter 造成的几像素宽度差。
- 主任务（浏览器实测）：双击画板文字→复核栏聚焦→改写，画板虚线预览；暂停输入后自动保存，刷新恢复同一画板与未应用文案；应用→`/api/design/edit` 200；标记可交付→再改文案→“已变更”→重新确认；点选图层改填色（草稿预览→应用后画板变色）；改画板名、写备注、上移为 01。
- 导出文件内容校验：SVG 可被 XML 解析（392×846，20 段文字含修改后的文案，含 `#b45309` 填色路径）；PNG 2× 签名正确、784×1692；交付说明含页面顺序、状态、备注、文案表；`.figcraft` 解压后 `characters`/`name`/`dev_status`/`dev_changed`/填色/页面子节点顺序均为修改值，`thumbnail.png` SHA256 与原件一致。
- 引擎卡：导出菜单中原生 PNG/PDF 禁用，旁边显示安装/启动命令、地址与原因（“FigCraft 原生引擎服务未运行（127.0.0.1:8796）”），“重新检查”实际请求 `/api/engine-status`。Escape 关闭并把焦点还给“导出”。
- 引擎在线：胶囊“原生引擎”；文案修改走 `/api/engine`（提示“原生引擎”）；“原生”切换显示 CLI 渲染图；原生 PNG（`\x89PNG`）与 PDF（`%PDF`）下载内容校验通过。中途停止服务后再次修改自动回退内置写入并提示，胶囊回到“内置校样”。
- 自动保存契约：延迟第一次保存期间继续输入，刷新后保留较新的完整备注；服务器已提交但回执丢失（connection reset）后状态为“草稿已暂存本机”，重试后项目数不变（1→1）；非法填色 `#zz` 与未写完的工程 JSON 刷新后原样恢复，JSON 导入给出可读错误；打开 `.figcraft` 另建校样（1→2），旧校样仍在列表并可打开；完整工程 JSON 导入另建校样；删除需确认，取消不删除。
- 真实输入：上限从 600 KB/1200 图层/30 页放宽到 1.35 MB/60000 图层/展开 80 MB（受 SDK 2 MB 请求上限约束，保存完整工作副本）；非 zip 文件提示“不是 .figcraft（zip）文件”。
- 375px：`scrollWidth` = 375，无横向溢出；画板带横向滚动，舞台、复核栏纵向排列；文件对话框与导出菜单可滚动。
- 控制台：无引擎主流程、恢复流程、首开截图 0 条错误。仅在有意注入的故障中出现浏览器资源错误：回执丢失测试的 `ERR_CONNECTION_RESET`，停止引擎后的 503。

## 结构审查（单独记录）

已按 `docs/design-principles.md` 结构验收重排，结果待主代理对照近邻截图确认：删除项目下拉与新建/导入/设计文件/完整项目按钮组；文件生命周期进入“校样文件”对话框；保存状态安静地在顶栏右侧；交付状态切换与导出紧挨画板。对照 0.8.1 的 glTF（模型空间+浮动检查器）与 Oasis（纸张+文稿菜单），本工作台是“画板带+舞台+复核栏”。截图：`docs/screenshots/figcraft.png`（1440×900，示例数据）。

## 界面核查（Web Interface Guidelines）

已处理：图标按钮 aria-label、装饰图标 aria-hidden、表单 name/autocomplete、标签页键盘切换、浮层 Escape/外部点击关闭与焦点返回、对话框 overscroll-behavior、长文本截断、flex/grid `min-width: 0`、reduced-motion、删除确认（共享自动保存的原生 confirm）、数字 tabular-nums、错误信息包含下一步。保留：画板上单击选图层是 div 点击（键盘用户使用“图层”标签的图层列表与文案列表完成同样操作）；图层列表最多列出 600 项未虚拟化。

## 边界

近似校样不是原生渲染：系统字体代替设计字体，图片填充为占位斜纹，角度/菱形渐变近似，旋转元素按包围盒导出 SVG。原生 PNG/PDF 仍需引擎。文字带分段样式（styled runs）时内置修改只替换 `characters`，未在样本中出现，未验证。Floatboat 客户端源码包导入、FigCraft 桌面 GUI 重开导出文件未单独实测。
