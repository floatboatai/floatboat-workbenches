- [PptxGenJS](https://github.com/gitbrent/PptxGenJS) 精确 4.0.1，MIT。`app/src/vendor/pptxgen.bundle.js` 是 npm 官方浏览器文件原字节副本，原始 LICENSE 保留为 `PPTXGENJS-LICENSE`；JSZip 等完整生产依赖许可见 `THIRD_PARTY_LICENSES.txt`（与 05-pptxgenjs 相同依赖集）。
- Presenton（Apache-2.0）只作为可选的外部 HTTP 服务对接，未分发其源码、模型、模板或素材；接口依据见 `app/PRESENTON.md`。
- 导出 PPTX 只写入 Microsoft YaHei / SimSun 字体名称，不分发或嵌入字体。
- 示例资料、插画（由代码绘制的几何图形）与界面均为本仓库原创。

应用源码许可遵循总仓库，第三方各自许可独立适用。
