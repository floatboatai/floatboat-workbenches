# 页间 · PageIndex

长报告阅读：打开PDF（示例或自有文件）→ 沿PDF自身书签或版面标题生成的章节树定位 → 在PDF.js渲染的原页上阅读、检索 → 选中原文摘录并写审阅意见 → 可选：按原页提问并逐字核对引用 → 导出审阅Markdown、阅读档案（含原PDF）、章节JSON。

必须满足：

- 没有Python服务、没有Floatboat Host时，示例与自有PDF都能打开、渲染、检索、摘录、导出。
- 章节树来源依次为：PDF书签（`getOutline`）→ 版面标题识别 → 按页分段；PageIndex服务生成的Flash/模型章节树为可选增强，单独保存，可切换。
- 摘录、已核对引用、检索定位在原页文字层上按字符范围高亮。
- PDF上限64MiB、1000页、原文600万字符、3000个章节节点；每档案200条摘录、50条问答。扫描件（无文字层）可阅读和按页摘录，但不能检索或提问。
- 问答需Floatboat Host；未连接时提问区说明原因并可重新检查，其余功能不受影响。引用必须逐字出现在所读原页，否则记录失败，不编造。
- 自动保存覆盖档案名、页码、缩放、章节树选择、问题、摘录、检索词、未应用JSON和未确认提问；导入总是创建新档案。
