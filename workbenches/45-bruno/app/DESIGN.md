# Bruno · 接口调试台

目标用户是校验 API 的开发者与测试人员。首屏主任务是选择集合请求、修改 HTTP 参数、显式发送、检查响应。以深石墨色编辑台、琥珀色发送按钮与青绿色状态码组织视线。方法/URL 横条连接请求编辑与响应检查，两侧等宽对照，左侧集合可收起；不使用流程图纸/营销卡片。

请求参数使用可读表格式行编辑，原生 Bru 源码独立分页；未应用编辑明确显示。响应展示操作状态、HTTP 状态、时间、响应头和正文，未知回执提供读取记录动作，不提供自动重发。会产生 HTTP 副作用的按钮仅为“发送请求”。导入、恢复与自动保存只存工作稿。

375px 将文件条收纳、请求响应纵向排列，按钮与原生表单保持键盘可达。保存、解析、执行分别显示状态；背景保存不禁用输入。大响应限制字节且标记截断，原始源文件与未支持脚本始终保留；原生脚本不执行。
