# Bruno 接口调试台

使用者可导入单个/多个 `.bru`、`bruno.json` 或集合文件夹，选择请求，编辑 HTTP 方法、完整 URL、查询参数、请求头、none/json/text/xml 正文，使用官方 `@usebruno/lang` 解析与序列化。原生源文件直接编辑与结构化参数分开；所有未应用和无效输入进入自动工作稿。

只有点击“发送请求”产生 HTTP。发送前先保存完整工作稿及发起快照，再由服务器持久化稳定操作 ID，随后才触发网络副作用。响应展示状态、头、正文、编码、字节与时间；取消、超时和网络失联表示回执未知；读取回执不重发。相同操作 ID 幂等返回已有记录，新的未知回执后请求需明确确认。

原生集合 ZIP 包含原文件路径、`bruno.json` 和 `.bru` 字节，可解压后从文件夹再次导入。完整工程含响应快照与编辑稿，实际恢复文件的 snapshot:{title,data,extra} 导入新副本。源安装包不含业务数据。导入历史记录不会执行。

脚本、tests、assertions、变量、认证继承、集合/文件夹执行规则、代理、非 HTTP 协议、复杂 body、额外参数注解不执行；原文完整保留且阻止结构重写。结构化编辑仅作用于明确支持的简单 HTTP 请求。环境秘密绑定暂不支持，所有手动输入数据按明示范围保存/导出。

预算：20 文件、每个源文件 40K 字符、4 响应快照、模型780KB，恢复结构预算2MB；完整自动保存请求（含标题、extra 和协议字段）仍限1.95MB；请求10秒、响应64KiB，超出正文标记截断。窄屏、键盘、响应对照、可收起集合均需真实浏览器验证。
