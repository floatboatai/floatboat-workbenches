# 写作笔记需求

面向记录观察、整理读书笔记和撰写长文的个人用户。以正文为主要工作面，目录/标签定位文字，章节大纲定位段落，页边旁注保存尚未整理的线索。

验收：真正的 Milkdown Crepe 可编辑正文；支持标题、常见格式、列表/任务、代码与表格。笔记本/笔记/标签可创建编辑删除，删除需确认。搜索、章节跳转、专注和源码模式有效。Markdown 与完整笔记本导入创建新项目；真实文件导出可核验原文与元数据，近容量 JSON 导出可再次导入。所有编辑和未完成输入自动保存，离线/冲突状态真实，原生编辑器不因回执重新挂载。

上限与安全边界以 contracts/notebook.ts 为唯一来源，README 描述产品限制。检查桌面和 375px、暗色、reduced-motion、键盘焦点、无横向溢出；错误可恢复；无隐式第三方网络请求。Floatboat 包交付，桌面导入单独声明未验证。
