# API 参考台

面向接口使用者，整理 OpenAPI 规格并调用同源只读示例。

## 功能与边界

只接受 OpenAPI 3.0/3.1 JSON 对象；禁止远程 $ref；试调仅限 GET。

项目支持创建、重命名、保存、打开、删除与版本冲突检查。AI 返回候选稿，用户明确采用后才替换编辑内容。无效输入保留，失败信息说明恢复路径。

## 验收

真实渲染和导出、保存刷新恢复、无效输入、并发更新、375px 与宽屏、键盘焦点、页面错误与 CSP 检查；工作台导入与本地验收分开记录。

未应用 JSON 不得静默丢失；取消离开、切换或覆盖应保留原文。导出仅允许当前已应用规格，等待应用时禁用。试调明确限制同源 GET，不承诺外部 API 连接能力。
