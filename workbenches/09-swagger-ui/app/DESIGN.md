# API 参考台设计

完整参考文档为主体，顶部规格摘要与可折叠 JSON 编辑器；不使用画布外壳。

主要动作围绕编辑、预览、保存、导出。每个输入有标签和可见焦点，状态使用 live region。窄屏顺序呈现关键区域，长代码与数据在自身容器滚动。深色和 reduced-motion 尊重系统偏好。

独立布局选择基于当前任务，不复制其它工作台的侧栏与欢迎页。生成稿与当前内容同时可见，采用操作需要明确点击。

本轮回到API参考工具的结构：紧凑工具栏、固定端点目录、真实Swagger原生文档及Try it out console；JSON编辑按需并排展开。取消大hero与指标卡，接口信息由Swagger文档本身呈现。端点目录定位并展开实际接口，窄屏顺序保留目录、编辑和试调。
