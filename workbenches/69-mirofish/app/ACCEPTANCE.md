## 独立 Chrome 验收

Chrome for Testing **143.0.7499.4**，独立无头进程和新 profile，1440×1000 与 375×1000。真实本地 HTTP、Node 推演与 SQLite，浏览器阻断外部网络；预览设置 `FLOATBOAT_HOST_MODE=offline`，MiroFish 指向不可连接的回环地址。

**15 组完整浏览器验收通过：**

1. 示例真实生成 232 条动作，通道显示未连接；1440px 首屏无正文横向溢出。
2. 推演档案 Escape 关闭，焦点返回触发按钮。
3. 空白推演导入 Markdown 与 HTML → 抽取图谱 → 生成人设 → 8 轮本地运行 → 规则报告；此次新输入生成 6 智能体、9 动作。
4. 下载并解析逐轮 CSV、智能体 CSV、原生 JSONL、图谱 JSON、Markdown、独立 HTML、推演文件和恢复稿；CSV 带 BOM，动作条数与运行一致；HTML 用 `file://` 单独打开并渲染 4 张 SVG 图表。
5. 导入推演文件创建新记录，原记录不变；按输入重生成的指纹一致。
6. 服务端保存回执延迟时继续输入，较新内容保留并随后写入，刷新仍一致。
7. SQLite 已提交但浏览器丢失回执，重试使用同一个 mutationId，项目只增加一次修订。
8. 轮次 0 保存为草稿；刷新保留 0，正式模型仍为原来的有效轮次，修正后恢复正常保存。
9. 外部更新触发乐观冲突，不覆盖服务器；新标签页仍恢复本机冲突稿，可显式打开服务器版本。
10. 全新离线工作副本切换后在“本机恢复稿”找回，恢复连接后同步。
11. 501 页 PDF 读到第 501 页；CMap 返回字节与本地资源一致；损坏 PDF 有可操作错误。
12. 两种宽度走完六阶段、后端未连接提示与重新检查、文件菜单和截图，正文无横向溢出。
13. 加载结果期间显示加载状态；切换到不同运行时，旧报告不可导出新附图，重新生成后可导出。
14. 375px 新建、粘贴、抽取、人设、运行、报告下载、刷新恢复、导入恢复稿和打开已保存推演。
15. 原生 JSONL 导入与带原始动作的推演包导出；缺平台 JSONL 保留草稿，刷新后选择平台可重试成功。

无非预期 console error / pageerror。故障注入产生的 `ERR_FAILED` 与缺平台导入的 HTTP 400 是预期事件，逐项记录在 `browser-codex.json`；外部请求为 0。

另外完成真实服务进程停止/重启与全新 Chrome profile 验证：从 SQLite 恢复原推演名称、报告阶段、研究者备注及完整 Scenario，结果重新载入后的指纹仍为 `00c6bb8c00be1a`，无 pageerror 或外部请求。证据为 `restart-codex.json`。

## Host 与外部模拟边界

Host 浏览器 mock **4 组通过**：人设建议需确认才应用；模型报告失败保留原报告；模型稿需确认才替换；断开后显示明确状态与重试入口。服务端合同测试验证提示词、请求 ID、输出校验、越界钳制、截断拒绝和离线错误。没有真实 Host/LLM 请求或计费。

官方 MiroFish 的 health/list/start/stop/status/result 仍由本地 HTTP 合同测试验证；没有运行真实 OASIS、Zep 或其模型。上游 stop 仅接受 simulation_id，无法原子排除另一个客户端在预检后重启的竞态。

## 限制

- “离线”仍需要本地工作台服务运行；不是无服务端的 PWA。
- 本地意见动力学与模板帖子用于比较假设，不是上游 LLM 模拟的等价实现或现实预测；中文规则抽取、词典立场需要人工核对。
- 资料 12 份 / 20 万字符，模型 900KB，最多 200 智能体、240 轮、8 次运行；大量输入快照会先达到保存上限。未做满容量性能/内存压力验收。
- 扫描 PDF 不含 OCR；密码 PDF 先解密；501 页回归用本地可提取文字 PDF，不代表所有复杂排版与语言均验证。
- 恢复稿保存工作副本；非本地运行的大结果在独立库中，跨机器应使用附带原始动作的 `.mirofish.json` 或原始 JSONL，不能只带恢复稿。
- 0.5 工程转为导入运行，保留动作与背景/假设/结论；旧逐动作批注不映射为新六阶段编辑控件。
- 未完成屏幕阅读器、触屏拖动与全部图表键盘交互测试；列表提供实体/关系检查器入口。真实 Host、OASIS/Zep、客户端导入均未实测。
