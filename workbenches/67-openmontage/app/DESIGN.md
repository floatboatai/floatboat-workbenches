# 剪辑台

## 用户与主任务

用户是要把手头的视频、照片、音乐和旁白稿剪成一条短片的内容制作人。他们最常做的事：把素材放上时间线，修剪、分割、挪位置，加转场、标题和字幕，调音量，边看监视器边改，最后导出一个能直接发出去的 MP4。

工作对象叫“影片”。内部仍存为 project，界面不出现“项目”。

## 路径

- **首次使用**：首屏就是示例影片《海边的一天 · 粗剪》：4 个镜头（淡入开场、两处交叉溶解、经黑场进静帧）、标题、下方字条、4 条字幕、配乐和环境声。监视器停在第 2 秒，画面和标题都可见。可以直接播放、修改或导出，不需要先建项目或启动服务。工作副本在第一次编辑时创建。
- **自己的素材**：素材库“导入素材”可一次选多个视频、图片、音频，也可夹带 SRT/VTT 字幕；拖到轨道上，或点“＋”放到播放头。“影片”菜单里的“新建空白影片”从空素材库开始。
- **继续上次工作**：打开时恢复最近一份工作稿（服务器自动保存，加 IndexedDB 本机副本）。“影片”菜单列出最近的影片、未同步的本机稿和草稿。
- **导入与恢复**：“影片 → 导入工程…”接收 `.openmontage` 完整工程包（含素材）、0.5 版工程 JSON 和恢复稿。导入后总是新建一部影片，不覆盖当前影片。恢复稿不含素材：缺失的素材会在保存状态里提示，重新导入同一文件即可补齐（素材按内容哈希识别）。

## 空间关系

剪辑软件的惯例布局，按任务分配面积：

- **主工作区**：监视器（中上，画面接近纯黑底）和多轨时间线（底部，通栏）。时间线上的操作就在片段本身：拖动移动或换轨，拖左右边缘修剪，吸附到播放头和其他片段边缘，淡入淡出直接画在片段上，交叉溶解区标成琥珀色。
- **上下文工具**：左侧素材库（素材、文字模板、导入字幕），右侧检查器（选中片段时显示时间、画面、声音、转场、文字样式和备注；选中轨道时显示轨道设置；都不选时显示影片设置：画幅、帧率、底色、说明）。时间线工具条在监视器和时间线之间：分割、删除、吸附、缩放、加轨。
- **按需信息**：导出对话框（本机导出、成片架、OpenMontage 服务），工程 JSON 对话框。
- **文件生命周期**：全部放进左上角“影片”菜单：新建空白影片、打开示例、导入/导出工程、导出恢复稿、工程 JSON、导出字幕 SRT、导出剪辑单 Markdown、最近的影片、删除。页头只剩菜单、影片名、保存状态、撤销/重做和主动作“导出成片”。原来的“项目选择器 + 新建/导入/完整工程”按钮组已经去掉。

## 色彩、排版与密度

石墨色剪辑间（`#121315` / `#1a1b1e`），监视器区 `#0b0b0c`。用深色是剪辑任务本身的需要：看画面颜色时，界面不能比画面亮。所以这里固定用深色，不跟随宿主的浅色主题。片段按类型着色：视频钢青、图片赭黄、音频墨绿（带竖纹）、文字紫。播放头用演播红，选中和主动作用琥珀色。界面字号 13px，信息密度高。时间码和时间尺用等宽数字，格式为 `分:秒:帧`。

## 关键状态

- 保存：`已自动保存` / 待保存 / 草稿（如名称为空、素材缺失）/ 离线已暂存本机 / 冲突，分别给出重试或打开服务器版本。
- 片段的起点、时长、入点和淡入淡出保留未完成文本。未应用的 JSON 或数值已保存时显示“工作稿已自动保存，含未应用输入”，不把它误报为已应用的时间线；Escape 放弃当前数值输入。新建和切换影片期间锁定编辑，普通后台保存仍可继续输入。
- 素材：导入时显示上传进度；格式不支持或本机不能解码时，在提示条里写明文件名和原因，同批其他文件照常导入；播放时读不到的素材，在监视器上显示错误。
- 导出：进度条带帧数，可以取消；完成后成片保存到成片架，可以回看、下载、放回素材库。成片架保存失败时直接下载文件。WebCodecs 不可用时说明原因，并给出替代方案。
- OpenMontage 服务：状态点（已连接 / 未就绪 / 未连接）、地址、启动命令和“重新检查”。主画面轨不符合服务条件时，写明是哪一段、为什么不符合。只有服务连通、轨道也符合条件时，才显示“用 OpenMontage 渲染”按钮，不显示点不了的按钮。
- 删除素材或轨道不弹确认框，执行后提示“可撤销”，用 ⌘/Ctrl+Z 恢复。

## 窄屏（≤900px）

页面纵向排列：页头（菜单、名称、撤销、导出，保存状态单独一行）→ 监视器（满宽）→ 走带 → “时间线 / 素材 / 属性”三段切换（吸顶）→ 当前面板。时间线在自己的容器里横向滚动，轨道名称列缩到 92px。触控目标 36px。菜单改为固定在顶部的全宽浮层，导出对话框可纵向滚动。375px 下页面没有横向溢出。

成片架在窄屏中把名称/规格、操作按钮、回看片段按行排列，避免按钮把名称和规格挤成窄列。对话框内滚动不向外层页面传播。

## 与相邻工作台的差异

- **HyperFrames**（暗色动效舞台、镜头轨与输出队列）：它是单轨的镜头序列，每个镜头是模板化的文字卡，右侧编辑镜头文案，底部是渲染输出条，页头仍是项目选择器加新建/导入/工程按钮。剪辑台是真正的多轨：每类轨道一条泳道，片段可以移动、修剪、分割、叠层和交叉溶解；文件操作收进“影片”菜单；导出放在对话框里，本机导出是主路径。
- **faster-whisper**（暗色波形、字幕入出点）：那边以一条音频的波形和字幕表为中心。这里字幕只是一条文字轨，和画面、音乐一起剪。
- 0.5 版 OpenMontage 是浅色“分镜制作单”：横向逐行审批，成片架放在侧栏。本版改为剪辑软件的空间组织，审批流程不再保留，镜头备注保留在片段的“剪辑备注”里。
