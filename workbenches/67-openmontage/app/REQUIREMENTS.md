# OpenMontage 剪辑台转化范围

真实可用的短片剪辑：导入视频、图片、音频和字幕 → 多轨时间线编排（移动、换轨、修剪、分割、吸附、撤销重做）→ 转场（淡入淡出、交叉溶解、经黑场）→ 标题、下方字条、字幕与角标 → 片段与轨道音量 → 浏览器内实时预览 → 导出真实成片（MP4：H.264 + AAC；本机不支持时用 WebM）。空数据、无外部服务、无 Floatboat Host 时，从首屏就能完成全部流程。

素材上限为单个 2 GB，格式以文件头识别：MP4、MOV、WebM、MKV 视频，PNG、JPEG、WebP、GIF 图片，MP3、M4A/AAC、WAV、OGG、FLAC 音频。导入前用 Mediabunny 读取时长与尺寸，并确认本机浏览器能解码。字幕接受 SRT 和 WebVTT，可导出 SRT。时间线最长 4 小时，24 条轨道，5000 个片段。

工作台附带原创示例素材（`samples-src/generate.mjs` 用程序绘制画面、合成声音，再用 FFmpeg 编码）：3 段 1280×720 视频、1 张静帧、1 段配乐、1 段环境声，合计约 2.6 MB。示例影片《海边的一天 · 粗剪》引用这些素材。

自动保存完整工作稿（含未应用的 JSON、未完成的名称和片段时间数值），处理丢失回执、冲突和本机恢复。未完成数值按片段和字段保存，刷新或导入恢复稿后重新选择对应片段可继续输入；应用前不改变已保存的时间线，并明确提示工作稿包含未应用输入。新建、打开示例和打开影片等待旧稿保存时锁定编辑，避免切换覆盖刚输入的内容。完整工程包 `.openmontage` 由 JSON 头和原始素材字节组成，不做 base64 编码；导入时逐个核对内容哈希，然后新建一部影片。

OpenMontage 服务（固定上游提交，调用官方 VideoTrimmer / VideoStitch）是可选的高级渲染，只处理主画面轨的 MP4 片段，硬切拼接为 720p/24fps。服务条件不满足时，界面说明原因，并给出启动方式。

不包含：AI 生成素材、配音、素材检索、画中画位置/缩放关键帧、调色、变速、倒放、音频波形显示。

本轮验收以 Node 22.23.4、独立无头 Chrome 的 1440px/375px 页面为准，不连接真实 Host 或 LLM。单素材 2 GB、4 小时时间线是校验上限，未作为负载能力保证；实际最大输入为 29.2 MiB 的 1080p MP4，最长导出时间线为 58.2 秒。导出混音和成片缓存在内存，长片和大素材受浏览器可用内存及编码器限制。
