# Docling 校对台

用户：需要核对抽取文本、阅读次序和表格内容的文档整理者。主动作：从结构目录选择一项，对照源文与校订值，标记复核，再导出。

首屏采用纸张校样台：薄顶栏与文件管理、左侧窄结构树、中央白色正文纸张、右侧竖向校订栏。正文使用衬线字体，控件使用系统无衬线字体，元数据使用等宽字体。冷灰与墨蓝区分结构目录、编辑器和校样面板；蓝色代表选择，绿色只用于连接状态。没有聊天输入框、统计卡或仪表盘。

主要状态：无文档、已导入、未复核/已复核、校订、原始 JSON 草稿、自动保存/草稿/离线/冲突；服务未配置/提交中/不确定/排队/运行/失败/结果待采用。服务操作与人工编辑彼此独立。

375px 改为纵向结构目录、文稿、校订区；表格自身滚动。按钮最小 36px（移动端 44px），键盘焦点清晰，不依赖拖动调整顺序，不使用动画。所有文件和参数输入有可见名称。深色宿主保留纸张与控件的明确对比。

实现顺序：1. 原始文档与校订契约；2. SQLite/完整草稿；3. 校样页及表格编辑；4. 持久化异步转换；5. 单测、浏览器和移动端；6. 截图、文档及包。
