# Docling 0.9.0 校对空间

## 主任务与文件路径

用户把文档解析成结构，核对每个块在原文的位置，修改后导出。首屏直接呈现“示例 · 城东水厂水质报告”，无需项目选择或新建/立即保存页头。首次编辑创建保存记录；打开示例、转换或导入均建立新的工作副本。继续工作从文档菜单“最近的校对”进入；恢复输入从同一菜单导出工作副本，再经转换面板导入。可移植校对包携带原文件和结构。

## 空间组织

1440px：薄顶栏集中当前文档名称、保存状态、文档菜单、转换和导出；约 264px 的结构轨在左，原页与校样对照占中央约 840px，约 336px 的校订栏在右。中央可切换原页、对照、文稿；选择结构项同步定位原页框、表格或正文，校订控件紧邻当前对象。转换面板按需打开，服务状态、启动命令、重新检查和选项在提交操作旁。

冷灰蓝用于看片台和结构轨，米白纸张承载阅读，朱红标记当前选择，绿色表格框和复核标记区分对象/进度。正文用系统衬线字体，控件用系统无衬线，引用与数值使用等宽字体。没有远程字体。原页保留原文，校样呈现修订，双方不混淆。

375px：页头分两行，“结构 / 原页（原文）/ 文稿 / 校订”切换主区；选择结构后进入原页或文稿，再切换校订。表格内部独立滚动，页面不横溢；主操作触点至少 44px。不是把桌面四栏强行压缩或隐藏关键操作。

## 状态与可访问性

首次空数据有可信多页示例；无文档的恢复副本打开后提供转换和示例入口。无源文件的 JSON 明确告知无法原页对照；服务不可用时仍可本地解析。解析错误保留已有校订。自动保存显示待保存、保存中、已保存、未应用输入、离线或冲突；冲突提供恢复导出及读取服务器版本。

按钮、输入均有名称，状态播报、可见焦点和 reduced-motion 路径保留。转换弹窗支持 Tab/Shift+Tab 循环、Escape 及焦点返回；关闭回调保持稳定，真实逐键输入和后台保存不得触发重复 autofocus。PDF 页面按可见区域渲染，图框支持按钮点选和结构目录选择；无需拖动也能完成主任务。

## 结构审查（2026-10-29，独立于功能结果）

实际对照仓库 `docs/screenshots/pageindex.png` 与 `docs/screenshots/pdfme.png`：

| 对照 | 差异 |
| --- | --- |
| PageIndex | PageIndex 为章节目录、单张原页、右侧摘录/问答；本工作台以结构块而非章节导航，中央同时呈现原页和校订稿，右侧编辑文本或逐格表格，不提供问答 |
| pdfme | pdfme 为页面缩略轨、版式舞台和字段/批量数据；本工作台没有模板字段映射，左侧是抽取结构及复核筛选，右侧为原文修订，核心是坐标证据与校订的对应关系 |

当前 1440 与 375 实际截图已检查：主区占比、原页/稿件对应、文件菜单和窄屏顺序满足任务。功能入口无需项目创建；导入、转换、打开最近校对、恢复导入、导出与移动端单元格修改已实跑。转换弹窗和文件菜单 Escape/焦点返回已测。结构审查结果：**通过本轮范围**。
