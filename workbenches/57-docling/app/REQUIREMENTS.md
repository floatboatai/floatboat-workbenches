# 文档结构校对

用户是文档整理者，需要从 DoclingDocument 中核对文本、表格和阅读顺序，再输出适合检索或编辑的内容。

必需行为：
- 导入 DoclingDocument 1.x / 可移植校对项目，保留原始解析对象与 self_ref/parent/children。
- 结构目录与纸面文稿选择同步；源文本和校订版本可对照；文本、类型、表格单元格、备注、复核状态可编辑。
- 同父级阅读次序调整，保留完整引用；表格预览支持合并跨度，CSV 为首格保留合并值的二维投影。
- 校订 Markdown、原生 JSON、选中表格 CSV、可移植 review JSON、恢复工作副本可导出；导入永远新建。
- 所有输入包括尚未应用的 JSON/HTML 自动保存，明确草稿/离线/冲突；不会让异步响应覆盖新编辑。
- 官方 Serve 异步 multipart HTML 上传、任务轮询、结果持久化，提交前持久化输入与操作 ID；无法确认提交时绝不自动重交。
- 服务结果显式作为新项目采用，离线/未配置服务不影响已有文档校对。

第一版边界：HTML 转换输入 ≤400 KB；原生 JSON ≤600 KB、正式 review ≤800 KB、可恢复/导入导出的工作稿 ≤1.2 MB，含额外编辑输入的工作副本 ≤1.85 MB；不做 PDF 视觉渲染、OCR、DOCX 上传、图片展示或模型调用。Serve 实例未实际部署验收；真实 Docling core 转换与原生 schema 兼容性已验证。

验收：严格模板检查、23 项单测、13 条原有真实浏览器工作流与 5 条容量恢复定向流程、375px/1440px、键盘/reduced-motion、保存与故障恢复、真实 Docling 输出校验、截图和独立源包。
