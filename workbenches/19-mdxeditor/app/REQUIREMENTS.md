# MDXEditor 文档审阅台

为产品文档、教程和说明书作者提供 Markdown 写作与审阅工作台。使用真正的 @mdxeditor/editor 富文本编辑器及原生源文、并列差异视图。

- 编辑标题、正文、标题层级、粗体/斜体、列表/任务项、引用、链接、表格和代码块；Markdown 快捷输入、撤销/重做可用。
- 固定比较基线独立保存。差异视图左侧基线、右侧当前稿均只读，修改在正文或源文完成；更新基线需要明确确认。
- 审阅意见可添加、直接修改、完成/重新打开、确认删除；未提交的意见输入也保存。
- Markdown 或审阅项目 JSON 导入均创建新文档。粘贴窗口保存未完成的输入；JSON 导出带文稿、基线、意见、未提交输入与导入格式。
- 编辑后自动保存；保存响应不重建编辑器。SQLite 工作副本与同源 IndexedDB 恢复支撑离线、重试与冲突。明确区分已保存、仅草稿、离线和冲突。
- HTML/JSX 与图片只作为可恢复源文，不能进入已应用模型；不执行任意 MDX/JSX、JavaScript、远程媒体或代码块。普通 Markdown 中的大括号、import/export 只是文字。链接仅支持 http/https/mailto/#，编辑表面点击链接不导航。
- 不提供组件运行环境、图片附件托管、协同光标、逐行批注锚点或 AI 生成。意见属于整份文档。Floatboat 桌面导入单独验证。

验收覆盖契约边界、真实 Chrome 原生编辑、实际下载、导入新文档、自动保存与重启、延迟 ACK 输入、丢失响应重试、无效源文/未完成输入恢复、乐观冲突、新标签页冲突、本机离线新稿恢复、375px/深色/reduced-motion、焦点和页面错误。
