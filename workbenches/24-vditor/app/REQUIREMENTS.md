# Vditor 文章工作台

## 用户任务

用中文写作一篇 Markdown 文章，在原生所见即所得、即时渲染与源码分屏间切换，查看大纲、署名与摘要，检查书稿/发布稿排版，导出可移植内容。

## 必须能力

- 使用 Vditor 4.0.1 实际编辑器。原生标题、强调、列表、任务列表、引用、链接、代码、表格与撤销重做。
- 三模式共用同一编辑器实例。后台保存及回执不重建编辑器；切换文章才重新初始化。源码精确保留未闭合语法及尾部空白。
- 自动保存完整工作副本，区分服务器模型、未完成草稿、本机暂存及冲突。保存期间可继续输入；失败可重试/导出恢复草稿/打开服务器版本。
- Markdown 与安全 HTML 导入；完整项目 JSON 导入导出保留正文、作者、摘要、模式及版式。所有导入必须新建文章。
- 未应用的导入框输入与格式选择也保存。文章名称为空时保留草稿，不谎报模型保存成功。
- 独立 HTML 阅读版内联排版样式，无脚本或外部资产；Markdown 导出保持源码。
- 所有运行时脚本、CSS 使用声明项目资源的同源固定路由。原 SDK CSP 不变，无默认 CDN 请求。
- 桌面及 375px 可写作，浅/暗色与减少动态效果可用；表单有名称与可见焦点。

## 明确范围

- 正文上限 100,000 字符；超限到 200,000 字符保留为草稿，不能形成有效文章；大粘贴会提示容量限制。作者 80、摘要 1,000、名称 120 字符。
- 项目文件上限 900 KB；文本粘贴区上限 100,000 字符。较大 JSON 通过文件导入，最大合法项目可完整往返。请求/草稿上限 1.95 MB，模型 900 KB。
- 这是文字文章编辑器。代码块作为原文显示，不执行语法高亮、数学、图表或远端 PlantUML；不上传图片，不请求外部媒体。含原始 HTML、Markdown 图片与块公式的文档保留在原生源码模式；移除这些语法可切换富文本模式。
- HTML 导入只保留文章常用文字结构与安全链接，移除脚本、样式、媒体、嵌入及事件属性。预览与导出也使用闭合标签/属性白名单。
- 不提供 AI、协同编辑、版本历史或跨设备本机缓存。IndexedDB 只在相同浏览器来源恢复。

## 验收

契约/容量/导入往返/幂等/冲突单测；实际 Chrome 三模式输入与格式、文件内容独立检查、延迟确认继续写、响应丢失重试、无效草稿恢复、新建离线草稿切走找回、同源新标签冲突阻断、导入新建、桌面/手机/暗色/减少动态效果与网络检查。Floatboat 客户端导入另行验证。

排版预算：正文超过 50,000 字符或单行超过 4,000 字符时，自动使用原生源码编辑并暂停即时预览、阅读排版与 HTML 导出，避免上游解析阻塞输入。Markdown 与完整项目的 100,000 字符保存/往返能力不变；缩短后可恢复三模式。切换富文本时遵循 Vditor 原生 Markdown 规范化。
