# Vditor 文章工作台

用户把一个想法写成可发布的中文文章。主任务是连续写作、切换 Markdown 表达方式、检查排版，再导出正文。

首屏 P0 是文章标题与真实 Vditor 正文；P1 是三种编辑模式、自动保存状态、文章大纲；P2 是作者、摘要、导入导出与文章切换。采用温暖纸色的全宽写作桌：细顶栏，左侧可折叠的文章目录/写作信息，中央宽纸面。右侧留白用于阅读节奏，不使用统计卡。

正文用系统宋体/衬线字体，标题有清晰层级；操作区用系统无衬线字体。青绿色是编辑与当前状态，暖灰分隔文章与工作区。正文约 720px，源码与预览并列时扩展到全部可用空间。暗色模式保留温润对比。无装饰动效。

状态覆盖加载、空文章、编辑中、服务器已保存、未完成标题草稿、离线本机恢复、版本冲突、无效导入、编辑器加载失败。后台保存不锁编辑器；只在切换文章时重建 Vditor。导入始终新建文章。元数据与未应用的导入文字均自动保存。

375px 收起侧栏；模式栏可换行，工具栏局部横滚；源码预览上下排列；作者、摘要等在可折叠侧栏继续可编辑。焦点可见，按钮有中文名称，弹窗使用原生 dialog 并返回焦点。

与相邻产品的区别：这是单篇文章的写作/排版桌，不采用 MDX 差异评审、Milkdown 笔记本或 BlockNote 页面装订结构。

验收顺序：契约与容量边界 → 原生三模式与本地资源 → 保存/恢复/冲突 → 导入导出互通 → Chrome 桌面/窄屏/暗色/减少动态效果 → 源码打包。
