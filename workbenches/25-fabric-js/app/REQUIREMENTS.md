# 海报排版台

面向需要制作活动海报、社交方图和横版封面的用户。打开模板，在画板直接修改文字、拖动形状、通过手柄缩放和旋转，再用属性精调并导出。

已实现：
- Fabric.js 7.4.0 原生 Canvas、Textbox、Rect、Ellipse；原生双击改字、移动、缩放、旋转；键盘可通过图层和属性完成编辑。
- 精确位置、宽高、缩放、角度、不透明度、填充、描边、圆角、字体、字号、字重及对齐。文字高度由排版自动计算。
- 单对象选择、复制、删除、图层上下移动，当前会话最多 60 步撤销/重做。
- 三种模板、画板尺寸预设与自定义尺寸、缩放；模板选择与 JSON 导入创建新项目。
- PNG、SVG、项目 JSON 导出；工作副本导出保留原始草稿用于人工恢复。
- SQLite 自动保存 + 同源 IndexedDB 缓存；未应用属性和不完整导入内容保存为草稿；背景确认不重建 Canvas。
- 失败重试、冲突提示、打开服务端版本、导出恢复副本；中文、桌面/窄屏、暗色和 reduced-motion。

边界：只接收工作台 schemaVersion=1 的项目；不导入任意 Fabric JSON、SVG、HTML 或图片。最多 160 个对象、每对象 8000 字、项目 500 KB；输入文件最多 550 KB。画板单边 128–4096px、面积最多 1200 万像素。纯色及三种系统字体，文字渲染受接收设备字体影响。没有多选/组合、路径绘图、渐变、外部资源、照片处理、服务端出图、AI 调用或打印色彩管理。Undo 历史不跨重开；对象与未应用草稿跨重开。工作副本 JSON 是包含草稿的恢复资料，项目导入器只接收其中的 data 模型或常规项目 JSON。

验收见 README。Floatboat 客户端导入与安装后的运行需独立验证。
