# CircuitJS1 0.8.1 验收

2026-10-28；本次为电路实验仪器台的信息架构改版。GPL-2.0-or-later、appId、registryName、storageKey、数据结构和原生求解/保存实现保持不变。

## 信息架构

首屏由左侧纵向元件架、全幅原生电路/Scope、底部时基/探针/电压/电流仪器台组成。常驻右侧笔记栏及顶部项目下拉/创建/导入条已移除。左上「实验」进入实验簿，电路页管理样例、最近实验、导入与恢复；记录页编辑名称和笔记；文本页保留未完成源码与原始文件。电路/PNG 导出位于画布上下文，记录导出位于记录页。

主线已审阅 1440×1000 / 375×900 首屏，确认与纸张编辑台和浅色模型工作台形成结构差别。最终仓库截图为自然 RC 方波实验；截图前实际导出当前画布，并等待服务端原生 dump 与当前电路完全一致、UI 回执为 saved。

## 实际浏览器流程

- 实验簿 Enter/Tab/Shift+Tab/Esc：焦点在 dialog 内循环，关闭后回到「实验」或「实验记录」各自入口；打开/切页/关闭不重建 native iframe。
- 实验簿新建直流示例、最近实验打开、实际原生 XML 导入均通过，文档切换成功后返回画布。
- 5 V + 两个 1 kΩ 分压：原生读数 2.5 V / 2.5 mA，分别在 1e-8 V / 1e-10 A 容差内。
- 调整布局后的画布坐标能实际拖放新增电阻并原生撤销；原生 Scope 保留。
- 元件参数未失焦输入 `-` 后保存并刷新：草稿保留，显式恢复到原生参数框；无效数值不应用，改为 `2k` 后正确写入 XML。恢复始终暂停。
- 画布 XML、PNG 和实验记录 Markdown 均真实下载；实际恢复包下载再导入产生新副本，保留未应用的 `3k` 参数草稿。
- 延迟已提交回执时继续写笔记 B，再从实验簿切换实验：旧实验保留 B；最近列表重开仍为 B。
- 普通自动保存等待回执期间，笔记可编辑；显式 change 期间，旧对象字段、实验簿切页、顶部入口和对象操作均禁用。实际延迟切换已验证不能转到旧稿继续输入。底层 freeze/保存函数未修改。
- 未完成电路文本在实验簿关闭/重开后保留。
- 375 px 页面无横向溢出；原生画布宽 332 px，电路可见像素范围 x=16–299。两项探针操作点击区至少 28 px；实际用键盘修改电阻为 1.5k，再新增原生 Scope。另验证运行/暂停、reduced-motion 和实验簿 Esc 焦点恢复。
- 浏览器脚本最终 passed=true，page errors 为空。
