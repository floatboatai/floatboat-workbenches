# CircuitJS1 0.8.1：电路实验仪器台

## 主任务与信息层级

用户放置/连接元件、调整参数并运行电路，通过原生 Scope 和元件读数判断响应，再记录实验。

- P0：原生电路 + Scope 占据主空间；元件架在左侧；运行/暂停、复位、时间和当前元件电压/电流在底部仪器台。
- P1：工具选择、撤销/重做、适合画布；电路文件与画布图像在画布上下文中导出。未提交参数紧邻仪器台提示并恢复。
- P2：文件生命周期、样例、最近实验与笔记在按需打开的实验簿；不常驻项目下拉、创建/导入条或右侧笔记栏。

## 文件与实验生命周期

左上「实验」打开原生 dialog 实验簿，分为电路、记录、文本三个页面。电路页提供 RC / 直流实验新建、最近实验与文件/恢复包导入。记录页编辑名称、笔记和导出实验记录；文本页保留原生文本与原始导入文件。自动保存状态留在仪器顶沿，重试、恢复包、冲突处理位于实验簿。切换成功后实验簿关闭并将焦点还给入口；Esc 关闭也返回入口。

文档实例、原生求解器、保存协议、草稿内容与容量不变。实验簿开关不卸载或重新挂载 iframe。只有原有 documentKey 变更才建立新原生实例。文件切换继续通过原有冻结/保存流程；transition 期间禁用旧对象字段、实验簿切页和对象操作，普通自动保存期间继续允许输入。恢复不自动运行。

## 布局与视觉

采用纵向紧凑元件架 + 大面积黑色电路/波形 + 底部仪器面板。仪器面板分为时基/运行、当前元件、两路读数与参数/记录操作，主视觉是数值与操作，不放项目管理。细网格分隔、等宽数字和绿/黄信号色沿用电子实验仪器语义。无营销文案、统计卡、常驻笔记栏或顶部 CRUD 工具条。

实验簿是短时进入的独立工作层，不与画布共享三栏布局。名字只在顶沿显示，修改在记录页完成。工具按钮使用名称与电气符号，屏幕阅读名称完整。底部状态色与文字共同传达运行、未运行和未应用草稿。

## 与相邻产品的结构差异

Oasis 以纸张正文和文档文件菜单为中心；glTF 以浅色模型与模型上下文属性为中心。CircuitJS 的首屏是波形仪器、元件架与运行时基，文件/笔记均按需进入；不复用两者的固定编辑栏或创建入口布局。

## 状态与响应式

保留 loading、原生错误、自动保存 saved/draft/offline/conflict、草稿待应用和计算待运行。375 px 保留左侧窄元件架，原生电路与 Scope 自适应；底部仪器分两排，实验簿占屏幕内区域可滚动。dialog 原生焦点约束、Escape 和焦点返回；原生参数输入继续由原桥接捕获。无新增动效；reduced-motion 沿用原生关闭电流点。

## 验证计划

1. 重排 App/CSS，首屏截图确认画布、元件架、底部仪器语义。
2. Chrome 1440/375 检查坐标、Scope、iframe 实例稳定、键盘焦点和实验簿开关。
3. 实际样例新建/最近打开/导入、DC 数值、未失焦参数草稿、延迟切换及恢复新副本。
4. 实际 XML/PNG/记录导出；check 与既有 6 测试；GPL 源码包 CRC/transfer/资源核对。

采用 frontend-vibe-coding、Vercel React Best Practices 与 Web Design Guidelines；不新增运行时依赖、SDK/CSP 改动或保存/求解算法。
