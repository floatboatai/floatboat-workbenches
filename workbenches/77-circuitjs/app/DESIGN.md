# CircuitJS1 实验工作台

用户在电路上放置、连线和调整元件，运行仿真后观察示波器，再记录实验条件和结论。首屏以原生电路画布与下方示波器为主；左上文件条、横向仪器控制条、右侧窄实验记录本。

用石墨黑画布、荧光绿电压线、琥珀色电流和暖灰笔记纸表达电子实验台。无统计卡。等宽数字用于读数，系统无衬线用于操作。原生工具保留编辑与波形能力，外层提供键盘可达的元件工具、选择器、运行控制。窄屏纵向布局，画布保持最小高度，元件栏可横向滚动。

恢复电路始终暂停。参数输入草稿与已应用电路分别保存；未提交草稿提供显式恢复按钮。旧文档消息通过实例键隔离；切换前冻结画布，失败则解冻。离线、冲突、无效草稿和仿真失败独立显示。无自动声音、真实硬件或网络元件。减少动态效果时关闭电流点。

应用 frontend-vibe-coding、Vercel React Best Practices 与 Web Design Guidelines：完整输入标签、焦点、状态提示，避免高频 React 全量画布重绘，独立原生实例生命周期。
