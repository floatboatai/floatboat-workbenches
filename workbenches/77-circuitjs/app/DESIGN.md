# CircuitJS1 0.9.0：电路实验仪器台

0.8.1 的结构（电路 + 示波器占主空间、左侧纵向元件架、底部仪器台、按需实验簿）已通过结构审查，0.9.0 保留它，只在原有位置加深能力。

## 主任务

用户搭建或打开一个电路（任意 CircuitJS 元件），运行真实求解器，在示波器和仪器读数里观察响应，拖动滑块/修改参数做对比，最后导出电路、画布图或实验记录。

- P0：原生电路 + Scope；左侧元件架；底部时基（运行/单步/复位/速度/电流动画）、探针（元件选择、状态行、编辑/示波器/滑块）、电压、电流。
- P1：元件库抽屉（分类 + 检索，紧贴元件架）；滑块条（紧贴仪器台上沿，仅当电路有可调元件或正在添加滑块时出现）；画布顶沿的电路/PNG 导出。
- P2：实验簿（电路 / 示例库 / 记录 / 文本），顶栏「实验」与「示例库」两个入口。

## 首次使用

空数据目录首次打开即是「555 LED 闪烁器」：555 无稳态振荡驱动 LED，两路示波器（电容锯齿 / 输出方波）、一条 Timing Resistor 滑块。点「运行」即可看到 LED 闪烁与波形；拖动滑块改变频率。顶栏「示例库」直接进入 366 个官方示例。

## 继续上次工作

自动保存的实验在实验簿「电路」页的最近实验中；打开后恢复电路（含速度、滑块、元件动态状态与 Scope 配置）、视图、笔记与未提交草稿（原生参数框输入、未完成的滑块表单、电路文本）。恢复总是暂停，不自动运行。

## 导入与恢复

实验簿「电路」页导入原生 XML/文本或恢复包，「示例库」页「作为新实验打开」，「文本」页「作为新实验应用」——都创建新实验，旧实验不被覆盖。打开前由原生引擎检查：不开放或不识别的元件给出原因并保留原文。

## 空间关系

```
┌ 顶栏：实验 ▾ · 示例库 · 标题 ······························ 保存状态 ┐
│元件架│ 画布顶沿：放置提示 ······················· 电路文件 · 画布 PNG │
│选择  │                                                              │
│元件库│        原生电路（主空间）            ┌──────────────┐          │
│导线  │  ┌ 元件库抽屉（按需，340 px）┐       │              │          │
│R C L │  │ 检索 / 9 个分类 / 不开放说明│                              │
│V ⏚ S │  └───────────────────────────┘                              │
│最近 3│        原生 Scope                                            │
│撤销…│                                                              │
├──────┴───────────────────────────────────────────────────────────┤
│ 滑块 / ADJUST：标签 · 范围 · 数值 · 移除   [添加滑块表单]            │
├──────────────────────────────────────────────────────────────────┤
│ 时基：运行 单步 复位 时间 │ 探针：元件 · 编辑/示波器/滑块 · 状态行 │ V │ I │ 记录 │
│ 速度 ── 电流动画 ──      │                                     │   │   │      │
└──────────────────────────────────────────────────────────────────┘
```

- 元件库是元件架的延伸，而不是新的侧栏：它叠在画布左缘，选中元件即关闭，放置仍在原生画布上拖动；Esc 关闭并把焦点还给「元件库」按钮。元件架保留 7 个常用元件 + 最近 3 个（仅本机浏览器记忆）。
- 速度、单步、电流动画属于时基，所以放在运行按钮下方；滑块属于被调元件，放在仪器台上沿，与探针「滑块」按钮相邻。
- 示例库是实验簿的一页（宽版对话框）：左侧分类/检索，右侧布局示意、引擎检查结果、元件构成和打开按钮。打开即新实验，对话框关闭回到画布。

## 视觉

沿用 0.8.1：黑色画布、深青灰仪器面板、等宽数字、绿/黄信号色。元件库条目用短电气符号（R、NPN、555、AND…）加中英名称；分类标题带英文小字。示例库预览为端点连线示意（细线为导线，粗段为元件本体，黄点为端子），明确标注“非原生渲染”。

## 状态与响应式

保留 loading、引擎错误（可关闭）、保存 saved/draft/offline/conflict、草稿待应用、读数待运行。修改参数或导出不暂停仿真；运行中改参数后读数在下一时间步恢复有效，只有暂停时才显示“待运行”。

≤780 px 时页面整体纵向滚动（画布高 62dvh，滑块与仪器依次排在下方），避免滑块表单被裁剪；元件库抽屉占满画布宽度；示例库改为上下排列。375 px 无横向溢出。

## 与相邻产品的结构差异

Oasis 以纸张与文件菜单为中心；glTF 以浅色模型与浮动检查器为中心。CircuitJS 仍是“仪器台”：工具在左、仪表在下、文件在按需实验簿；新增能力都放进这三个既有区域，没有引入顶部工具条或右侧常驻面板。
