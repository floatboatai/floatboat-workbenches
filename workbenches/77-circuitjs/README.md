# CircuitJS1 电路实验台

基于 [pfalstad/circuitjs1](https://github.com/pfalstad/circuitjs1) 的原生电路求解器、画布和示波器。电路与示波器占据主空间，左侧是元件架与可检索的元件库，底部是时基、探针和电压/电流读数。纯 TypeScript / JavaScript，不需要模型、WASM 或外部服务。

## 使用

- 首次打开是「555 LED 闪烁器」：点底部「运行」，LED 闪烁，示波器显示电容锯齿与输出方波；拖动「Timing Resistor」滑块改变频率。
- **元件库**：左侧「元件库」打开分类抽屉（导线与标注、无源、电源与信号源、半导体、运放与模拟模块、逻辑门与 I/O、数字芯片、定时与混合信号、开关与继电器、仪表与输出，共 141 个元件），可用中文、英文或符号检索（“555”“npn”“与门”“led”），回车选中最佳匹配；在画布上拖动放置。元件架常驻导线/R/C/L/V/接地/开关和最近使用的 3 个元件。
- **示例库**：顶栏「示例库」浏览 366 个 CircuitJS1 官方示例（基础、交流、滤波、二极管、运放、三极管、MOSFET、555、逻辑族、组合/时序逻辑、模数转换、电源变换、锁相环、传输线…），检索、查看布局示意与元件构成，由原生引擎预先检查兼容性，「作为新实验打开」。
- **时基**：运行/暂停、单步（一个时间步）、复位（时间归零并重置元件状态，保持运行或暂停）、仿真速度（显示每秒推进的仿真时间）、电流动画速度。速度随电路保存。
- **探针**：选择元件（在画布单选元件也会同步）、查看状态行（如三极管工作区、Ic/Ib/Vbe，555 各脚电压，逻辑门输入输出）、「编辑参数」打开原生参数框、「加入示波器」、「滑块」为当前元件的数值参数添加滑块（名称、最小/最大，支持 4.7k、100n 写法和对数刻度）。
- **滑块条**：电路中的可调元件（含示例自带的滑块）显示在仪器台上方，拖动实时改变元件值，可移除（撤销可恢复）。滑块随电路文件保存。
- 修改参数、移动滑块和导出都不会暂停仿真；运行中修改后读数在下一时间步恢复，暂停时显示「待运行」。
- 画布顶沿导出 CircuitJS XML 电路文件与 PNG 截图；「实验记录」编辑名称、笔记并导出 Markdown。实验簿「电路」页新建（555 / RC / 直流分压）、最近实验、导入电路或恢复包；「文本」页查看/修订原生文本。
- 原生参数框未提交的输入、未完成的滑块表单和电路文本都随工作副本自动保存；刷新后「恢复到参数框」显式恢复，不自动应用。

## 运行与构建

在总仓库根目录执行：

```sh
pnpm workbench prepare circuitjs
pnpm workbench check circuitjs
pnpm workbench test circuitjs
pnpm workbench dev circuitjs
```

使用 CLI 打印的完整预览地址。重建原生资源：在本应用目录 `node app/engine-src/build.mjs`（结果逐字节可复现）。完整对应源码、原始 SHA-256、依赖许可和重建步骤见 `app/notices/SOURCE.md`。

## 范围、排除与容量

上游注册的元件全部可加载与仿真，只有 3 个元件不开放：音频输入、数据输入（会读取本机文件）和数据导出（只能生成浏览器下载，嵌入引擎无下载权限）。打开含这些元件的电路会说明原因并保留原文。音频输出元件可加载、正常仿真，但不发声（播放入口属于隐藏的原生侧栏，且播放被禁用）。外部电压（需外部脚本驱动）、通用子电路实例（需先有模型）、画布内嵌示波器不放在元件库中，但含它们的电路可以打开。高级示波器属性表单、浮动示波器和子电路创建仍未开放；原生波形与右键快捷设置可用。

单个电路最多 4000 个元件条目（官方最大示例 420 个），正式数据 850 KB UTF-8，恢复数据 2 MB，完整保存请求和导入快照 1.95 MB；恢复文件容器 12 MiB。离线 IndexedDB 草稿仅能在相同预览来源恢复；跨来源请使用恢复包。版本冲突不覆盖服务端内容。

该工具用于电路学习与实验分析，不连接真实硬件。画布编辑以鼠标/触控为主；外层元件库、时基、滑块、探针和实验簿支持键盘，画布的全部空间操作并非完整的屏幕阅读器界面。
