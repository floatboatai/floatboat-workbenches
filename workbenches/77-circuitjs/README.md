# CircuitJS1 电路实验台

基于 [pfalstad/circuitjs1](https://github.com/pfalstad/circuitjs1) 的原生电路求解器、画布和示波器。电路占据主工作区，右侧记录实验条件与测量结果。纯 TypeScript / JavaScript，不需要模型或 WASM。

## 使用

- 选择 RC 方波响应或直流分压示例，点击「运行」；原生电路下方显示波形。
- 工具条选择导线、电阻、电容、电感、电压源、接地或开关，在画布拖动放置；原生选择、移动、连线、撤销和重做可用。
- 双击元件或通过元件列表「编辑参数」，点击原生 Apply/OK 才应用。原生参数框未失焦的输入也自动保存；刷新后「恢复到参数框」显式恢复草稿，不自动应用。
- 「加入示波器」观察选中元件。原生右键菜单保留波形设置等功能。
- 导出 CircuitJS XML 电路文件、PNG 电路/波形截图和 Markdown 实验记录。导入原生 XML/传统文本或实际恢复包都创建新实验。
- 「恢复包」包含已应用电路、原始导入文本、实验笔记、视图和未提交输入；普通原生电路文件不含笔记/未提交草稿。
- 恢复电路始终暂停；修改电路后的旧读数显示「待运行」。波形历史不持久化，原生 Scope 配置与元件动态状态随 dump 保存。

## 运行与构建

在总仓库根目录执行：

```sh
pnpm workbench prepare circuitjs
pnpm workbench check circuitjs
pnpm workbench test circuitjs
pnpm workbench dev circuitjs
```

使用 CLI 打印的完整预览地址。重建原生资源：在本应用目录 `node app/engine-src/build.mjs`。完整对应源码、原始 SHA-256、依赖许可和重建步骤见 `app/notices/SOURCE.md`。

## 首版范围与保存

支持基础 R/L/C、电压源、导线、接地、开关、二极管、运放、输出和文本等基础 CircuitJS 电路，最多 256 条顶层记录；默认器材栏提供 RLC 实验工具。未验证的复杂模型、子电路、音频与外部服务入口不开放；高级示波器属性表单、浮动示波器和滑块编辑器暂不开放，原生波形与右键快捷设置可用。未支持导入会显示诊断并保留原文；支持类型中上游不识别的扩展字段仍可从「下载保留原文」获取，不声称原生转换保留未知语义。原始文件不会被转换输出覆盖。

正式数据上限 850 KB UTF-8，恢复数据结构 2 MB，完整保存请求和导入快照 1.95 MB；恢复文件容器允许 12 MiB。离线 IndexedDB 草稿仅能在相同预览来源恢复；跨来源请使用恢复包。版本冲突不覆盖服务端内容。切换会冻结当前原生实例并确认快照，退出实例会清理计时器与原生全局事件上下文。

该工具用于电路学习与实验分析，不连接真实硬件。画布编辑以鼠标/触控为主；外层主要操作、参数选择和原生输入框支持键盘，画布的全部空间操作并非完整的屏幕阅读器界面。
