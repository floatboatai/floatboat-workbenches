# Vega-Lite 图表实验台设计（0.9.0）

## 用户与主任务

数据分析者、运营和产品人员用 Vega-Lite 规格把一份表格数据做成可复现的图表，并贴进报告或演示。P0 是**导入数据 → 选字段/写规格 → 立即看到图 → 修正错误 → 导出 PNG/SVG 或项目包**。用户对象是“图表”（规格 + 所用数据集），内部仍存为 project。

## 首次使用

空数据目录打开即看到一张真实的“三城气温季节变化”图（图层：区间面积 + 折线，点击图例突出城市），右侧是带行号、高亮与 schema 校验的规格，下方数据窗是对应的 `weather.csv`（1,098 行，带类型标记）。不需要创建项目，也不需要 Floatboat Host：渲染、校验、数据导入、示例库和导出全部本地完成；只有“AI 拟定”使用 Host 模型，未连接时在该条内给出状态卡和重新检测。

## 继续上次工作

刷新或重开自动恢复最近的工作副本，包括尚未通过校验的规格原文、数据窗当前页签、导出倍率、AI 提示词与候选稿。左上「文件」列出最近图表（含“本机草稿”“待完善草稿”），点击切换；切换期间工作区 inert。

## 导入与恢复

- 数据：数据窗「导入 CSV / TSV / JSON…」或把文件拖进窗口，附加到**当前图表**（UTF-8/GB18030，最大 20 MiB、50 万行）。导入后可“设为规格数据”，或点字段芯片放到 x/y/color 等通道。规格中 `data: {"url": "data/sales.csv"}` 这类官方写法，只要导入了同名文件就会解析到该数据集。
- 规格与项目包：「文件 → 导入规格或项目包」导入 `.vl.json` 或本台导出的 `.vlproject.json`（含数据原文），总是另建新图表；Vega（非 Lite）规格给出明确提示。
- 恢复稿：「下载恢复稿 / 导入恢复稿」处理完整工作副本，导入同样另建新图表。冲突时保存状态提供“打开服务器版本”和“导出恢复草稿”。

## 空间关系

```
┌ 文件 │ 图表名称 │ 自动保存状态（安静）──────────────────────── 示例库 │ AI 拟定 ┐
├──────────── 图表舞台（主区）────────────────┬──── 规格检查器 ─────────────┤
│ 图表 · layer ×2 · area · params  ● 已绘制 [导出]│ 规格 · 通过 schema · 格式化 │
│ [错误条：规格第 N 行 … 定位]                   │ 行号 │ JSON 高亮 │ 折叠        │
│        白色图纸（容器自适应宽度）              │ 补全 / 悬停说明 / 波浪线      │
├──────────── 数据窗（可收起）─────────────────┤                              │
│ 数据 [weather 1,098 行 ●] [sales] … 导入…     │ 问题列表（行:列 · 来源 · 说明）│
│ 字段芯片：date 时间 · city 类别 · temp_max 数值│                              │
│ 表格预览（前 200 行，类型着色）               │                              │
└───────────────────────────────────────────────┴──────────────────────────────┘
```

- **主工作区**：图表舞台占左侧约三分之二宽、上部约三分之二高；浅灰蓝网格台面上放白色图纸。单视图/图层未写宽高时按容器尺寸绘制（不再夹到 900px），拼接、分面、重复按规格中的子图尺寸绘制并可滚动；这类图表不因窗口变化重建，框选等交互状态得以保留。
- **上下文工具**：导出（PNG 1×/2×/3×、复制 PNG、SVG、复制规格、`.vl.json`、编译后的 Vega、项目包）挂在图纸上沿；规格错误条贴在图纸上方并可跳到对应行。
- **规格检查器**：右侧常驻，CodeMirror 6 JSON 编辑；官方 schema 实时校验，合法即自动应用；错误只阻止应用，图纸保持上一次有效版本。
- **数据窗**：图表下方，同一实验的数据证据；字段芯片可点按插入编码或拖入编辑器。
- **文件生命周期**：新建空白、示例库、导入规格/项目包、最近图表、项目包与规格下载、恢复稿、删除全部在「文件」对话框，不占用常驻页头；原“项目选择器 + 新建/立即保存”页头组合已删除，⌘/Ctrl+S 仍可立即保存。

## 视觉

冷静的实验仪器风格：台面 `#e9edf2` 加 24px 细网格，图纸纯白带柔和阴影，检查器白底等宽字体，强调色靛蓝 `#3d55b8` 只用于主要动作（导出、生成、选中页签）。字段类型用固定三色：数值靛蓝方块、时间绿色圆点、类别橙色方块，表头与芯片一致。暗色方案下台面与检查器转深，但图纸保持白色以保证图表配色与导出一致。

## 关键状态

- JSON 语法/schema 错误：错误条 + 行内波浪线 + 问题列表同时给出行列；保存状态显示“规格草稿已自动保存，修正 N 处错误后生效”；图片导出禁用并说明原因，规格仍可复制和下载。
- 外部资源：`url` 指向网络或未导入文件时，问题列表给出琥珀色提醒，图纸上方显示“已阻止外部资源”；加载器拒绝一切网络、文件与链接访问，只允许 `data:image`。
- 渲染提示：Vega-Lite 编译警告折叠在“提示 N 条”中，不打断编辑。
- 自动保存：idle/pending/saving/saved/draft/offline/conflict 以小字显示在名称旁。

## 窄屏（375px）

顶栏保留「文件」、名称、示例库、AI；下方为“图表 / 规格 / 数据”分段页签，三者都保持挂载（切换不重建编辑器），规格有错误时页签带红点。导出面板变为底部宽弹层，字段芯片菜单不越界，文件与示例对话框全宽滚动。

## 可访问性

跳转链接直达编辑器；编辑器内容区带 `aria-label`；图表容器为 `role=figure`；对话框为原生 `<dialog>`，Escape 关闭并归还焦点；导出与芯片菜单 Escape/外部点击关闭；状态使用 live region；字段名、数据集名和代码标记 `translate="no"`；尊重 reduced-motion。

## 与相邻工作台的差异

Mermaid 是“源码 IDE 与图形逐行对照”（深色编辑器占一半）；Observable Plot 是“数据观察报告”。Vega-Lite 的核心是**图表本身**：图纸为主、规格检查器为辅、数据窗作为同一实验的证据，导入的数据集与规格一起保存、导出。
