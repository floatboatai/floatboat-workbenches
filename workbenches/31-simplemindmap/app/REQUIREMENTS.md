# SimpleMindMap 思绪地图 · 0.6.0

围绕计划/学习主题创建原生节点树，提供子节点、同级节点、删除、撤销/重做、原位纯文本编辑和上下文文字编辑。可导航到分支、收起/展开，使用思维导图、向右展开、组织结构三种原生布局及花园/墨色/莓紫三种原生主题配置。

导图与标题、尚未结束的原位文字、上下文未应用文字、无效 JSON 编辑器内容须自动保存；恢复后用户可继续应用。后台保存不锁输入，新建/打开/导入须同步防重入和等待旧稿持久化。导入工程或实际 cacheValue.snapshot 恢复稿均创建新项目。

原生 getData 节点 JSON 可再次导入；完整工程含布局/主题/全部草稿；原生 getSvgData 产生可独立解析和显示的 SVG。只支持纯文本节点，明确拒绝富文本、图片、链接、自定义样式和第三方插件数据；未支持文件原文留在 JSON 草稿，不能静默抹掉字段。

正式模型最多 300 节点、30 层、每节点 4000 字符及 850KB；工作稿最多 1000 节点/每节点 10万字符/1.8MB，另受总请求容量限制。无模型/账号/外部网络能力。普通浏览器和 375px 窄屏均可使用。Floatboat 客户端导入单独标记 unverified。
