# 审批图纸与 SOP 审阅

运营人员可以在原生 LogicFlow 图纸中添加任务/判断/入口/终点、移动节点、编辑文字、从锚点或表单连接步骤、修改坐标与分支条件。检查器按显式入口/终点角色提示悬空、不可达、无后续和有向循环，路径审阅最多显示 30 条并标记循环；这些仅为图纸审阅，不执行业务流程。

导入/导出原生 nodes/edges JSON，完整工程与恢复稿作为新文档；支持 500 节点/1000 连线、550000 字符图纸、40000 字符审阅记录。未知顶层和对象字段保留，未支持的节点/连线类型提示错误并保留原始 JSON 编辑稿，不映射为其他类型。图纸支持 core 内置 rect/circle/ellipse/diamond/polygon 与 line/polyline/bezier。悬空边保留在原始图纸中、检查器报告，无法由原生引擎绘出的悬空边不画出。

完整工作稿含原生图纸、标题、审阅、未应用 JSON、连接表单；后台保存不禁用编辑。新建/打开/导入先同步锁定，等待旧稿离开。恢复不改变原始序列化内容。导出范围不含服务数据库。

原生双击文字输入在尚未退出 contenteditable 时进入完整工作稿，包含未完成换行与空文字。刷新和恢复稿回导提供可见的逐对象恢复输入；只有明确应用才更新图纸。原生正常退出时依据实际落地文字清理对应草稿，新输入或目标缺失时保留。切换文档前同步撤销旧画布写入权，迟到回调不能改写新图。
