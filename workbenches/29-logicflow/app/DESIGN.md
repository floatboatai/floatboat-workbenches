# LogicFlow · 流程图纸

用户为编写审批与业务 SOP 的运营人员。首屏优先完整图纸、节点工具与结构审阅；主操作是编辑与检查，不承诺流程自动执行。

采用浅米白图纸、深蓝墨线与朱红问题标识，标题使用系统衬线、表单使用系统无衬线。画布占主区域；上方横向节点工具，右侧窄检查栏；原生 JSON 收纳于底部折叠区。与 React Flow 节点 IDE 不同，突出业务标签、入口终点、条件与路径，不展示代码执行器。

保存状态使用共享工作稿状态；编辑未应用 JSON 与审阅记录持续保存。导入/新建/打开期间同步锁住旧文档编辑，后台保存保持可编辑。375px 改为图纸、检查器纵向排列，提供键盘节点选择、属性编辑与连接表单。无必要动效，支持 reduced-motion。
