# 研究台

## 用户与主任务
研究者把一个问题变成有出处的报告。对象是“一份研究”：问题、计划、来源、报告。

## 首屏优先级与路径
- 首次使用：打开即是一份已完成的示例研究（报告分栏 + 来源栏），能直接导出、点引用看依据。“研究”菜单 → 新研究，进入空计划。
- 新建：写问题 → 按模板生成/模型起草 → 改步骤 → 确认 → 执行 → 撰写 → 导出。工作副本在第一次编辑后自动保存。
- 继续上次工作：自动打开最近研究，阶段按进度落在计划/执行/报告；“研究”菜单列出最近研究。
- 导入恢复：“研究”菜单导入完整项目、恢复稿或 DeerFlow 原生会话，总是新建研究。

## 布局原型
顶栏：研究菜单、研究名、三阶段进度（每段带状态：已确认、n/m 步、可交付）、保存状态、主动作“导出报告”。下方左侧是当前阶段工作区，右侧固定来源证据栏（编号、出处、要点、核验）。
- 计划：问题卡（衬线大字）→ 步骤编辑列表（类型色条）→ 确认栏。
- 执行：方式切换（本地检索 / DeerFlow 服务）；本地为逐步卡片（状态、来源编号、发现记录、单步重试）；DeerFlow 为服务卡（状态、启动方式、地址、重新检查）、提交卡、带实时事件日志的研究记录。
- 报告：工具条（视图、格式、插入引用、引用检查）+ Markdown 编辑区与米白报告纸面分栏。
文件生命周期全部在“研究”菜单，没有项目下拉与新建/立即保存页头。

## 色彩、排版与密度
浅暖灰桌面、米白纸面、暗红强调（编号、主按钮、选中引用）；报告用衬线正文，界面用无衬线；编辑区等宽。中等密度：步骤卡与来源卡紧凑，纸面留白。步骤类型用左侧色条区分。

## 关键状态
计划草稿/已确认；步骤待执行/检索中/完成/失败（错误码 + 中文说明）；模型未连接（说明 + 重新检查）；DeerFlow 未设置/未连通/已连接、运行中事件流已连接/重连中/暂停；报告撰写中/复核中/可交付；保存的 idle/pending/saving/saved/draft/offline/conflict。禁用的按钮旁都有原因。

## 窄屏（375）
顶栏换行，三阶段等分；“工作区 / 来源”切换；点击引用自动切到来源并展开；报告分栏改为单列；研究菜单全屏。

## 与相邻工作台的差异
Agent-Reach 是“来源采集台”（目录—原文—摘录夹，以原文阅读为中心）；Oasis 是居中单纸张文稿。本工作台以研究流程为骨架：阶段进度在顶栏，计划与执行是独立工作面，报告纸面与来源栏并排以引用编号互相跳转。

## 结构审查
对照 Agent-Reach 0.9.0 与 Oasis 0.9.0 截图：主区约 74% 宽度给阶段工作区，来源栏固定右侧；主操作（确认计划、执行、完成复核）都在对象旁；文件操作进入菜单；窄屏顺序为阶段 → 工作区/来源。结果见 ACCEPTANCE。
