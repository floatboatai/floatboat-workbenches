# 深度研究工作台需求

用户：需要就一个具体问题做有出处的研究，并交付一份可审阅报告的人（工程选型、方案调研、资料综述）。

主任务：研究问题 → 计划（可编辑步骤、人工确认）→ 执行 → 带引用的报告 → 导出。

- 无外部服务、无 Floatboat Host 时，首屏即可新建研究，用模板计划与 Node 内置检索完成执行，用本地底稿与编辑器完成报告，导出 Markdown/HTML。
- 计划在确认前不执行；修改步骤定义需重新确认。
- 来源有稳定引用编号；报告引用可跳转；交付要求被引来源已核验且无悬空引用。
- Floatboat 模型只给建议（计划、报告草稿），采用是单独动作；离线时说明状态并提供“重新检查”。
- DeerFlow 是可选通道：服务地址可配置、可重新检查、未连通时给出启动方式；提交后以 SSE 事件流跟踪进度，回执未知只读核对、不重发；结果载入不覆盖人工报告。
- 导入真实 DeerFlow 会话（≤8MB），超出项目容量时压缩并标记。
- 自动保存完整工作稿与未完成输入；导入总是新建。
