# Promptfoo 评测台

用户是维护提示词、测试集与发布基线的应用工程师。主任务是从真实 Promptfoo 结果中发现退步，逐个检查输入、断言和输出，记录发布判断。

首屏以横向评测矩阵为主；列是提示版本与 provider，行是用例。左上报告切换、右上导入/运行；不使用固定侧栏和统计卡。选中单元格后底部展开可键盘访问的基线/当前输出与复核记录，测试配置在独立抽屉中。

视觉：浅米白工具纸面、深墨文本、细网格、苔绿通过、砖红失败。数字/耗时用等宽字体，表头紧凑，输出阅读区较宽松。不是聊天产品；主按钮是导入评测、运行套件、导出审阅。

状态：无报告可导入或载入明确的真实离线示例；生成任务 queued/running/completed/failed/interrupted，未连接执行器时显示可操作说明。保存显示 pending/saving/saved/draft/offline/conflict。未应用配置 JSON 和复核意见完整自动保存。导入项目创建新项目。运行结果只加入报告版本，不覆盖编辑。

窄屏将矩阵收为当前版本的纵向结果列表，版本用 select 切换；详情在列表下方。表格滚动局限桌面矩阵，不让整页横向溢出。按钮/表单都有名称、可见焦点；Esc 收起配置，减少动效模式禁用转换。

验收：真实 Promptfoo 0.125.1 结果导入；正确保留失败断言/评分；基线对比；保存重开；延迟保存/失响应/冲突；安全 JSON 套件；独立 runner 实际执行；375/1440px 与错误/空状态；CSV/JSON 导出。
