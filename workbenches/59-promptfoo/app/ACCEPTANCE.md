# Promptfoo 0.9.0 验收

日期：2026-10-29。环境：Node 22.23.4、pnpm 10.22.0、独立无头 Chrome 149.0.7827.55。功能状态 local-verified，结构审查通过。测试数据库、浏览器 profile 和下载均独立于 Host；服务配置 hostConnection:null，网络守卫仅允许本机，未发起真实 Host / LLM 调用。

## 之前 → 现在

- 主任务依赖另装执行器 → 包内 Node 引擎可直接运行 echo、录制回放与规则脚本，产出真实评测文件。
- 4 类断言、单 provider → 21 类本机确定性断言、加权/阈值/指标/transform/assert-set、多版本多 provider，未执行评分单独标记并阻止自动建议发布。
- 3 通过/1 失败的小示例 → 36 个中英文售后工单、7 列、252 格，含通过、失败、执行错误与退步；录制输出为虚构手工资料。
- 600KB/400 格结果限制 → 40 MiB/20,000 格结果，原文独立入库、分片上传；浏览器实际往返约 3.3MB 结果与 5.3MB 项目。
- 基础复核与 CSV → 运行对照、输出差异、发布门槛和逐列判断，YAML/结果 JSON/CSV/HTML/完整项目五种导出。
- 任务回执不确定时丢编号、草稿文件不能导回 → 冻结输入先保存、同编号查询/重试、草稿导入新建；窄屏长列表可继续加载，所有恢复项保留。

## 结构审查（与功能验收分开）

主任务是评测矩阵和失败格复核；文件生命周期进入“评测”菜单，主区没有通用项目选择/立即保存组合。1440×1000 展示矩阵、列头发布判断和右侧检查器；375×812 使用单列列表与下方检查器，保留文件、配置、运行和所有导出。菜单和配置 Escape 归还焦点，按钮/编辑器可键盘操作，空白评测可直接运行。对照 Vega-Lite、DeepTutor 的实际截图后，按主区、工具、文件生命周期和窄屏顺序记录差异，见 DESIGN.md。

正式截图在仓库 docs/screenshots/promptfoo.png。窄屏、错误、冲突和导出报告截图保存在本项 archive。截图内容为普通虚构售后资料，不含测试过程。

## 未覆盖与限制

- 真实 Host 未测，真实 LLM 未测，Floatboat 客户端导入未测；mock 不代表授权、计费、模型可用性或安装已通过。
- 本机引擎是 promptfoo 0.125.1 的确定性子集，不支持全量 provider、Python、模型评分、红队扫描或组织管理。仅对样例与 fixture 范围核对兼容性。
- 官方执行器可选且不入包；本机脚本和 Host 列不参与官方核对。官方 JS 需信任配置，不是工作台 worker 沙箱；worker/VM 本身不是 OS 安全边界。
- YAML 含 recorded:/floatboat: provider 时需要工作台或配套适配器，不能原样交给未改造的官方 CLI。示例输出为手工资料，录制成本/耗时不是新调用测量。
- 40 MiB/20,000 格为上限；实际浏览器验收覆盖 252 格示例、242 用例列表和约 5.3MB 项目，不声明压满上限的性能。
- 自动保存仍受元数据和总请求容量限制；IndexedDB 恢复仅同源。工作草稿不含全部结果，跨设备应导出完整项目；多个运行可使完整导出超出重新导入的 40 MiB 限额。
- 移除运行不回收本机结果表，当前无垃圾回收。官方执行器不支持取消；停止本机任务不会撤销已发生的调用。
- 5 个模块体积 warning 保留；未改共享 SDK/蓝图、catalog、根 README、wiki 或其他工作台，没有推送。
