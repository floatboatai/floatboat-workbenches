# Mesh2Motion 角色动作工坊

将静态人形模型绑定到人形骨架，检查关节与动作，再交付带动画的GLB。采用Mesh2Motion原生权重计算和平滑流程；模型、原件、未完成输入和制作便笺自动保存。

## 使用

在仓库根运行 `pnpm workbench prepare mesh2motion`，然后 `pnpm workbench dev mesh2motion`。导出的 `.fbworkbench` 在Floatboat「我的 → 工作台 → 导入工作台」安装；客户端导入尚未实测。

1. 载入人形样例，或导入自包含静态GLB。
2. 在骨架树选择关节，填写相对偏移和整体比例。源模型先归一到约1.83米并落地。
3. 点击“绑定模型”。更改关节后，旧绑定结果不再作为当前结果导出。
4. 选择动作，显式播放或拖动时间线核对，再导出单个动作GLB。
5. 下载完整工程可带原件和绑定结果；恢复稿只含引用，跨实例用“补齐模型文件”重附匹配原件。导入总是创建新副本。

界面为三维舞台、骨架树、关节检查器和动作轨。关节数值未完成时保留原始字符串，不把它悄悄替换为零；保存状态与绑定状态分别显示。恢复不会自动绑定或播放。

## 范围

- 原生人形骨架66关节，官方CC0动作库87项。支持原生权重生成、有效权重检查、动作预览和GLB导出；不提供手绘权重。
- 输入静态GLB≤1MB、16000顶点，结果资源≤1.4MB，完整工程≤8MB。嵌入PNG/JPEG单边≤2048，总像素≤8388608。
- 不支持外部URL、压缩/特殊扩展、Morph、已绑定或带动画的源模型、FBX、其他骨架类型。导出结果作为完整工程的绑定资源保留。
- 三维需要WebGL；不可用时保留工程与参数，显示说明。没有WASM、GPU计算服务或Host模型依赖。
- 绑定效果仍取决于模型形状和姿态；可人工调整关节。未接动作捕捉或自动语义骨骼识别服务。
- 本机离线恢复限定同一来源/浏览器；端口/设备变化请使用完整工程或恢复稿与匹配原件。
