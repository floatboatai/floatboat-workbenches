# 纸张工坊

当前版本：**0.9.1**。把报价单、发货标签、证书或已有 PDF 表格做成模板：在原生 pdfme Designer 上排版全部 26 种字段，在纸面上直接填写一份，或导入 CSV/JSON 按行批量生成合并 PDF 或 ZIP。全部在浏览器内完成，不需要模型或外部服务。

![纸张工坊实景：结业证书批量数据视图](../../docs/screenshots/pdfme.png)

## 从一张单据开始

1. 打开即是“报价单”示例：标志图片、客户与编号、四行明细表、自动计算的小计/税额/合计、付款说明变量文本、收款二维码、签章框，页脚逐页重复。右上“生成 PDF”直接下载。
2. 顶栏三个视图：
   - **版式**：pdfme Designer。左侧元素栏是全部字段类型（中文名称）：文本、变量文本、表格、图片、矢量图、二维码、Code 128 / EAN-13 / EAN-8 / Code 39 / ITF-14 / UPC-A / UPC-E / NW-7 / GS1 DataMatrix / PDF417 / 日本邮政条码、日期、时间、日期时间、下拉选择、单选、复选框、直线、矩形、椭圆；右侧是 pdfme 的字段列表与属性栏。左侧页面轨顶部的“纸张”卡可选 A4/A5/A6/Letter/物流标签，或**导入 PDF 底图**（最大 40 MB / 100 页），再“改回空白纸”。
   - **填写**：pdfme Form，在纸面上直接填写（日期选择、下拉、勾选、表格增删行都可用）；右栏字段清单可把字段改成可读的中文名称（同步填写值与数据映射）、设为必填，并列出当前填写的问题。
   - **批量数据**：导入 CSV 或 JSON（UTF-8 或 Excel 的 GBK CSV，逗号/分号/制表符、引号内换行；≤ 5000 行、16 MB）。列名与字段名相同自动对应，可逐个改映射；变量文本按同名列填充每个 {变量}；日期“2026-11-15 / 2026年11月15日”、勾选“是/否”自动转换。行列表标出每行的问题（必填为空、条码格式、选项不在列表、表格列数等），中间 pdfme Viewer 预览所选行。“生成合并 PDF”或“生成 ZIP”（文件名取自所选列）会跳过有问题的行并说明跳过了哪几行，可取消。
3. 左侧页面轨的缩略图由生成器 + `pdf2img` 渲染当前数据（批量视图渲染所选行），点击跳到对应页。

“模板”菜单承担文件生命周期：报价单 / 发货标签（7 行发货数据）/ 结业证书（叠加导入的 PDF 底图，6 位学员）示例、空白 A4/A5/标签、以 PDF 为底图新建、导入模板 JSON（本工作台导出、0.3 项目 JSON、pdfme 模板含旧版键值字段）、立即保存、导出模板 JSON（内联底图/图片/数据，可在别处完整导入）、导出恢复草稿、冲突时打开服务器版本、删除，以及已保存模板列表。导入总是创建新模板。

## 实现要点

- pdfme 六包精确 5.4.6（ui/common/schemas/generator/converter/pdf-lib），由 `scripts/build-browser-vendor.mjs` 打成同源浏览器脚本按需加载。所有文本类字段（文本、变量文本、表格表头/表体、日期时间、下拉）统一使用内置的思源黑体（Noto Sans CJK SC），生成的 PDF 中文可检索。
- PDF 底图、较大的图片与数据文件存为 SHA-256 资源（`0004_assets.sql`，1 MiB 分块上传、服务端校验哈希与文件头），模板里只保存 `fbasset:` 引用；≤ 96 KB 的内容直接内联。保存前服务端核对引用都在，缺失时只存为草稿并给出原因。
- 只读文字支持 pdfme 表达式，例如合计 `{报价明细.reduce((s, r) => s + Number(r[2]) * Number(r[3]), 0).toFixed(2)}`；页眉页脚可放在 `staticSchema` 中逐页重复。

## 运行

在总仓库执行 `pnpm workbench prepare pdfme`，然后在本目录 `pnpm workbench:check`、`pnpm test`、`pnpm dev`、`pnpm package`。生成包在 Floatboat → My → Workbenches → Import workbench 导入，默认不含预览数据。验收记录见 [ACCEPTANCE.md](ACCEPTANCE.md)，设计见 [app/DESIGN.md](app/DESIGN.md)，工程说明见 [app/ENGINEERING.md](app/ENGINEERING.md)，来源与许可见 [NOTICE.md](NOTICE.md)。

## 边界

- 纸张 20–1200 mm；模板 1–100 页、≤ 500 个元素；单个值 ≤ 100,000 字符；PDF 底图 ≤ 40 MB / 100 页（加密 PDF 需先去掉打开密码）；图片 PNG/JPEG ≤ 10 MB；数据 ≤ 5000 行 / 200 列 / 16 MB；模板 JSON 导入 ≤ 64 MB。
- 不编辑 PDF 底图原有的文字与表单域，只在其上叠加字段；pdfme 的 signature、自定义插件与远程字体不在范围内（导入时外部字体统一换成内置中文字体）。
- 未被任何模板引用的资源不会自动清理。
- pdfme 自带的 Designer 侧栏和控件在暗色主题下仍是浅色。
