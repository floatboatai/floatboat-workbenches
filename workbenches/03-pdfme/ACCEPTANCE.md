## 浏览器流程（Playwright + Chrome for Testing，1440×900 与 375×812，全新数据目录）

1. **首次打开**：无任何外部服务，报价单示例在版式视图打开，Designer 元素栏列出 26 种中文字段；缩略图由生成器 + pdf2img 渲染。
2. **填写 → 自动保存 → 生成**：在 Form 纸面上把客户改为“宁波海曙书局”，状态转为“已自动保存”，刷新后恢复；“生成 PDF”下载 `报价单.pdf`：1 页，PDF 标题“报价单”，文字含新客户名与“合计 ¥51516.00”。
3. **发货标签批量**：菜单新建示例 → 自动进入批量数据（7 行，第 5 行“「收件人」为必填，当前为空”）；选第 2 行时 Viewer 显示“周以宁”；合并 PDF `发货标签-6份.pdf` 为 6 页、第 2 页为周以宁，提示“已生成 6 份，跳过有问题的第 5 行。”；ZIP 含 6 个按运单号命名的 PDF，解压后单个文件 1 页、含收件人。
4. **结业证书**：示例底图经与用户上传相同的路径入库；合并 PDF 6 页，每页含底图上的 “Certificate of Completion” 与对应学员姓名。
5. **真实 PDF 底图**：715 KB 3 页扫描式表单经“以 PDF 为底图新建”（1 个分块）；2.8 MB 版本经“更换 PDF 底图”走 `status → parts/0,1,2 → finish`；页面轨 3 张缩略图，点第 3 页 Designer 滚到该页；刷新后从资源取回仍为 3 页；生成的 PDF 3 页且保留底图文字；改名为 .pdf 的文本文件提示“所选文件不是 PDF。”；“改回空白纸”恢复 210×297。
6. **导出/导入**：导出模板 JSON（底图内联为 data URL，954 KB）→ 导入后成为新模板（项目数 +1），原模板不变。
7. **GBK CSV**：报价单导入 GB18030 编码的 3 行 CSV，自动对应 5/10 个字段（含 JSON 明细表列）；合并 PDF 3 页，客户与合计分别为 9328.00 / 11660.00 / 15900.00。
8. **字段改名**：填写栏把“客户名称”改成“客户全称”，批量映射仍指向“客户名称”列，Designer 字段列表同步；改成已存在的名称时行内提示“已有名为「客户全称」的字段。”。
9. **自动保存契约**：保存请求延迟 2.5 s 时继续输入，最终值与刷新后均为“报价单AB”；服务端提交后丢弃响应，重试后项目数不变（8 → 8）；503 时状态为“草稿已暂存本机，连接恢复后重试。”（offline），恢复后“立即保存”成功；Designer 属性框宽度清空 → “待应用的属性输入”草稿，刷新后恢复，填 120 应用后回到已保存；批量视图所选行刷新后保留。
10. **规模**：300 行发货 CSV 自动对应 14/14 字段，合并 PDF 约 15 s 生成，300 页（10.9 MB），末页为第 300 行。
11. **375px**：默认填写视图，无横向滚动；页面轨横排，字段/数据栏在纸张下方；模板菜单 Enter 打开后焦点在首项，方向键移动，Escape 关闭并把焦点还给“模板”按钮；视图标签支持方向键。
12. 所有流程 page error 为 0；console error 只来自自动保存演练中人为注入的 503 与断开。

修复记录：缩略图最初用 blob: URL 被 CSP 拦截，改为 data URL；pdfme 5.4.6 Viewer 构造时的弃用提示被单独过滤；预览壳用 grid 时工作区未占满高度，改为 flex；文件选择器原本出现在无障碍树中，改为 `hidden`。

## 结构审查（与功能验收分开）

主任务（排版 → 填写或导入数据 → 生成）都发生在纸张旁：左侧 DTP 页面轨（真实渲染缩略图 + 纸张/底图卡）、中间粘贴板上的 pdfme 原生 Designer/Form/Viewer、右侧字段或数据栏；“生成 PDF”在顶栏右侧，批量输出在数据栏底部。原来的两行通用页头（项目选择 + 立即保存/导入/导出 JSON 按钮行）已移除，文件生命周期只在“模板”菜单。对照 0.9.0 的 PageIndex（文档菜单 + 目录/原页/审阅）与 glTF Transform（资产库 + 画布 + 检查器）截图：主区占比相当，文件入口同为产品内菜单，窄屏顺序为“工具条 → 纸张 → 侧栏”。1440 与 375 截图已审阅。限制：版式视图的 pdfme 自带右侧栏固定 400 px；暗色主题下 pdfme 自带面板仍为浅色。结构结论建议记为 **pass（待主代理复核）**。
