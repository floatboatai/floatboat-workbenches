# 纸张工坊 · 设计（0.9.0）

## 用户与主任务

行政、运营、小型设计工作室：把一张单据（报价单、发货标签、证书、表格回执）做成模板，再按一份或一批数据输出 PDF。主任务顺序：排版 → 定字段 → 填写一份或导入数据行 → 生成 PDF / ZIP。

## 首次使用

打开即是“报价单”示例：标志图片、客户与编号、四行明细表、自动小计/税额/合计、付款说明变量文本、收款二维码、签章框，页脚在 `staticSchema` 中逐页重复。桌面默认在“版式”视图，原生 pdfme Designer 的元素栏列出全部 26 种字段（中文名称）。右上角“生成 PDF”无需任何外部服务即可下载真实 PDF。“模板”菜单再提供发货标签（含 7 行发货 CSV）、结业证书（叠加导入的 PDF 底图，含 6 位学员）与空白纸张。

## 继续上次工作

自动打开最近的工作副本。“模板”菜单列出已保存模板与本机恢复项；保存状态是顶栏中的一行安静文字，冲突时菜单出现“打开服务器版本”。

## 导入恢复

- 模板菜单 → “以 PDF 为底图新建…”或“导入模板 JSON…”（本工作台导出、0.3 项目 JSON、pdfme 模板，含旧版按名称键入的字段），总是创建新模板，不覆盖当前模板。
- 版式视图的页面轨顶部“纸张”卡：空白纸尺寸、导入/更换 PDF 底图、改回空白纸。
- 批量数据侧栏：导入/更换 CSV 或 JSON，换数据不改模板；可下载含全部字段列的空白 CSV。
- 导出模板 JSON 会内联底图、图片与数据，能在另一台机器完整导入。

## 空间关系

```
┌ 顶栏 48px：[模板▾] 模板名 ｜ 版式 · 填写 · 批量数据 ｜ 保存状态 ［生成 PDF］
├ 页面轨 148px ┬ 粘贴板（主区，占满剩余宽度）                     ┬ 侧栏 320px
│ 纸张卡(版式) │ 版式：pdfme Designer（含元素栏与字段/属性栏）       │ 填写：字段清单
│ 真实渲染缩略 │ 填写：pdfme Form，直接在纸面上填写                 │ 批量：数据映射、
│ 图，点按跳页 │ 批量：pdfme Viewer，显示所选数据行                 │ 行校验、合并/ZIP
```

- 主区始终是纸张；文件生命周期只在“模板”菜单里，不再有“新建/立即保存/导入”按钮行。
- 主业务动作“生成 PDF”在顶栏右侧；批量输出在数据栏底部、紧邻行列表。
- 页面轨缩略图用 pdfme 生成器 + `pdf2img` 渲染当前数据（批量视图渲染所选行），因此与下载结果一致。

## 视觉

- 粘贴板暖灰 `#e6e2da`，纸面恒为白；界面墨绿 `#1f5f5b` 作为唯一强调色，同时传给 pdfme 的 antd 主题，原生面板与外壳一致。
- 13px 系统字体，界面中文；字段类型显示中文名（文本、表格、二维码、Code 128 条码…）。
- 数字（行号、页码、进度）使用等宽数字。暗色主题下外壳变深，纸面保持白色。

## 关键状态

- 引擎/字体加载、缩略图“更新中”、底图上传百分比、批量进度（可取消）。
- 单份填写有问题时，“生成 PDF”给出具体字段，并在字段栏列出；批量时有问题的行标出原因并在生成时跳过，结果提示跳过了哪些行。
- 设计器属性框中未完成的数值作为“待应用的属性输入”草稿保留。

## 窄屏（375px）

默认“填写”视图。顶栏两行：模板菜单 + 名称 + 生成，第二行视图切换与状态。页面轨变为横向缩略条；纸张在上，字段/数据栏在下顺序滚动。Designer 仍可使用但以桌面为主。

## 与相邻工作台的区别

- Invoice Builder：以明细行填写为中心的单一发票；这里以模板为中心，字段类型完整，并按数据行批量输出。
- PDF.js：阅读与批注现有 PDF；这里把 PDF 当作底图叠加字段并生成新文件。
