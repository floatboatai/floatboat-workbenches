# 纸张工坊设计

以纸张和字段映射为中心。沙色点阵桌面、暖白纸张、细棕线条；顶部文档动作，左侧填写字段，右侧完整纸张，设计/填写两种模式。375px 字段在上、纸张在下，Designer 只在自身容器滚动。

首屏优先主编辑任务和保存/导出。加载、未保存、保存中、生成中、错误及待采用均有文字状态。原生控件提供标签和可见焦点，正文有 skip link；删除/替换需确认、未保存离开警告。支持 reduced-motion、安全区与长内容换行。

React Best Practices 应用于条件加载和稳定编辑器初值；Web Design Guidelines 用于语义、键盘、表单、错误状态和触摸布局。桌面/375px 真机浏览器截图检查通过，窗口无横向溢出。Chrome 1500px/375px 中文填值与保存刷新恢复；Designer 的 customer X 坐标从 22 改为 28，填写→设计往返及保存刷新后仍为 28；148×210 mm 双页 JSON 导入、按真实尺寸和选定页预览。下载 PDF 解析确认 2 页、中文可提取，栅格图检查正常。
