# 纸张工坊需求与验收

主流程：编辑文本与矩形版式 → 填写中文字段 → 保存/恢复 → 导出真实 PDF；模板及字段值支持 JSON 导入/导出。

边界：空白纸张 50–500 × 50–700 mm；1–10 页、80 个唯一命名字段，每个内容 5000 字符；1–20 份相同内容副本。只支持 text/rectangle，不支持任意 PDF 原文编辑、图片或 CSV 逐行映射。 持久化项目最多 900 KB，导入在验证后才替换内容。删除和覆盖未保存内容需确认，保存采用版本号防止覆盖另一窗口更新。

2026-10-27 已通过：6 项业务/数据库测试；Chrome 1500px/375px 中文填值与保存刷新恢复；Designer 的 customer X 坐标从 22 改为 28，填写→设计往返及保存刷新后仍为 28；148×210 mm 双页 JSON 导入、按真实尺寸和选定页预览。下载 PDF 解析确认 2 页、中文可提取，栅格图检查正常。

PDF 主流程无需模型或外部服务。 尚未验收导出包导入客户端的安装流程。
