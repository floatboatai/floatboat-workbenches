# 纸张工坊需求与验收（0.9.0）

用户：行政、运营与小型设计工作室。主任务：把单据做成模板 → 填写一份或导入数据行 → 生成 PDF（单份、合并或 ZIP）。

## 必须满足

1. 首次打开无需任何外部服务即可看到报价单示例并下载真实 PDF。
2. 注册 @pdfme/schemas 5.4.6 的全部 26 种字段；所有文本类字段嵌入内置中文字体。
3. 可用现有 PDF（≤ 40 MB / 100 页）作底图，缩略图逐页显示；可改回空白纸。
4. 填写用 pdfme Form，批量预览用 pdfme Viewer。
5. 批量数据：CSV（含 GBK）/JSON 导入，字段映射可改并持久化，逐行校验并标出原因，生成合并 PDF 与 ZIP，跳过有误行并告知。
6. 字段可改为中文名称，同步填写值与映射；拒绝重名、保留名和花括号。
7. 示例：报价单（标志、明细表、计算合计、二维码）、发货标签（条码 + 7 行数据）、结业证书（导入底图 + 6 行数据）。
8. 文件生命周期在模板菜单：新建、示例、以 PDF 新建、导入/导出模板 JSON、保存、恢复草稿、冲突处理、删除；导入总是新建模板。
9. 自动保存：完整工作副本（模板、填写值、数据映射与所选行、未应用的设计器属性）；无效输入保存为草稿，不覆盖最后的合法版本；引用的资源缺失时只存草稿。

## 边界

纸张 20–1200 mm；1–100 页；≤ 500 个元素；值 ≤ 100,000 字符；图片 PNG/JPEG ≤ 10 MB；数据 ≤ 5000 行 / 200 列 / 16 MB；模板 JSON ≤ 64 MB；项目正文 ≤ 900 KB（大文件以资源引用存放）。
