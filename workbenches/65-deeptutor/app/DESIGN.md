# DeepTutor 0.9.0：对页练习册

## 主任务

学习者读一份课程讲义，在右页一次做一道题：选择或写下答案 → 核对 → 答错时读解析、请导师针对自己的错误讲解并追问 → 选择复习等级，题目进入错题/到期复习清单。用户对象是“课程”（一份讲义 + 它的练习题 + 作答与复习记录），界面上不出现“项目”。

## 首次使用

首次打开即是示例课程“Python · 函数与集合”：左页四节讲义（含代码示例），右页第1题已就绪，12道题覆盖单选、多选、判断、填空、简答。判题、复习排程和题库导入都在工作台自身的Node服务内完成（DeepTutor练习模块的TypeScript移植），不需要启动任何外部服务；没有Floatboat时只有“请导师讲解”和“根据讲义出题”两个模型动作不可用，并在按钮旁说明启动方式与“重新检查”。

## 继续上次工作

打开即恢复上次课程、当前题、未提交答案、讲义编辑与题库原文；自动保存状态以一行安静文字跟在课程名下方，只有离线/冲突/工作稿时才出现重试、导出工作稿、读取服务器版本。左上“课程”按钮打开课程书架对话框：最近课程（含本机未确认副本）、新课程、导入课程、导出本课程、导出工作稿与导入记录。

## 导入恢复

- 课程文件或恢复工作稿：在课程书架导入，总是新建课程，原课程不被覆盖；旧生成/复习操作只作为导入记录，不自动重放。
- 题库（JSON/CSV/TSV，UTF-8或GB18030，最多500题）：右页“题库”打开题库对话框，检查后逐行列出问题且整批不导入；通过检查的题可“追加到练习册”（保留已有作答和复习）或“替换整套题”。
- 模型出题：左页“根据讲义出题”设置题数（1–12）、题型（混合或单一题型）、难度后提交；结果先在左页审题，再追加或替换。

## 空间关系

- 顶部文件条（一行）：课程按钮 · 课程名与保存状态 · 复习进度与到期数 · 题库按钮。没有项目选择器、口号或大标题区。
- 主区是左右对页，占满剩余视口并各自滚动：左页讲义（约40%），右页练习（约60%，视觉主体）。
- 右页自上而下：题号条（每题一个编号格，颜色表示未练/答对/答错/到期，可按全部/错题/到期筛选）→ 当前题卡 → 紧挨答案的“核对答案”主按钮 → 判定、参考答案与解析 → 导师讲解与追问 → 复习等级 → 上一题/下一题。
- 左页自上而下：讲义（阅读/编辑切换）→ 学习目标 → 课堂笔记 → 出题设置与出题审阅。
- 按需信息：题库对话框、课程书架对话框；均为模态`dialog`，Escape关闭并把焦点还给触发按钮。

## 视觉

暖白纸张、墨棕文字、砖红表示答错/待巩固，深绿表示答对/已掌握，金色表示到期。讲义与题干用衬线体，选项和控件用无衬线体，题号与代码用等宽体。对页中缝一条细线，不用卡片阴影堆叠。主按钮只有“核对答案”（右页）与对话框内的采用动作。

## 关键状态

未作答 / 已作答未核对 / 客观判定正确或错误 / 需要自评 / 已排复习 / 复习提交待确认（可按原操作重试）；导师：未连接 / 讲解中 / 已讲解 / 失败可重试；出题：设置中 / 生成中 / 待审题 / 失败 / 中断 / 回执未知（核对原任务）；题库：原文草稿 / 行错误 / 待采用候选。

## 窄屏（375px）

文件条压缩为课程按钮、课程名和题库按钮；对页改为单页，顶部“练习 / 讲义”切换（两页都保持挂载，切换不丢输入），默认先练习。题号条横向滚动，选项按钮整行可点，对话框全屏滚动。页面本身无横向滚动。

## 与相邻工作台的结构差异

Oasis以居中纸张为主；PageIndex是章节目录 + 原页 + 便笺；DeepTutor的主体是“讲义—练习”对页，右页一次只给一道题并把核对、讲解、复习排在同一张题卡内，复习状态通过题号条而不是底部长列表表达。
