# 问卷工作台

在当前工作空间设计问卷、填写并保存答卷、查看和导出答案。提供题目列表与参数编辑，也可编辑受限JSON定义；使用实际SurveyJS Form Library渲染。AI建议先展示题目后由用户采用。

每份问卷1至50道题，选择题2至20个选项。只支持纯文字标准题型，不提供商业Creator或公开分发链接。每个项目最多500份答卷，单份50KB。

提交须针对已保存版本，服务端验证必填、类型和选项，保留提交时的问卷快照。重复提交用稳定ID去重；保存失败保留答案并可重试。刷新可以恢复定义和已提交结果，未提交离开有确认。

JSON 定义未应用时须显示状态，禁止把旧定义静默导出；无效 JSON 仍是需保护的草稿。新建、打开或关闭 JSON 编辑器可以取消并保留草稿。已保存问卷切换时答卷页必须刷新为该项目的数据。
