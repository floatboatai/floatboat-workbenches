# 问卷工作台

在当前工作空间设计问卷、填写并保存答卷、查看和导出答案。提供题目列表与参数编辑，也可编辑受限JSON定义；使用实际SurveyJS Form Library渲染。AI建议先展示题目后由用户采用。

每份问卷1至50道题，选择题2至20个选项。只支持纯文字标准题型，不提供商业Creator或公开分发链接。每个项目最多500份答卷，单份50KB。

提交须针对已保存版本，服务端验证必填、类型和选项，保留提交时的问卷快照。重复提交用稳定ID去重；保存失败保留答案并可重试。刷新可以恢复定义和已提交结果，未提交答案自动保留，离开前同步草稿。

JSON 定义未应用时须显示状态，禁止把旧定义静默导出；无效 JSON 仍是需保护的草稿。新建/打开前同步草稿，关闭 JSON 编辑器须确认放弃未应用原文。已保存问卷切换时答卷页必须刷新为该项目的数据。

## 自动保存

编辑后 700ms 防抖自动保存，提交串行且不锁定输入；IndexedDB 暂存、SQLite 工作草稿与合法项目分别保存。无效输入仍保留为草稿，网络失败和版本冲突明确提示并可导出恢复文件。导入创建新项目，打开/新建先同步旧草稿，只有需要放弃未同步内容时才确认。本项目覆盖未应用 JSON、未完成题目、填写答案和 AI 草稿。自动保存回执不得重建重型编辑器；只有切换文档或重新打开才重建。
