# 信笺 · 邮件创作与校样

主流程：编写主题和收件箱预览文案 → 添加/排序/编辑标题、段落、按钮、分隔线与双栏组件 → 配置默认变量和示例收件人 → 桌面/手机/纯文本校样 → 导出可用HTML、纯文本和完整本工作台JSON。

模板变量仅替换 {{name}} 一类标识符，不执行表达式。示例收件人只是本地替换数据，不发送邮件，不调用通讯录。链接只允许http/https；所有文本经React组件转义。缺失变量原样保留并提示。

自动保存完整工作稿：空主题、半截链接/颜色/宽度、未应用变量/收件人JSON、未应用工程JSON与备注。snapshot:{title,data,extra}恢复文件可导入新副本。切换/新建/导入先同步锁定编辑再等待离开；普通后台保存不锁输入。渲染与文件读取按文档/内容身份隔离，晚到渲染不能更新当前校样。

预算：80组件、60默认变量、30示例收件人；正式邮件内容850KB；恢复结构2MB以覆盖服务器≤1.95MB的完整请求已确认草稿；导入文件4MB。超过服务器请求上限时仅按实际IndexedDB结果报告本机保护，不能称已存服务器。

浏览器预览不承诺所有邮件客户端一致。双栏、字体与间距需在目标客户端检查。无任意JSX执行、无发送和服务商接入。
