# 信笺 · 邮件校样台

面向内容运营与产品编辑，完成邮件组件编排、变量校样与交付HTML。首屏先看邮件主题、预览文案和真实信件，再操作正文结构。

空间：上部窄稿件栏；左侧可滚动的内容工坊（段落/标题/按钮/分隔/双栏），右侧更宽的邮件校样纸。字体以Georgia衬线标题和系统无衬线控件形成编辑部感，葡萄紫、淡薰衣草灰和白纸为主。没有波形或录音审阅绿色，也不使用概览指标卡。

状态：编辑内容即时自动保存，服务端官方renderer异步校样；渲染pending/error时隐藏旧预览，不把旧HTML当作新结果。默认样例姓名只用于替换校样，无发送和通讯录操作。空主题/半截链接/无效变量JSON仍可恢复；导出仅接受有效渲染结果。

窄屏：编辑与校样切换标签，保留所有稿件操作；手机校样380px容器在375px实际视口自适应。键盘可添加/排序/删除与修改块，拖拽不是必需。iframe仅展示生成的邮件，禁脚本，浏览器校样不代表所有邮箱客户端保真。
