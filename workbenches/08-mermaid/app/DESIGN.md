# Mermaid 图形工坊设计（0.9.0）

## 用户与主任务

工程师、产品经理和技术写作者用文字维护流程图、时序图、ER 图、甘特图等，并把结果贴进文档、PR 或演示稿。P0 是**改源码 → 立即看到图 → 修正错误 → 导出图片或源码**。用户对象是“图形文件”（`.mmd`），内部仍存为 project。

## 首次使用

空数据目录打开即看到一张真实的“Web 服务发布流程”流程图（含判断、回路、子图与样式类），左侧是带行号和语法高亮的源码，右侧是已适应窗口的图形。无需创建项目即可直接编辑；首次编辑后自动保存为新文件。不需要 Floatboat Host：渲染、模板、导入、导出全部在本地完成，只有 AI 起草依赖 Host 模型。

## 继续上次工作

刷新或重开时自动恢复最近的工作副本（含未通过解析的草稿、AI 提示词、待采用候选稿、导出设置）。左上「文件」打开文件面板，列出最近图形（含“本机草稿”“待完善草稿”标记），点击即切换；切换期间工作区 inert，避免写入旧文件。

## 导入与恢复

- 「文件 → 导入 .mmd / .md」或把文件拖进窗口：`.mmd/.mermaid/.txt` 整体导入；Markdown 提取 ```` ```mermaid ````、`~~~mermaid`、`:::mermaid` 代码块，多个代码块时弹出选择列表（显示所在标题与行号）。导入总是 `replace()` 另建新文件，不覆盖当前图形。名称取 frontmatter `title`、所在 Markdown 标题或文件名。
- 「下载恢复稿 / 导入恢复稿」处理完整工作副本 JSON，导入同样另建新文件。
- 冲突时自动保存状态提供“打开服务器版本”和“导出恢复草稿”。

## 空间关系

```
┌ 文件 │ 图形名称.mmd │ 自动保存状态（安静） ───────────── 模板库 │ AI 起草 ┐
├──────────────── 源码 IDE ─────────┬────────── 图形预览舞台 ────────────────┤
│ 行号 │ 高亮源码 │ 行内错误波浪线   │ 类型 │ 主题 │ 风格 │ − 100% + 适应 │ 导出▾ │
│      │                            │ [错误条：第 N 行 … 到源码中修改]       │
│      │                            │      可拖动/缩放的图形（点阵底）       │
├ 状态栏：图形已同步 / 第 N 行：… 定位 │ 行数·字符 ┤                         │
└───────────────────────────────────┴────────────────────────────────────────┘
```

- **主工作区**：源码（约 42%）与预览（约 58%）并排占满视口高度，没有页头卡片和营销区。
- **上下文工具**：主题、风格、缩放、导出属于图形本身，放在预览舞台上沿；导出（PNG 1×/2×/4×、透明背景、复制 PNG、SVG、复制 SVG、.mmd、Markdown 代码块）是主业务按钮。错误条贴在预览顶部并可一键跳到源码对应行列。
- **文件生命周期**：新建空白、从模板新建、导入、最近图形、下载源码、恢复稿、删除全部在「文件」对话框，不占用常驻页头。
- **按需信息**：模板库是带实时缩略图的对话框；AI 起草是顶栏下的可收起条，Host 未连接时在按钮旁显示状态卡（原因、启动方法、重新检测）。

## 视觉

源码区是深色 IDE（墨蓝底、柔和语法色：图类型琥珀、关键字蓝、连线橙、标签绿、注释灰斜体），预览是浅色制图台：图形自身背景 + 细点阵，深色主题时舞台随图形变暗。顶栏 44px，按钮 12px 字号、3px 圆角，主操作（导出、生成、采用）用钢蓝实色。状态色：已同步绿、绘制中蓝、错误珊瑚红、外部资源警告琥珀。

## 关键状态

- 解析失败：保留上一版图形（半透明），错误条 + 编辑器行内波浪线 + 状态栏同时指出行列，导出图片禁用并说明原因，源码仍可下载。
- 外部图片/CSS url()：只拦截真正联网的写法（`@{ img: "https://…" }`、样式中的 `url(http…)`/`@import`），预览中移除，编辑器以琥珀警告标出，文件保存为工作草稿。`A[Docker image: nginx]` 之类普通文字不受影响。
- 自动保存：idle/pending/saving/saved/draft/offline/conflict 以小号文字显示在名称旁；⌘/Ctrl+S 立即保存。

## 窄屏（375px）

顶栏保留「文件」、名称、模板、AI；名称下方是“源码 / 图形”分段页签（默认“图形”，源码有错误时页签带红点），两个窗格都保持挂载，切换不重建编辑器；预览工具条换行，导出面板变为底部宽度弹层。文件、模板对话框全宽滚动。

## 可访问性

所有控件有标签；编辑器 contentDOM 带 `aria-label`；舞台 `tabIndex=0`，支持 + − 0 与方向键；对话框用原生 `<dialog>`，Escape 关闭并把焦点还给「文件」按钮；导出弹层 Escape/外部点击关闭并归还焦点；渲染与保存状态使用 live region。尊重 reduced-motion（无动画）。

## 与相邻工作台的差异

Markmap 是“脑图主体 + 可收起大纲”；Vega-Lite 是“图表实验台 + 规格检查器 + 数据窗”；Mermaid 的核心是**源码与图形逐行对照**，因此两窗等高常驻、错误精确到行列、外观属性挂在图形上而不是全局设置。
