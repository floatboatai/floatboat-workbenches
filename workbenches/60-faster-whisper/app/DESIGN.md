# 字幕剪辑室 · 设计

## 用户与主任务

用户是访谈、播客、课程与短视频的字幕编辑。最常做的事是：听一句，改字，把入点出点对到声音上，标好是谁在说，然后交付 SRT/VTT/逐字稿。faster-whisper 负责出初稿；产品的重心是**校对**，不是“上传—等待—下载”。

工作对象叫“字幕稿”：一段音频原件 + 一组字幕行（入点、出点、对白、说话人、逐词时间与置信、复核标记）+ 说话人名册 + 术语备注 + 下次转写的参数。内部存为 project，界面上只出现“字幕稿”。

## 路径

- **首次使用**：空数据打开即创建“梧桐路图书馆访谈 · 示例”字幕稿：82 秒原创双人访谈音频，加上 faster-whisper small 的真实逐词转写。前 4 句已人工校对，后 8 句保留模型原样的错字（吴同路、管长、执办、做做……）和低置信词，用户第一眼就能回听、改字、拖入出点、导出。
- **继续上次工作**：自动保存，刷新回到上次的字幕稿和选中的句子；“字幕稿”菜单列出最近字幕稿。
- **新建**：“字幕稿 ▸ 导入音频或视频…”为这段音频建一份新字幕稿（当前稿是空白稿时直接挂上音频）；再在“转写”页提交，或用“在播放头加一句”手动打轴。
- **导入与恢复**：SRT/VTT（含 `<v 名字>`）、faster-whisper 分段 JSON（含 words）、粘贴文本、含音频的完整项目 `.subtitle.json`，一律导入为新字幕稿，原稿不动；采用转写结果同样新建字幕稿，并按时间重叠沿用原稿的说话人。
- 工作副本在第一次编辑或导入/采用时创建；未完成的时间格式与说话人名存为草稿，不冒充已保存模型。

## 空间关系

```
┌ 文件条：字幕稿▾ · 名称 · 保存状态 ················ ●转写 · 导出▾ ┐
├ 监看台：播放 · 时间码 · 倍速 · 缩放 ─────────────────────────────┤
│ 波形（真实峰值）+ 按说话人着色的字幕区间 + 可拖入出点               │
│ 逐词轨（放大后显示每个词，低置信描黄，人工修改虚线）· 时间尺       │
│ 当前字幕（按逐词时间逐字点亮，带说话人）                            │
├ 字幕表（主区）──────────────────────────┬ 检查器 ────────────────┤
│ 筛选：待复核 / 低置信词 · 查找替换 · 加一句 │ 本句｜说话人｜转写      │
│ 每行：编号回听 · 说话人 · 入/出 · 对白 ·  │ 本句：入出点 ±0.1/0.5、 │
│       字数/低置信/匹配 · 复核 · 拆/合/删  │ 设为播放头、字速、逐词  │
│                                           │ 说话人：名册与计数       │
│                                           │ 转写：服务状态+启动命令 │
│                                           │ +重新检查+参数+开始+队列│
└───────────────────────────────────────────┴ 术语与校对备注 ─────────┘
```

- 主操作贴着对象：回听在句号上，入出点在波形上直接拖、在本句里微调，拆分以播放头或所选词为界，复核在行尾（Ctrl/⌘ Enter 复核并进入下一句）。
- 转写是按需的上下文工具，不占主区；文件条上的“●转写”胶囊显示服务是否在线并跳到“转写”页。服务状态、启动命令（可复制）和“重新检查”就在“开始转写”按钮上方；未连接时按钮禁用并写明原因，同时说明校对与导出不受影响。连上后才展开 `transcribe()` 参数（语言、转写/翻译为英语、word_timestamps、vad_filter 与最短静音、beam_size、initial_prompt、hotwords、condition_on_previous_text）。
- 文件生命周期只在“字幕稿”菜单（新建、示例、导入音频/字幕/项目、粘贴、最近字幕稿、删除）和“导出”菜单（SRT/VTT/TXT/JSON、写入说话人、TXT 带时间、完整项目、恢复草稿）。去掉了 0.4 的“项目选择器 + 新建按钮”页头。

## 视觉

深海蓝黑工作区（#10161d）延续剪辑软件的暗场，青绿色（#66d6c4）只给播放头、播放键、当前词与主按钮；琥珀色（#f5c37f）专门表示“需要人看一眼”：待复核、低置信词、拖动中的时间。说话人用 8 色循环，同时出现在波形区间顶边、行左边线、行内说话人选择与当前字幕前缀，靠颜色就能看出对话轮次。时间码一律等宽 + tabular-nums；对白 15px 系统中文字体，行高 1.55；行与行之间只用细分隔线，不用卡片。

密度：1440 宽下首屏同时看到约 5 句字幕、完整波形和本句逐词，适合连续校对；动效只有当前字幕逐字点亮，reduced-motion 下关闭。

## 关键状态

首次示例 / 空白稿（导入音频或打开示例）/ 音频上传进度 / 波形解码中 / 浏览器不能解码（原件仍保存、可转写）/ 逐词与文字不一致（导入后改过）/ 时间格式未完成（草稿，导出被拦截并提示）/ 服务检查中、未运行、令牌不符、版本过旧、非本服务、已连接 / 任务排队、转写中、完成、失败、取消、中断、状态待确认（用原任务重试）/ 删除一句后的“撤销删除” / 保存中、已保存、草稿、离线、冲突（重试、导出恢复草稿、重新打开服务端版本）。

## 窄屏（375px）

文件条两行（菜单与操作一行，名称与保存状态一行）；监看台保留走带、缩放与可横向滚动的波形；字幕行改为两列：编号 + 说话人/入出点两格 + 对白 + 操作行；检查器移到字幕表之后，标签页不吸顶；菜单改为全宽浮层。全页无横向滚动（实测三个标签页均为 0）。

## 与相邻工作台的差异

- **wavesurfer.js**（波形、区间与听审记录）：那里的对象是“音频上的区间与批注”；这里的对象是“字幕行”，区间只是字幕行在时间上的投影，主区是可编辑的字幕表，波形下面多一条逐词轨。
- **OpenMontage**（分镜制作单、原片预览）与 **HyperFrames**（镜头轨）：它们按镜头组织画面；这里按句子组织声音与文字，没有画面预览。
- **LangExtract**（原文纸张 + 证据账本）：同样是“模型初稿 + 人工复核”，但那里以纸面高亮为主；这里复核单位是一句话加它的时间。
