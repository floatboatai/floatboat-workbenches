# 字幕剪辑室需求

对象：音频原件、字幕稿、字幕行（入点、出点、对白、说话人、逐词时间与置信、复核）、说话人名册、转写参数、转写任务、修订草稿与便携项目。

用户从示例、音频或现有字幕开始，在波形与字幕表之间回听、改字、对齐入出点、拆分合并、查找替换、标注说话人、复核，输出 SRT/VTT/TXT/JSON。首屏不依赖任何外部服务即可完成这条主流程，并得到真实文件。

转写调用独立 faster-whisper 服务，任务保存固定 ID 与不可变输入快照（音频哈希、语言、全部 `transcribe()` 参数）；服务回显的参数与快照不一致时不采纳结果。采纳后形成新字幕稿，原稿不被覆盖。服务未连接时，状态、启动命令与“重新检查”出现在转写按钮旁，按钮写明为何不可用，其余功能照常。

必须保留原音频、未完成的时间输入、未命名的说话人、待导入文本、查找替换输入与备注。自动保存不能阻止编辑；冲突不得覆盖另一窗口。任务失败、服务不可达、版本过旧、令牌错误、未识别出内容必须分别说明；不能用示例冒充推理结果——示例字幕标明来源（模型、参数、哪几句已人工校对）。

验收矩阵：

| 场景 | 成功条件 |
| --- | --- |
| 首次打开 | 空数据下直接出现示例访谈：真实波形、12 句、2 位说话人、逐词时间与低置信标记；可回听与导出 |
| 校对 | 逐词时间点亮当前字幕；改字后逐词时间按字符重对齐；在播放头/所选词处拆分，合并；入出点拖动、键盘与按钮微调；查找替换（大小写、正则）；复核与筛选 |
| 说话人 | 名册增删改；逐句与批量标注；VTT `<v>` 导入导出、SRT/TXT“名字：”；重新转写沿用说话人 |
| 导入与交付 | SRT/VTT/分段 JSON（含 words）解析，毫秒时间往返；SRT/VTT/TXT/JSON 合法；完整项目含音频与草稿，导入为新字幕稿 |
| 真实输入 | WAV、MP3、AAC、M4A/MP4/MOV、OGG/Opus、WebM/MKV、FLAC、AIFF 按内容识别，最大 200 MB；字幕最多 4000 行、6 小时 |
| 自动保存 | 编辑、延迟回执、丢回执重试、无效时间草稿、刷新与冲突可恢复；导入新建 |
| 转写 | 真正调用 WhisperModel.transcribe() 并传入所选参数；持久任务、相同 ID 幂等；结果含逐词时间与运行信息 |
| 可访问与窄屏 | 标签、焦点、键盘控制（波形手柄、标签页、快捷键）；375px 无全页横向溢出；reduced-motion |
| 外部边界 | 模型/服务、Host 与客户端导入分别记录，不混同完成状态 |
