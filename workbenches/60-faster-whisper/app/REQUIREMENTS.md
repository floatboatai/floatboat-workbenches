# 字幕剪辑室需求

对象：音频原件、字幕项目、字幕行、转写任务、修订草稿与便携项目。

用户从音频或现有字幕开始，在播放器/波形与字幕行间切换，修订文字和入点出点、标记复核，输出 SRT/VTT/TXT。转写调用独立 faster-whisper 服务，必须保存固定任务 ID 与输入快照；人工采纳后形成新项目。

必须保留原音频、未完成时间输入、待导入文本与备注。自动保存不能阻止编辑；冲突不得覆盖另一窗口。任务失败、服务不可达、未识别出内容必须明确呈现，不能用示例代替真实推理。示例字幕只从用户主动选择进入，标明来源。

验收矩阵：

| 场景 | 成功条件 |
| --- | --- |
| 导入与编辑 | 真实 SRT/VTT/JSON 解析，文字和毫秒时间可往返 |
| 自动保存 | 编辑、延迟回执、丢回执重试、无效时间草稿、刷新与冲突可恢复 |
| 音频 | 原件哈希和分块验证，重开后回听，波形为解码结果 |
| 转写 | 真正调用 WhisperModel；持久任务和相同 ID 幂等；原稿不被覆盖 |
| 交付 | 字幕输出合法；完整项目包含音频和草稿，导入为新项目 |
| 可访问与窄屏 | 标签、焦点、键盘控制；375px 无全页横溢出；reduced-motion |
| 外部边界 | 模型/服务、Host 和客户端导入分别记录，不混同完成状态 |
