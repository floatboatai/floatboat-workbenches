# Graphify · 知识地图

## 用户与主任务

接手或审阅一个代码仓库与其文档的人：先看“这批资料里有哪些模块、谁是核心”，再追问“这个对象被谁调用、哪篇文档提到它、两个概念之间怎样连上”，最后回到原文核对并写下判断。工作对象是**知识地图**（一份资料集抽出的图谱 + 人工审阅层），以资料集命名，例如「门店补货助手」。

## 路径

- **首次使用**：首屏直接是示例资料集的地图（131 节点、6 个社区）、选中的核心类与一条已算好的路径，示范“看社区→看对象→看路径→回原文”。不要求先建项目；编辑示例即自动保存为一份知识地图。
- **开始自己的地图**：「图谱 → 新建知识地图」进入空态，地图区域本身就是放置区：拖入文件夹、选择文件夹/文件、打开示例或导入 graph.json。抽取完成即出现地图，左栏切到社区。工作副本在新建时创建，第一次编辑或抽取后保存。
- **继续上次工作**：打开时恢复最近的知识地图（含固定位置、选择、路径、未提交的粘贴文字）；其它地图在「图谱」菜单的最近列表。
- **导入与恢复**：graph.json、完整项目、恢复稿、0.5 版项目都从「图谱 → 导入 JSON…」进入并新建知识地图；恢复稿的旧保存操作只作为历史记录展示。
- **交付**：顶栏唯一的业务按钮「导出」：HTML 报告、graph.json、GraphML、GRAPH_REPORT.md。

## 空间关系

| 区域 | 内容 | 理由 |
| --- | --- | --- |
| 顶部细文件条（深墨蓝） | 「图谱」菜单、地图名、安静的保存状态、全局检索、导出 | 文件生命周期收进菜单；检索与导出是跨区域动作 |
| 左栏 280px | 「社区」：色块、规模、外连、代表成员、显隐/只看/改名、模型命名；「资料」：放置区、粘贴、抽取引擎与状态、资料清单与跳过原因 | 社区是地图的图例与筛选器，资料是地图的来源，二者都直接作用于中央地图 |
| 中央地图（约 55% 宽） | Canvas 力导向图、缩放/适配/重新布局、路径条、图例与计数 | 主工作区，占满剩余高度；路径条紧贴地图，因为结果画在图上 |
| 右栏 340px | 「详情」：类型、社区、摘要、来源行、设为起点/终点、笔记、按关系分组的邻居；「原文」：定位并高亮定义范围 | 选中对象的按需信息；原文与详情同栏切换，地图始终可见 |

## 视觉

浅雾灰地图底（`#eef2f5`）、白色侧栏、深墨蓝文件条；12 色分类色板只用于社区，路径用青柠绿，推断关系用虚线、存疑用点线。节点形状区分资料类型：方块=文件、圆=代码符号、圆角矩形=章节、菱形=术语、三角=设计理由、空心圆=外部模块。等宽字体只用于路径、编号与原文。密度偏高（13px 正文、12px 辅助），因为目标是在一屏内同时看到社区、地图与关系列表。

## 关键状态

空资料（地图即放置区）、读取/上传/抽取进度、布局中、检索无结果、路径不可达（提示忽略方向）、图谱读取失败、原文不在内容库、Python 服务未连接（原因 + 启动命令 + 重新检查）、Floatboat 未连接（说明 + 重新检查，发送按钮停用）、保存中/草稿/离线/冲突（重试、下载恢复稿、读取服务器版本）。

## 窄屏（375px）

文件条两行（菜单+名称+导出 / 检索 / 保存状态），下方三段切换「地图 · 社区·资料 · 详情」，默认地图。在社区里点成员直接切到详情；原文在详情栏内切换。对话框整宽，Escape 关闭并把焦点还给触发按钮。

## 与相邻工作台的差异（结构审查）

对照 `docs/screenshots/agent-reach.png`（三栏资料桌：目录 / 原文 / 摘录夹）与 `docs/screenshots/pageindex.png`（章节树 / 纸张原页 / 便笺）：两者的主区都是“阅读一篇原文”，本工作台的主区是**整批资料的关系地图**，原文只是右栏按需打开的证据；左栏不是文件目录而是社区图例与筛选器，资料清单退到第二页签。与 0.5 版相比，去掉了“项目下拉 + 新建/导入/项目”页头组合与常驻的源码抽屉，文件生命周期进入「图谱」菜单，抽取入口紧贴地图（空态放置区）与资料页签。


## 2026-10-29 结构审查记录

实际查看 Agent-Reach 与 PageIndex 的现有 1440px 截图，分别确认其采集目录/原文/摘录与章节树/纸张/便笺结构。Graphify 的中央区域为整批资料的关系地图，路径就近位于地图底部；社区按颜色、规模与代表成员组织左栏，原文只在右侧检查器按需展开。首次示例与空白地图均无需项目选择器。文件菜单负责新建、最近、导入和恢复，导出菜单独立。

键盘操作包括地图邻居导航、Alt＋方向键固定位置、Enter 定位原文、原生文件输入、对话框 Escape 与焦点返回；文件选择控件保留在 Tab 顺序中，外层显示焦点环。长资料列表使用 content-visibility 降低布局开销。375px 使用视图切换，保留地图、社区、资料与检查器全部入口，不把侧栏隐藏后丢掉操作。

功能验证与结构审查分别记录在 `ACCEPTANCE.md`。本轮截图使用普通「门店补货助手」示例资料，无模型生成的用户数据；画布并非屏幕阅读器的逐节点树，节点文字另通过检索、社区成员及检查器访问。URL 不同步选区/筛选，工作副本保存这些业务状态。
