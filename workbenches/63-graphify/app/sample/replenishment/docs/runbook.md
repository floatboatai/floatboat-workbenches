# 运维手册

## 夜间任务失败

1. 查看任务日志中 `nightly_run` 的退出原因。
2. 如果是个别门店 POS 超时，无需处理：`retry_failed_orders` 会在 06:00 重试，重试记录在 `sync_failures`。
3. 如果所有门店同步失败，检查 `InventoryClient` 的令牌是否过期，然后手动执行：

```bash
python -m replenish.jobs --date 2026-10-28 --only-failed
```

## 建议量异常

采购员反馈建议量过大时，先确认**预测误差**是否因促销被放大。促销期间应在门店配置中开启“促销隔离”，`forecast_demand` 会跳过促销日。

如果某商品的**安全库存**长期为 0，通常是**供应商交期**缺失。补齐供应商主数据后重新运行即可。

## 审批积压

`ApprovalQueue` 超过 500 条未处理建议时会告警。可以在审批界面按门店批量批准低风险建议（建议量不超过两箱）。

联系人：供应链平台组值班表。
