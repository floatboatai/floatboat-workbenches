# ADR-0003：安全库存按服务水平计算

- 状态：已采纳
- 日期：2026-09-14
- 相关：[架构说明](../architecture.md)

## 背景

早期版本使用固定 3 天销量作为**安全库存**。高峰期缺货率达到 6.8%，而长尾商品积压严重。门店希望按商品的波动程度区分安全库存。

## 决策

安全库存改为：

```
safety = z * sigma * sqrt(cycle_days + lead_time_days)
```

其中 z 为**服务水平系数**（默认 95% 对应 1.65），sigma 为**预测误差**，cycle_days 为**补货周期**，lead_time_days 为**供应商交期**。实现位于 `ReorderPolicy.safety_stock`。

## 影响

- 需要预测模块输出预测误差，`MovingAverageForecast.error` 因此新增。
- 生鲜品类的服务水平系数单独配置为 1.28，以控制损耗。
- **补货点**随安全库存变化，审批界面需展示两者。

## 备选方案

按 ABC 分类设置固定天数：实现简单，但无法反映同类商品之间的波动差异，未采纳。
