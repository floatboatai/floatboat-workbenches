- `pnpm workbench:check`：manifest、锁文件/依赖、TypeScript、服务与 UI 构建通过。保留三个模块体积提示：`extract/code.ts`、`autosave-client.ts`、`useGraphDesk.ts`，未绕过检查。
- `pnpm test`：26/26。覆盖代码与文档抽取、社区确定性/连通性、元数据/平行边/容量、最短路径、导出转义、内容地址与分片、旧项目迁移、草稿验证、完整项目/恢复稿导入，以及模拟 Host 的命名合同和服务连接失败提示。
- Python：6/6，真实锁定库的 AST 抽取、输入代码不执行、独立解释器、路径与空输入拒绝、多文件集合。直接同进程调用的上游缓存根切换警告仍存在；HTTP 适配器每次使用新解释器。
- 缓存并发回归：1/1，实际 `data.ts` 编译产物、请求桩；同一 hash 同时加载图谱和原文得到正确类型，各自复用请求，四个调用只产生两个请求。

浏览器使用 archive 内全新 SQLite 数据目录与独立浏览器上下文。运行编译后的实际应用服务，配置 `hostConnection: null`；浏览器禁止外部网络和真实模型提交。除主动注入的断网/409 冲突外，无非预期 console error 或 pageerror。

## 结构审查：通过

分别查看 Agent-Reach、PageIndex 的真实截图后审查：Graphify 的主对象是关系地图，社区图例和路径直接服务地图，原文作为证据按需展开。空态可直接选择文件，示例可直接审阅；文件生命周期进入图谱菜单。1440×900 与 375×812 实际浏览器均通过主任务和文件生命周期，菜单 Escape 返回触发控件，自动保存期间可继续输入。对照与差异详见 DESIGN.md。

截图：仓库 `docs/screenshots/graphify.png` 为普通示例的真实 1440×900 页面；375px 地图/社区/详情/资料及完整流程截图在证据目录。

## 交付包与证据

三个项目指导文档定稿后再运行 `pnpm package`。同版本已有包先移入 archive，交付不覆盖旧产物。验包逐项比对 `application/` 内源码、测试、迁移、指导文档；资源按 manifest 的模板规范化路径映射核对，检查 zip CRC、未带入数据库/缓存/环境，并在解出的 application 上运行同一测试套件。原始示例资料、安装说明、验收说明与许可均声明为资源随包提供。

所有本轮脚本、日志、截图、下载物、隔离数据库、包与校验清单保留在工作区 `archive/2026-10-29-workbench-depth/graphify/`。本轮浏览器证据在 `codex-browser/out/`，入口脚本在其上一级；包哈希和逐文件匹配结果见 `package-verification.json`，最终提交与包路径见交接回复。

## 未覆盖与限制

- **真实 Host/LLM 未测**，没有发起真实模型或 Host 调用。Floatboat 客户端安装、导入后的权限交互未测；源码包的成功构建与解包测试不等同客户端验收。
- Python 服务做了真实库测试；本轮浏览器仅验证断开提示，未重做 Python HTTP 服务到 UI 的在线端到端流程。Node 内置抽取是确定性启发式，复杂动态调用、宏、重导出与各语言完整语义无法保证；非 Graphify Cloud 或完整 CLI。
- 4 MB/文件、3000 文件、48 MB 资料、8000 节点/40000 关系是校验上限；没有在浏览器压满所有上限。大图布局与渲染仍在主线程，多层关系与高密度标签会拥挤。
- 完整项目含原文与图谱，可迁移；恢复稿仅含引用，需要同一内容库。本机 IndexedDB 仅同一来源恢复，旧版 storageKey 缓存不自动读取。原图消失的审阅笔记保留；内容库暂无孤立 blob 回收。
- 图谱选区/过滤未映射到 URL；Canvas 不提供逐节点可访问树，节点文字可从搜索、社区与检查器访问。未使用屏幕阅读器或真实触屏设备验收。
- 共享 catalog/README/wiki/飞书未改；未 push、PR 或合并。主线整合者负责统一状态与飞书维护。
