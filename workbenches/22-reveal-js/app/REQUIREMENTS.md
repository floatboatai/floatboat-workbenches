# Reveal 排练桌

- 原生 Reveal.js 6.0.2 渲染与导航，横向幻灯片序列；逐页 Markdown 编辑、讲者备注、复制/新增/移动/删除撤销。
- 三个内置舞台主题，16:9/4:3 画幅，淡入/滑动/无过渡，列表逐项出现与页码设置。
- 放映模式、上一/下一步、总览；嵌入时键盘仅聚焦舞台有效。
- Markdown 全稿可编辑应用；未应用与无效文字自动恢复；项目 JSON 和 Markdown 导入为新项目。
- 自动保存完整工作副本、恢复本机草稿、冲突不覆盖，项目选择、新建、删除与草稿恢复导入。
- 项目 JSON 可完整往返；Markdown 以独立 `---` 分页、`Notes:` 开始备注（代码围栏内不解析）。安全 Markdown 支持标题、段落、粗体、斜体、行内代码、列表、引言与代码块；HTML/链接/图片作为文字，不执行或联网。
- 单项目最多50页，每页4000字符正文/2000字符备注，总 JSON 350KB；导入文件400KB，整稿100000字符。过长内容明确拒绝。可继续保存有空正文的草稿。
- HTML 导出内嵌真实 Reveal 引擎与 CSS，可离线打开播放；保留备注，默认不显示。项目 JSON 是可编辑的备份格式，HTML 不作为编辑导入格式。
- 不提供 PDF/PPTX、远程媒体、自定义 HTML/JS/CSS、纵向页面、数学/图表插件、AI。
- 本地 Chrome 接受验收；Floatboat 桌面导入另行验证。
