# Reveal 排练桌设计

用户是用文字组织培训与产品讲解的讲者。主任务是写一页 Markdown、即时查看投影效果、用真实 Reveal 导航排练，然后带走可离线播放的网页。

首屏优先级：当前舞台和页序最高；右侧当前页 Markdown 与讲者备注次之；文件和主题操作放在顶栏和收起的文件区。主界面采用「上方页带 + 左舞台/下播放控制 + 右稿纸」结构，避免固定文件侧栏和统计卡。与 PptxGenJS 的字段编辑器区别是自由 Markdown 行文、Reveal 片段播放和网页导出。

视觉：暖白纸面与墨绿投影，赭金强调当前页，细直线界定区域。系统中文字体，源稿使用等宽字体；舞台采用大标题、宽留白和左对齐，页面页码为小号等宽。界面 13–14px，表单 14px；375px 下输入 16px。深色模式改为炭灰纸面，舞台主题不随工作区深色模式改变。

状态：加载保留明确反馈；正在输入/保存/仅草稿/离线/冲突分开显示。编辑不会被背景保存阻断。整套源稿是待应用草稿，可关闭后恢复；解析错误保留文字。冲突提供恢复文件与打开服务器版本。导入总是新建。删除页面保留撤销入口。

移动端：页带局部横向滚动；舞台在上，编辑稿和备注顺序排列，文件工具换行。放映模式占满当前窗口，退出后返回触发按钮；只在舞台聚焦时处理方向键，输入区不推进页面。尊重 reduced-motion；原生焦点描边保留。

验收：编辑/排序/新增删除撤销/备注/主题/渐进列表/方向键与放映/导出离线 HTML/项目与 Markdown 导入；刷新、失去响应重试、延迟 ACK、非法源稿与冲突恢复；1440/375px、深色与减少动态、零页面异常。
