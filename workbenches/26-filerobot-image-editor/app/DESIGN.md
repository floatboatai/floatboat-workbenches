# 照片工作室设计

用户为电商内容编辑与摄影素材整理者。主任务是在本地原图上裁剪、缩放、调色和标注，然后导出图片；重新打开继续编辑。首屏以图片及真实 Filerobot 工具为主体。

采用暗房式全幅舞台，顶部为小型文件栏（项目、导入与导出），中部保留 Filerobot 原生工具层级与深色中性照片衬底，底部为原始尺寸、工作副本状态与可收起的备注。避免统计卡片和通用后台布局。低饱和石墨灰、米白文字和单一暖琥珀强调色让照片色彩保持主角；控件以系统无衬线 13–14px、标题 16px、紧凑 8px 网格排布。

状态：首次无图时提供明确的本地导入与自制示例；载入显示原图读取状态；修改自动进入待保存/保存中/已保存；未应用输入单独保留为草稿；离线、冲突和失败给出恢复入口。背景保存不锁定工具，也不重建编辑器。

窄屏：文件栏换行，次要操作收进详情区，图片区保持足够高度；工具栏使用 Filerobot 原生响应式底栏，避免整页横向溢出。所有控件具有可见键盘焦点，减少动态效果设置下关闭非必要过渡。

实现步骤：1. 校验上游 React 19 和 onModify/恢复契约；2. 建立原图资源与受限可编辑模型；3. 挂载原生编辑器并接入完整草稿自动保存；4. 图片与便携工程导入导出；5. 领域、浏览器、恢复、窄屏和导出像素验证；6. 打包并记录边界。
