# 图片工作室需求

面向编辑商品图、社交配图和摄影素材的用户。使用真实 Filerobot 图像引擎，以原图为起点完成裁剪、旋转、翻转、尺寸、亮度/对比度/色相、滤镜及文字和形状标注；PNG/JPEG 输出必须包含实际编辑结果。

- 导入本地 PNG/JPEG 创建新工程；原图保持不变并写入声明的 durable data 资源。
- 默认自动保存工程名称、备注、编辑状态和未完成工具输入。后台确认不得重建编辑器或覆盖更新输入。
- 重新打开恢复编辑。待完善的尺寸保存为草稿，保留最后有效模型。离线/冲突与已保存清晰区分。
- 便携 `.fie.json` 导出包含原图、编辑状态与草稿；校验后作为新工程导入。失败不得宣称成功。
- 限制原图 1,000,000 字节、8000px 单边及 1600 万像素；编辑状态 400,000 UTF-8 字节、150 个标注；便携导入 2,000,000 字节。拒绝 SVG、远程图片、任意资源路径和不受支持的模型。
- 使用中文界面、深色图像舞台、键盘可达控件。375px 可导入、调整及导出；减少动态效果。

不包含云图片处理、AI、图片叠加/图像水印、EXIF 保留或完整撤销历史跨会话保存。文字水印可用文字标注实现。每次重开进入安全的裁剪页，编辑结果保持；Filerobot 上游设计恢复仍标为实验性，须保留工程备份。
