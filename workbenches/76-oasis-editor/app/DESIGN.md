# Oasis 0.8.1：专注文稿编辑

P0 是阅读当前段落、直接写作、修改选区和核对分页。首屏由一张居中的连续纸张占主导，稿名与保存状态在紧凑文件条中，格式工具靠近纸张顶部。页面不是文稿数据库，也不常驻管理表单。

P1 是文件生命周期：左上「文稿」打开文件面板，集中新建空白文稿、导入DOCX、最近文稿列表、DOCX导出、原件/文档信息、恢复稿下载与导入。右上只保留PDF校样这一交付动作。新建和打开是主动文件转场；后台保存不打断正文，文件转场保留现有只读guard。

P2 是按需辅助：页码按钮打开真实页数索引/页码跳转，不使用假缩略图；笔记按钮打开页边便笺；字体、原件来源与保真说明位于文档信息。打开/关闭面板只改变UI状态，原生编辑器始终在同一DOM位置，key仍只取documentKey；保留选区、光标与完整自动保存。

结构差异：Circuit的核心是电路与底部仪器读数；glTF的核心是模型与选中对象上下文；Oasis的核心是正文纸面与文字格式。Oasis不使用两侧常驻栏、项目选择器或右上CRUD按钮组，不放营销说明。

视觉：深墨文字、纸白、冷灰写作桌，少量蓝墨色表示当前工具。顶部单一文件条；格式栏按文字/段落/插入分组，空间紧凑。页边工具显示时不改变正文宽度与原生实例。无装饰动画。

375px保留同一个「文稿」入口与全部新建/打开/导入/恢复流程，文件面板成为可滚动对话框，纸张继续适配35%缩放，工具栏单独横向滚动，页面本身不溢出。Escape关闭对话框/便笺并返回触发按钮；Tab焦点可见，原生正文键盘输入不受影响。

验收：1440/375真实菜单生命周期、页码与笔记开关不remount、Escape/焦点返回、reduced-motion、正文未失焦保存/刷新、切换与延迟保存、恢复稿新副本、实际DOCX/PDF导出。数据结构、storageKey、appId、原生引擎、字体与SDK/CSP不变。
