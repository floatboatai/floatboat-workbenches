# Oasis Editor 文稿室

本工作台面向编写、修改、审阅和交付中文文稿的编辑者。连续纸张是首屏主工作区，纸张上方的功能区包含以下选项卡：

- 开始：段落样式、字体、字号、加粗/斜体/下划线/删除线/上下标、字体颜色、突出显示、清除格式、对齐、项目符号、编号、缩进、行距。
- 插入：图片、表格、链接、脚注、公式、符号、分页符、分节符。
- 表格：上下文选项卡，包括行列增删、合并拆分、平均分布、底纹、框线、标题行、镶边行、表格样式。
- 审阅：修订开关、修订者、上一处/下一处、接受/拒绝（逐条或全部）、新建批注、批注列表。
- 布局：页边距预设与自定义、纵向/横向、纸张大小、边距线、段落标记。

查找替换始终可用。原生菜单、右键菜单与对话框必须为简体中文。左上「文稿」菜单负责新建、最近文稿、导入、导出和恢复，右上是 PDF 校样。

编辑器必须使用固定版本的 Oasis 原生 Canvas 内核，所有编辑命令都经过原生命令注册表。保存的内容包括完整模型、修订、批注、脚注、页面设置、OOXML 部件、内嵌图像、原件和未完成的输入。自动保存要区分正式稿、草稿、离线、本机恢复、冲突和待确认写入。修订模式与修订者姓名随文稿一起保存或按浏览器记住。

导出的 DOCX 必须保留修订（w:ins/w:del 和作者）、脚注、批注、表格、编号、图片和纸张尺寸。重新打开导出的 DOCX 时，应得到内容相同的新文稿。中文正文按字断行并遵守基本避头尾规则，首行缩进对中文段落生效。

本地校样使用随包附带的 CJK 字体；DOCX 在外部软件中的排版取决于对方的字体和程序。复杂内容、容量上限和原件保留规则需要明确告诉用户。工作台独立打包，不调用模型，不使用 WASM，不依赖相邻目录。

本地浏览器验收和文档往返验收记录在 ACCEPTANCE.md。在 Host 中实际导入的验证仍为 unverified。
