# Oasis Editor 文稿室

面向需要修改、校样和交付短篇文档的编辑者。连续纸张为主工作区，提供纸张导航、常用排版、校样笔记、DOCX导入及实际DOCX/PDF导出。移动端保留文稿切换与新建入口，并缩小纸张以便查看。

必须使用固定 Oasis 原生 Canvas 内核；存储完整模型、OOXML部件、内嵌图像、原件与未完成输入。自动保存区分正式稿、草稿、离线、本机恢复、冲突与待确认写入。异步文件操作不能覆盖后续输入或另一文稿。

本地校样使用随包CJK字体；DOCX外部排版依赖字体和消费者。复杂内容、容量上限和原件保留应向用户明确说明。工作台独立打包，无模型调用、WASM或兄弟目录依赖。

本地浏览器/文档往返验收已记录在仓库 ACCEPTANCE.md；Host实际导入保持unverified。
