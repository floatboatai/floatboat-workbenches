# Oasis Editor 文稿室

版本 **0.9.0**。这是一个分页的中文文稿编辑器，可以写作、排版、修订和批注，并导出 DOCX 与 PDF。原生 Canvas 编辑内核来自 [celsowm/oasis-editor](https://github.com/celsowm/oasis-editor)，使用 npm **0.0.195**，固定在源码提交 `ad0bd38f7ec7258ee2fb7a9f23fa7815a3d04195`。

![Oasis Editor 文稿室](../../docs/screenshots/oasis-editor.png)

## 界面

纸张居中显示。纸张上方的功能区有以下选项卡：

- **开始**：段落样式、字体、中文字号、加粗/斜体/下划线/删除线/上下标、字体颜色、突出显示、清除格式、对齐、项目符号、编号、减少/增加缩进、行距。
- **插入**：图片、表格（8×8 网格选择）、链接、脚注、公式、符号、分页符、分节符。
- **表格**：仅在光标位于表格中时出现。可插入或删除行列、合并或拆分单元格、平均分布、设置底纹和框线、切换标题行和镶边行、选择表格样式。
- **审阅**：修订开关和修订者、上一处/下一处修订、接受/拒绝当前或全部修订、新建批注，以及可定位、解决和删除批注的批注面板。
- **布局**：普通/窄/适中/宽页边距或自定义（厘米）、纵向/横向、纸张大小（A4、A5、B5、Letter）、边距线、段落标记。

撤销、重做和查找替换固定在选项卡行右端。原生的右键菜单、查找替换、链接、公式、符号、表格属性和图片属性对话框都已是简体中文。

左上「文稿」菜单用于新建、打开 DOCX、打开最近文稿、导出 DOCX、查看原件和文档信息，以及下载或导入恢复稿。右上是 PDF 校样按钮。页码索引、校样笔记和批注按需打开，不会改变纸张宽度。375px 宽时，纸张自动适合宽度（约 43%），工具行可横向滚动，页面没有横向溢出。

首次打开会看到一份 3 页的《城南社区共享书房改造项目建议书》。文稿包含标题与小标题、首行缩进的正文、编号和项目符号、平面图与图题、进度表和预算表、脚注，以及两位审阅人留下的修订和一条批注。

## 保存与往返

正文（不必离开焦点）、文稿名、笔记、修订模式、批注和页面设置都会自动保存。界面会分别显示正式稿、未完成草稿、本机离线恢复、保存中和版本冲突几种状态。修订者姓名由浏览器记住。

导出的 DOCX 会保留以下内容：修订（`w:ins`/`w:del` 和作者）、脚注、批注、表格、编号、图片、首行缩进和纸张尺寸。重新打开导出的 DOCX 会创建一份内容相同的新文稿。原始 DOCX 另存为资源并按 SHA-256 校验，可以逐字节下载。

插入图片时，200 KB 以内的普通 PNG/JPEG/GIF 原样保留。较大的照片会压缩为文档尺寸的 JPEG（最长边 1600px，目标约 280 KB），界面会说明压缩前后的大小。

## 启动与交付

从总仓库执行：

```sh
pnpm workbench prepare oasis-editor
pnpm workbench check oasis-editor
pnpm workbench test oasis-editor
pnpm workbench dev oasis-editor
pnpm workbench package oasis-editor
```

独立的 `.fbworkbench` 包默认不带预览业务数据，可以在 Floatboat 的工作台导入入口中选择。**在客户端中实际导入尚未验证**。本项目不使用模型服务或 WASM，也不改变模板的 CSP、SDK 或工具链。

## 保真与容量

- **字体**：本地 Canvas、FontFace 和 PDF 共用静态的 **Workbench Sans SC**（常规/粗体）。DOCX 使用单一合法字体名，并带东亚字体映射。外部 Office 排版取决于对方机器上的字体，交付前应对照校样检查。
- **断行**：中文按字断行，并遵守基本避头尾规则。
- **复杂内容**：宏、嵌入对象和图表文件会被拒绝导入；如果解析出的图片或表格数量少于原文件，也会拒绝导入。文本框等复杂内容可能无法在画布上完整显示，但原件和全部 OOXML 部件都会保留。
- **容量**：
  - DOCX 原件最大 1.2 MB，展开后最多 8 MB、200 个部件。
  - 正式稿上限 850 KB，主要占用来自图片。导入块的逐字 OOXML 存放在压缩归档中，不计入这一上限。
  - 恢复数据上限 2 MB。超过正式上限的编辑会作为草稿保留并说明原因，不会冒充正式保存。超限的导入会直接拒绝，并给出原因。
