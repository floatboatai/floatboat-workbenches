# glTF 模型优化台

用户导入真实的 GLB、glTF（含 .bin 与贴图，多选或 ZIP）或 Draco/Meshopt 压缩模型（合计 ≤ 64 MB），服务端用 @gltf-transform/core + extensions + functions 4.5.1 解码为规范 GLB，保留 Khronos/EXT 扩展。用户一键运行剪除、去重、焊接、简化、重采样、量化、展平、合并网格、实例化、居中、缩小贴图；每一步生成独立阶段（内容寻址、回读校验），在画布预览、与原件比较文件大小/绘制调用/三角面/上传顶点/材质/显存/关键帧，可撤销或移除并只重算后续阶段。材质 PBR、节点 TRS、贴图替换与 extras 作为修订先于流水线应用。提供贴图清单、动画片段播放、inspect 报告。导出 GLB 可选 Meshopt/Draco 并回读校验；完整工程为带全部资源的 ZIP。完整工作副本与未完成输入自动保存，导入创建新副本，恢复不自动播放。内置可再生成的风机样例（多材质、两张贴图、两段动画）。客户端导入单独记录为未验证。
