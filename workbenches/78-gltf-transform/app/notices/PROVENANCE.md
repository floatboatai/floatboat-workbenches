# Upstream and asset provenance

- glTF Transform, Don McCurdy and contributors: https://github.com/donmccurdy/glTF-Transform . Runtime `@gltf-transform/core`, `@gltf-transform/extensions` and `@gltf-transform/functions`, all **4.5.1**, MIT (`gltf-transform-MIT.txt`). NodeIO with `ALL_EXTENSIONS` reads/writes models; the functions package provides prune, dedup, weld, simplify, resample, quantize, flatten, join, instance, center, inspect, unpartition, meshopt and draco transforms.
- meshoptimizer **1.2.0**, Arseny Kapoulkine, MIT (`meshoptimizer-MIT.txt`): simplifier, EXT_meshopt_compression decoder and encoder (WebAssembly embedded in the JavaScript module, run on the local service only).
- draco3dgltf **1.5.7**, Google Draco team, Apache-2.0 (`draco3dgltf-Apache-2.0.txt`): KHR_draco_mesh_compression decoder (import) and encoder (optional export), run on the local service only.
- pngjs **7.0.0**, MIT (`pngjs-MIT.txt`) and jpeg-js **0.4.4**, BSD-3-Clause (`jpeg-js-BSD-3-Clause.txt`): pure-JS decode/encode for the texture-resize step and the generated demo textures.
- fflate **0.8.2**, Arjun Barrett, MIT (`fflate-MIT.txt`): ZIP import of glTF folders on the service and complete-project ZIP export/import in the page.
- Transitive MIT dependencies of the functions package: ndarray, ndarray-ops, ndarray-lanczos, ndarray-pixels, cwise-compiler, iota-array, is-buffer, uniq, ktx-parse, property-graph. `ndarray-pixels` statically imports `sharp`, a native image library that this application profile cannot ship and does not call (texture resizing uses pngjs/jpeg-js). The lockfile overrides `ndarray-pixels>sharp` with `lodash.noop@3.0.1` (MIT, `lodash-noop-MIT.txt`) so no native module is installed.
- Three.js **0.185.0**, https://github.com/mrdoob/three.js , MIT (`three-MIT.txt`). Geometry of the generated sample, Euler/quaternion conversion and the on-demand viewport.
- `Wind turbine T-07` demo is generated by this workbench (`src/server/sample.ts`) from primitives, procedural textures and baked keyframes. Original Floatboat sample content, MIT, not an upstream or third-party asset.
- Application adapter, tests, inspection layout and original sample: copyright 2026 Floatboat contributors, MIT (`APP-MIT.txt`). This is an independent adaptation and is not endorsed by the upstream authors.

The `.fbworkbench` source package includes application source, exact dependency lockfiles, and these notices. Resource and license entries are manifest-declared assets.
