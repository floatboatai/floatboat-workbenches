# 写作台 · 产品布局（0.9.0）

## 用户与主任务

社区工作者、项目负责人、运营人员写方案、报告与 SOP：连续输入正文，穿插标题、表格、任务清单、配图和链接，最后交给别人一份 Markdown、网页或备份文件。主任务是**在一张安静的稿纸上连续写作**，其次才是排版、整理结构和导出。

## 首屏优先级

1. 稿纸：文稿标题（即文件名）与正文，窄栏、衬线标题、宽松行距。
2. 紧贴正文上沿的格式工具条（吸顶），光标进入表格/图片/代码块时下方多出一行上下文工具。
3. 左侧目录：由正文标题生成，标出当前章节，点击跳转。
4. 页头只放「文稿」「导出」两个菜单和「写作助手」开关；保存状态是稿纸上方一行小字（带状态色点）。

## 空间关系

- **主工作区**：居中稿纸（最大 780 px），三列网格中间一列。不加卡片边框、不放统计卡。
- **上下文工具**：吸顶格式条（撤销重做 · 段落样式 · 行内格式 · 列表/引用/代码 · 对齐 · 插入）；选中文字时浮出的深色格式条；键入 `/` 出现的插入菜单；链接浮层；表格/图片/代码块上下文行。主业务动作都贴着正文。
- **按需信息**：左列目录（≥1180 px 常驻，窄屏为页头「目录」弹层）；右列写作助手（宽屏占右侧留白，不挤压稿纸；≤760 px 为右侧抽屉）；底部字数/字符/阅读时长与快捷键提示。
- 文件生命周期全部在「文稿」菜单（新建空白、新建示例方案、导入为新文稿、最近文稿、删除）与「导出」菜单（Markdown、HTML、完整备份、立即保存、下载恢复草稿、冲突时打开服务器版本）。

## 路径

- **首次使用**：空数据目录直接显示示例方案《社区共享图书角改造方案》（约 800 字，含标题、表格、任务清单、链接、引用、高亮）。此时不创建任何记录；第一次修改后自动创建文稿。
- **继续上次工作**：刷新或重开时恢复最近的工作副本（含未完成草稿、写作要求与待采用的候选稿）。「文稿 → 最近文稿」按更新时间列出，可切换。
- **新建**：「新建空白文稿」立即创建一份空白文稿（占位提示「输入正文，或键入 / 插入…」）；「新建示例方案」回到示例，编辑后才保存。
- **导入恢复**：「导入为新文稿」或把 `.md/.json` 拖到页面上，总是新建，原文稿不变；支持 Markdown、完整备份 JSON、0.3.0 导出 JSON 与「下载恢复草稿」文件。导入提示会说明外部图片改为链接、危险链接被移除等清理结果。
- **工作副本何时创建**：示例在第一次编辑时创建；空白、导入在操作时创建。

## 色彩、排版与密度

白纸 + 灰绿强调色（#466c67），衬线标题（Georgia / 宋体）+ 无衬线正文 17 px / 1.88 行高；工具条 28 px 图标按钮、细分隔线，低对比默认态。高亮用浅黄，选中文字浮条用深色以区别于稿纸。暗色模式整套变量替换；减少动画时关闭平滑滚动。

## 关键状态

- 保存：`编辑后自动保存`（灰点）→ 等待/保存中（黄点）→ `已自动保存`（绿点）；草稿/离线/冲突为橙红色文字，离线时旁边出现「重试」。
- 提示：成功信息为底部浮条（7 秒自动消失），错误为底部可关闭的浮条，不遮挡吸顶工具条。
- 写作助手：Host 未连接时在表单上方显示状态卡（原因、启动方法、重新检测），生成按钮禁用；候选稿渲染预览，可插入到光标处、替换全部正文（确认）或放弃。
- 链接输入错误在浮层内联提示；图片过大、文稿超过容量给出下一步。

## 窄屏（375 px）

单栏稿纸；页头为「文稿」、目录图标、助手图标、「导出」；格式条和上下文行变为单行横向滚动（右端渐隐提示可滑动），按钮 36 px；菜单全宽；表格可横向滚动；助手为全宽抽屉。

## 与相邻工作台的差异

BlockNote 是知识夹 + 块式页面目录，Milkdown 是个人笔记库，MDXEditor 是稿件与审阅边栏，Oasis Editor 是分页纸张。写作台保持「一张连续稿纸 + 左侧章节目录 + 右侧按需助手」，不分页、不做块拖拽，强调长文连续书写与交付（Markdown/HTML）。

## 实现约束

编辑器只在打开/导入/采用另一份文稿时重建（`documentKey`/`epoch`），输入与后台保存不会重挂载；`setEditable` 不触发更新，避免打开即产生保存。工具条在编辑器实例就绪后订阅状态，首屏即可用。
