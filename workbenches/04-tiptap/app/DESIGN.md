# 写作台设计

以阅读与写作为中心。暖白长文稿、大行距、衬线标题、紧邻正文的紧凑工具栏。文件操作在顶栏，生成稿按需出现在右侧对照区；375px 下助手在正文上方、工具栏换行。布局区别于纸张字段面板和分页演示舞台。

首屏优先主编辑任务和保存/导出。加载、未保存、保存中、生成中、错误及待采用均有文字状态。原生控件提供标签和可见焦点，正文有 skip link；删除/替换需确认、未保存离开警告。支持 reduced-motion、安全区与长内容换行。

React Best Practices 应用于条件加载和稳定编辑器初值；Web Design Guidelines 用于语义、键盘、表单、错误状态和触摸布局。桌面/375px 真机浏览器截图检查通过，窗口无横向溢出。Chrome 1440px/375px 输入并加粗→保存刷新恢复→JSON/HTML 导出，导出的 HTML 包含真实 strong 标记。危险链接、非法节点语法、空项目与数据库冲突测试通过。
