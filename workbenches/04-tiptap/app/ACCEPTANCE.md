### Web Interface Guidelines

2026-10-29 从官方源获取后对改动源码复核：图标按钮均有可见名称或 `aria-label`；表单控件有标签、`name` 与 `autocomplete=off`，链接地址 `spellcheck=false`、`inputMode=url`；占位文字以「…」结尾；菜单/抽屉/浮层 `overscroll-behavior: contain`、Esc 关闭并归还焦点；吸顶页头与工具条不遮挡光标（ProseMirror `scrollMargin`、标题 `scroll-margin-top`）；提示改为底部浮条（`role=status`/`alert`）；数字 `tabular-nums` 与 `Intl` 格式；`theme-color` 分浅色/深色；暗色下原生 select 有显式背景与文字色；`touch-action: manipulation`；删除文稿与替换全文需确认，其余编辑可撤销。

### 限制

- 对齐方式无法用 Markdown 表达，导出 Markdown 时丢失（HTML 与 JSON 保留）；下划线写作 `++文字++`，非标准 Markdown 阅读器会显示加号。
- 强调范围两端紧贴文字的中文标点在导出 Markdown 时移到强调之外（仅标点不再加粗），以保证能读回。
- 图片随文稿保存，整份文稿（含图片）上限 1.6 MB，约 4–8 张压缩后的配图；GIF 超过约 480 KB 或长边超过 1600 px 时被转为静态图；不支持 SVG。编辑器内图片未预设宽高，加载时会有一次布局变化。
- 不提供 HTML/Word 导入、协作编辑、评论或分页打印版式。
- 本地恢复依赖同源 IndexedDB；不同预览端口不共享。
- Floatboat 客户端导入源包**未验收**。

## 结构审查：pass（待主代理整合确认）

- 主任务：居中稿纸占 1440 视口中列（780 px），首屏是标题、吸顶格式条与正文；页头只有「文稿」「导出」菜单和「写作助手」开关，没有项目选择器 + 新建/立即保存/导入的组合；保存状态是稿纸上方的一行小字。

- 空态与有内容：首开示例、空白文稿（占位提示）、导入文稿均可直接编辑；导入从「文稿」菜单或拖放一步可达。375 px 保留同一菜单、目录弹层和助手抽屉。
