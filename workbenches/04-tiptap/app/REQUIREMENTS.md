# 写作台需求与验收

主流程：富文本写作与粗体/斜体/小标题/列表/引用/撤销重做 → 保存恢复 → JSON/HTML 导出。AI 草稿先预览，确认后替换正文，可放弃生成稿。

边界：支持段落、1–3 级标题、列表、引用、代码块、换行及分隔线。最多 5000 节点、20 层、100000 字符；只接受安全链接协议。当前无图片上传、协作编辑、Word/PDF 导出或任意 HTML 导入。 持久化项目最多 900 KB，导入在验证后才替换内容。删除和覆盖未保存内容需确认，保存采用版本号防止覆盖另一窗口更新。

2026-10-27 已通过：6 项业务/数据库测试；Chrome 1440px/375px 输入并加粗→保存刷新恢复→JSON/HTML 导出，导出的 HTML 包含真实 strong 标记。危险链接、非法节点语法、空项目与数据库冲突测试通过。

真实 Floatboat llm.generateText 成功返回中文草稿并停留在预览区，未自动覆盖正文。另明确注入 HTTP 503 验证失败时要求和正文保留；注入结果不作为真实模型成功证据。 尚未验收导出包导入客户端的安装流程。
