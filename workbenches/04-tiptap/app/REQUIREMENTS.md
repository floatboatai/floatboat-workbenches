# 写作台需求与验收

主流程：富文本写作与粗体/斜体/小标题/列表/引用/撤销重做 → 保存恢复 → JSON/HTML 导出。AI 草稿先预览，确认后替换正文，可放弃生成稿。

边界：支持段落、1–3 级标题、列表、引用、代码块、换行及分隔线。最多 5000 节点、20 层、100000 字符；只接受安全链接协议。当前无图片上传、协作编辑、Word/PDF 导出或任意 HTML 导入。 持久化项目最多 900 KB，导入在验证后才替换内容。删除项目需确认；导入创建独立项目，版本冲突保留草稿并要求打开服务器版本或导出恢复文件。

2026-10-27 已通过：7 项业务/数据库测试；Chrome 1440px/375px 输入并加粗→保存刷新恢复→JSON/HTML 导出，导出的 HTML 包含真实 strong 标记。危险链接、非法节点语法、空项目与数据库冲突测试通过。

真实 Floatboat llm.generateText 成功返回中文草稿并停留在预览区，未自动覆盖正文。另明确注入 HTTP 503 验证失败时要求和正文保留；注入结果不作为真实模型成功证据。 尚未验收导出包导入客户端的安装流程。

自动保存：停止输入约 700 ms 后保存，后台请求不锁编辑。正文、写作要求与待采用生成稿可在刷新后恢复；不合法的业务输入显示“草稿已自动保存，待完善输入”，不会覆盖最后的合法内容。网络失败时保留本机副本，版本冲突提供恢复草稿导出与服务器版本入口。导入先验证，再创建独立项目。

当前布局：正文为中心的写作区与按需展开的助手；375px、暗色与减少动画偏好保持可用。
