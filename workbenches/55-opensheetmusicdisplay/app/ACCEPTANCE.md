### Web Interface Guidelines

按规则逐项复核改动源码（本轮未联网拉取最新规则文本）：图标按钮均有 aria-label/title；菜单 Escape 与外部点击关闭并还焦点；表单控件有 name、label 与 autocomplete=off；可见 focus-visible；跳转链接；`translate="no"` 用于乐谱标题、作者、声部名；数字 tabular-nums；`overscroll-behavior: contain`；`touch-action: manipulation`；删除批注与删除审校为菜单内二次确认（不使用 confirm 对话框）；theme-color 按明暗配色；reduced-motion 下滚动不做平滑动画；谱面编号标记可 Tab 聚焦、Enter/空格激活。

### 未覆盖与限制

- **真实 Floatboat Host 未测**；本应用不声明、不调用任何 Host/模型能力。Floatboat 客户端导入源包未实测。
- 回放在 headless 浏览器中验证了光标随时值推进与 AudioContext 正常运行，发声未经人耳试听；回放为简单合成音色，不区分乐器，不演奏装饰音、力度与渐变；乐器移调（如单簧管 B♭）不参与发声换算。
- PDF 谱页为 JPEG 图像（约 250 dpi），不含可选中文字；“无限滚动/单行横卷”下导出 PDF 时另做 A4 排版。
- OSMD 排版在主线程，上百页的总谱会让界面短暂停顿；没有 Web Worker 排版。
- 批注锚点按 MusicXML 小节顺序（声部 + 序号 + 拍位），不支持跨小节区间或单个声部内多声部（voice）的区分。
- 原件库中不再被引用的原件不会自动回收。本地恢复依赖同源 IndexedDB，0.3 版本留在浏览器 IndexedDB 中尚未同步的本机副本无法转换（服务端已保存的项目与草稿会在启动时迁移）。
- 大文件验收用的是生成的测试谱，没有用 MuseScore/Finale/Sibelius 的原始导出文件；DOCTYPE、UTF-16、MXL 容器等按 MusicXML 4.0 规范构造测试。
