# 乐谱审校台 · 产品布局（0.9.0）

## 用户与主任务

乐团资料员、出版社编辑、器乐教师拿到一份制谱软件导出的 MusicXML/MXL，要在排练或付印前逐处核对：听一遍、看清每个声部、在出问题的小节或音符上留下编号批注，再把带批注的校样（PDF/PNG）和批注清单交给作者或演奏者。最常做的动作依次是：点谱面定位 → 写批注 → 勾“已核对”；其次是回放、移调、切换声部与版式、导出。

## 工作对象与路径

用户面对的对象是“一份乐谱的审校”（以乐谱标题命名，例如“小步舞曲 G 大调 · 排练前校对”），内部存为 project。

- **首次使用**：空数据目录首开即是内置示例《小步舞曲 G 大调》（Petzold，BWV Anh. 114）及两条示范批注，可直接点谱、回放、写批注，不必先建项目。
- **继续上次工作**：自动保存的最近审校在「乐谱库」菜单里，刷新后回到上次的文档、显示设置与审阅位置。
- **导入**：「乐谱库 → 导入 MusicXML / MXL」。原文件分块上传到原件库，服务端解析通过、浏览器试排前 8 小节后，才另建一份新审校；失败时当前工作不变，错误说明原因（XML 第几行、DTD 内部子集、不是 score-partwise 等）。
- **示例**：「乐谱库 → 示例乐谱」三份，每次打开另建一份审校。
- **恢复**：审校引用的原件不在本机（例如从其他环境恢复的草稿）时，谱面位置显示“选择原文件…”，选择内容一致的原文件即找回，批注不动；内容不同则作为新导入。冲突时菜单出现“打开服务器版本”，任何时候可“导出恢复草稿”。
- **工作副本**：编辑即建立，约 700 ms 后自动保存；空白批注作为草稿保存但不进入正式版本。

## 空间关系

```
┌ 页眉：𝄞 谱校 · [乐谱库▾] · 审校名称 / 著录（作曲·编配·声部·小节·原件大小）· 保存状态 ┐
├ 谱面工具条：光标/回放/速度 · 缩放 · 版式 · 移调 · 声部▾ · 导出▾ ──────────┬ 批注账本 ─┤
│                                                                         │ 当前位置   │
│   宽幅谱纸（OSMD SVG，白纸）                                            │ 声部/小节   │
│   · 蓝色光标（逐音移动、回放时跟随）                                    │ 锚定方式   │
│   · 朱红框：当前小节；竖线：当前拍位                                    │ [在此添加]  │
│   · 编号圆标：批注（朱红=待核对，灰=已核对，蓝=选中）                   │ 筛选       │
│                                                                         │ 编号批注列表│
├ 页数 · 音符数 · 移调状态 · 版权说明 ───────────────────────────────────┴───────────┤
```

主操作贴着对象：定位在谱面上点击完成，添加批注在当前位置卡片里；回放、移调、版式与导出在谱纸上沿。文件生命周期只在「乐谱库」菜单：导入、示例、最近审校、恢复草稿、删除（菜单内二次确认）。没有“项目选择 + 新建 / 立即保存”页头组合；保存只有状态文字，离线或冲突时出现“重试保存”，⌘/Ctrl+S 可立即保存。

谱面与账本双向联动：点谱面编号 → 账本滚动到该条并高亮；点账本编号或位置 → 谱面滚动到该小节、光标移到拍位。光标移动（←/→ 逐音，Shift+←/→ 逐小节）同步“当前位置”。

## 视觉

- 冷灰校样桌（#e3e7ea）+ 白纸谱面，谱纸在暗色模式下仍白底黑字；工具与账本为浅灰面板。
- 朱红 #c2410c 只用于批注与当前位置，蓝 #2563eb 只用于光标、选中与回放状态，灰蓝表示已核对。
- 文档标题与当前小节号用宋体（Songti SC / Noto Serif CJK），呼应出版校样；界面文字用系统无衬线，数字等宽。
- 密度：工具条 32 px 控件；账本每条批注一张卡片，编号圆标与谱面一致。

## 关键状态

读取原件 / 解析 / 排版（谱面上方浮动提示）；导入分块进度（保存状态处）；原件缺失（谱面内找回入口）；渲染失败（谱面内 alert，已保存内容不受影响）；回放中（按钮变蓝“暂停”，位置卡片显示“正在回放”）；空白批注（卡片内琥珀色提示，状态为“草稿已自动保存，待完善输入”）；导出中（导出按钮显示进度，例如“正在生成 PDF 第 3/12 页…”）。

## 窄屏（375 px）

页眉换行：品牌、乐谱库、保存状态一行，审校名称与著录一行；工具条分三行（回放、缩放与版式、移调与声部/导出）；谱纸固定 64 vh 的独立滚动区，OSMD 以至少 680 px 的行宽排版，可横向滚动或缩小比例；账本在谱纸下方完整展开。菜单在窄屏改为左右各留 12 px 的固定面板。

## 与相邻工作台的差异

- **PageIndex**（docs/screenshots/pageindex.png）：左目录 + 中原页 + 右摘录/问答三栏，主区约 50%。本台没有左侧目录，谱纸占约 75% 宽；定位靠在谱面上点击与光标，而不是目录树；批注直接画进谱纸并随导出保留。
- **旧版本台**（0.3，docs/screenshots/opensheetmusicdisplay.png 的历史版本）：页眉有“稿件”菜单 + 立即保存，第二、三行是文件与显示工具条，右侧是“逐节核对”下拉表单，批注不在谱面上。现在页眉只剩乐谱库与状态，工具条一行贴着谱纸，定位改为谱面点击，批注编号显示在谱面上。
- **Mirador**（双图光台 + 复核账本）：同为“看图 + 账本”，但 Mirador 是左资料抽屉和深色光台；本台是白纸校样与音乐专用的时间轴（光标、回放、拍位）。
