# 乐谱审校需求（0.9.0）

用户：乐团资料员、音乐出版社编辑、器乐教师。

主流程：导入 MusicXML/MXL（或打开示例）→ 确认原谱渲染 → 回放、移调、选择显示声部与版式 → 在谱面上点击音符或小节定位，添加编号批注（类别、正文、核对状态）→ 自动保存 → 重新打开 → 导出带批注的 PDF/PNG/SVG、批注 JSON、原文件。

## 输入

- `.musicxml` / `.xml`（UTF-8、UTF-16、声明的 ISO-8859-1/Windows-1252）与压缩 `.mxl`，原文件最大 32 MB，解压后的 MusicXML 最大 64 MB。
- 制谱软件导出的标准 DOCTYPE（只引用公开 DTD）被接受且从不下载；DTD 内部子集、ENTITY 声明、自定义实体、xml-stylesheet 被拒绝。外部图片、链接仅提示“已忽略”。
- score-partwise；最多 64 声部、每声部 5000 小节、40 万个音符/休止符。score-timewise 给出转换提示。
- MXL：按 container.xml 选第一个 MusicXML rootfile（跳过 PDF 等），缺少容器时使用唯一的根目录乐谱；拒绝分卷、ZIP64、加密、未知压缩、路径穿越、重复条目，实际解压流按字节限额。
- 原文件逐字节保留在原件库（SHA-256 为键，内容去重）；项目只保存原件引用、解析索引、显示设置、批注与审阅位置。

## 能力（使用锁定的 OpenSheetMusicDisplay 2.2.1）

- 光标：逐音前后移动、逐小节跳转、点击谱面后光标移到该拍位；回放时跟随。
- 回放：Web Audio 合成器按光标逐时值发声（可见声部、移调后音高、乐谱速度 × 50–150%），不加载外部音色。
- 缩放 30–300%、适合宽度；版式 A4 竖版/横版分页、无限滚动（Endless）、单行横卷。
- 声部显示开关（至少保留一个）、小节号（每行开头/每小节/不显示）、标题与作曲信息、声部名称。
- 移调 ±12 半音（TransposeCalculator，调号一并改写）。
- 批注：锚定声部 + 小节（+ 可选拍位），7 类，最多 1000 条、每条 2000 字；按乐谱顺序编号，画在谱面上，与账本双向联动；筛选全部/待核对/本小节。
- 导出：PDF 校样（每页谱面含批注编号 + 批注清单页）、PNG 当前页、SVG 全部页、批注 JSON（v2，含原件 SHA-256、小节号、拍位、类别）、原文件、MXL 展开的 MusicXML。

## 持久化与恢复

自动保存约 700 ms 后提交，后台请求不锁编辑；空白批注保存为草稿、不覆盖正式内容；网络失败保留本机副本；冲突提供服务器版本与恢复草稿导出；导入与示例另建新审校。原件缺失时可选择同一原文件找回。0.3.x 旧项目（原件内嵌）在启动时迁入原件库。

## 不做

音符编辑与制谱、真实乐器音色、MIDI 输出、多人实时协作。无 AI/外部服务依赖，manifest 没有 llm 能力。
