## 实施与验收

1. 各项目独立worktree。核对固定上游提交、源码、许可和核心运行路径，编写REQUIREMENTS/DESIGN/ENGINEERING。
2. 在固定官方模板 `3b55d46f7ae25e939ce3299073c37ed334d69c02` 内验证原生核心，不修改SDK、工具链或CSP。WASM仍等待用户的客户端和模板支持；不能把只画外观或导入预计算结果作为实现核心。
3. 实现完整工作副本、原件资源、未完成输入、保存回执、恢复稿与完整工程边界。尤其验证原生输入未失焦保存，以及实例切换后拒绝旧回调。
4. 真实Chrome验证核心动作、可回导输出、桌面/375px/键盘/reduced-motion、离线/延迟/丢失回执/冲突/切换；保留自然业务示例截图。
5. check/test/package通过后独立提交，主线程合并并复核导出源码、资源路径、许可证与包哈希。分别标记本地、Host和客户端导入的实际覆盖；完成后才改为local-verified。
6. 更新catalog、README截图画廊、说明与交付包，推送既有公开仓库。

三项不需要默认调用模型；原有Gemini3.8设置保持。Invoice不自动寄送或记账；Mesh恢复不自动播放；Ray恢复不擅自继续模拟。所有范围缩减和不可支持的格式都在项目说明中明确，不静默丢弃数据。
