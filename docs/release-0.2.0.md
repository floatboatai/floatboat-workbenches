## 自动保存

编辑暂停约 700ms 后保存，后台请求不锁定编辑器。工作副本包含业务数据和未应用输入；通过校验才更新项目，未完成内容保存在草稿中并显示真实状态。模型更新和草稿回执在 SQLite 事务内完成，documentId/mutationId 处理响应丢失的重试；项目 revision 防止覆盖另一窗口。

IndexedDB 保存本机工作副本和活动索引。首次同步失败的新草稿可以从项目列表找回；同一浏览器来源的新标签可恢复，待同步请求保留原 mutation 和项目版本。存储不可用时明确提示并允许取消切换；后台保存只清理自身错误，不吞掉业务错误。浏览器存储按 origin 隔离，不承诺跨设备、浏览器配置或预览端口恢复未同步缓存。需要换环境时先同步或导出。

导入创建新项目，保留原项目。编辑器以 documentKey/loadEpoch 管理加载，自动创建数据库记录不会重挂富编辑器。AI 输入与待采用候选可作为工作草稿保存；生成稿不会自动采用。

## 验证

- 主仓库执行两段 catalog 范围的 check/test：1–11 与 51–55，16/16 均通过，共 **114 项应用测试**。
- `pnpm test:tooling`：3项通过，包括新初始化自动保存文件/迁移存在与重跑保留源码。
- 每项真实 Chrome：主要操作、自动保存、刷新/重新打开、实际导出、375px、深色与 reduced-motion。各领域另覆盖未应用JSON/CSV、未完成属性、填写答案、坐标和批注。
- 代表性网络回归：延迟回包继续编辑，服务器已提交但响应丢失，503重试，版本冲突与本机草稿恢复。核心事务有7项独立测试；本机索引另有5组Chrome回归。
- 新来源截图使用示例数据，图表、节点、乐谱及图像均由真实引擎渲染。尺寸、链接和文件哈希见 [截图说明](screenshots/README.md)。

最终构建/测试日志在本地忽略目录 `.cache/batch/`；各 worktree 的 `.cache/` 保存浏览器记录与导出验证。汇总源包以最终源码重新生成并检查身份、文件SHA-256、迁移及原图/数据库排除边界。

## 各领域证据与范围

- 制图：Maker.js 的 DXF 由独立解析器核对毫米单位、孔径与位置；图板参数不完整时保留草稿。React Flow 仍是单链文本处理，只有真实执行产生运行记录。
- 序列：SeqViz 环形跨原点和反向特征有坐标/导出验证；原始输入、选区、特征与意见可恢复。
- 地块：farmOS-map 真实圈绘、拖点、坐标和 GeoJSON；球面面积与独立公式交叉检查。首版限定单环 Polygon、离线坐标视图，不依赖远程底图。
- 文档：PDF Designer 未完成属性单独保存并显式应用；PPTX页序和备注以OOXML验证；Tiptap延迟保存期间保持同一编辑器和新输入。
- 乐谱：OSMD 原始 MusicXML/MXL 字节、声部/版式/小节批注保存恢复，真正 SVG 音符与独立源文件导出；不提供完整制谱或播放器。
- 馆藏：Mirador 原图存于数据资源，重复内容校验哈希、临时文件原子替换；双图光台视图持续保存，响应式重建保留位置；可移植项目JSON携带原图。页名/复核意见草稿及冲突不覆盖已保存数据。
