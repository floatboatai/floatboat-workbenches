## 实现与验收步骤

1. 每个app独立工作目录、身份与迁移；先阅读固定模板指导与上游接口，写REQUIREMENTS和DESIGN。
2. 实现一个完整的产品核心流程，使用真实上游核心、可核验原生格式或明确的服务适配；不得以假生成替代运行。
3. 复用统一自动保存、草稿恢复、冲突和幂等机制；按领域设计布局，所有完整项目可导入导出。
4. 构建与领域测试；真实Chrome桌面/窄屏、保存恢复与失败状态验收；有模型调用时默认gemini-3.8-flash并经Host验证。
5. 合并独立提交，主仓库复核、打包、截图与README画廊，分别记录本地流程、真实上游、Host调用和客户端导入。
