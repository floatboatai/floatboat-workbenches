# 许可证边界

仓库公开可读不等于所有文件使用同一许可证。当前 44 个已验收工作台的原创集成与封装代码采用 [MIT 许可证](https://opensource.org/license/mit)，版权声明为 `Copyright (c) 2026 Floatboat contributors`；各应用的完整许可文本及范围说明保存在其 `app/LICENSE`。

这项授权仅覆盖 Floatboat contributors 为相应应用编写的原创工作台代码，不把整个仓库、候选项目清单或应用内第三方材料统一改为 MIT。计划项目、仓库其他目录，以及来自 Floatboat 模板或 SDK 的代码不因这项授权而改变许可。

第三方包以其原始 LICENSE 为准；有些候选具有 AGPL/GPL、MPL 或商业扩展条款，实际集成时逐项记录，不把整个清单统一声明为 MIT。

复制到应用中的上游源码、静态资源、字体、照片及依赖继续保留原始版权、许可和归属说明。既有 `LICENSE`、`NOTICE`、`THIRD_PARTY_NOTICES` 及 `notices/` 文件不被应用的 MIT 文本替代。通过依赖清单安装的第三方包也沿用其各自许可。

官方 Floatboat 模板在固定版本中尚未选定开源许可证。本仓库开发时下载其工具链，保留原文件说明，不把 SDK/编译器源代码复制发布到此仓库。应用交付包也遵循官方工具的源代码导出边界。

官方打包工具会将 `app/LICENSE` 导出为 `.fbworkbench` 中的 `application/LICENSE`；源码目录中的第三方声明，以及声明为静态资源的许可文件，继续随对应源码或资源打包。声明为业务数据的内容不进入默认源码包，独立服务和模型权重仍按各项目的交付边界单独处理。商店中的 MIT 标记描述本项目原创封装代码的许可，不覆盖上游和第三方材料。

只提交应用代码、文档、依赖清单和锁文件。账号凭据、浏览器登录状态、用户数据及依赖安装目录不提交。
